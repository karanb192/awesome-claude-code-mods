mod-finder, built by Karan Bansal, the catalogue maintainer.

Set up mod-finder

Install in a Claude Code terminal session and complete the installation prompts.

/plugin install mod-finder --marketplace karanb192/awesome-claude-code-mods

Then run /reload-plugins before asking for a mod. Requires Node 18 or later.

The plugin runs a local MCP server that downloads this catalogue from GitHub and caches it on your computer. It gives Claude two read-only tools to search the catalogue and look up individual mods.

A few new tricks.

Mods are Claude Code plugins that run JavaScript or TypeScript hooks inside your session. They can add a dashboard, open a pane, change tool behavior, or bring context into the conversation.

Mods are on by default in Claude Code 2.1.287 and later. Choose a mod, open its repository, and follow the author’s setup instructions. The API can change between releases.
