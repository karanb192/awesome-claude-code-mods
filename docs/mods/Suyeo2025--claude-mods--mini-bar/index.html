mini-bar

A Claude Code mod in Suyeo2025/claude-mods

Minimal two-part HUD: context composition bar above the prompt; model, git, prompt-cache countdown and 5h limit below it. /mini-bar toggles the bar.

mini-bar reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 18
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
