otto-hud

A Claude Code mod in manuacl/claude-mods

Otto, a blue octopus, forecasts your context window on one line above the prompt, in the Claude Code desktop app, and in text in the terminal: weather scaled to auto-compact with what fills the context on hover, the tokens each recent prompt added, and your 5-hour and 7-day limits with a pace projection. Labels in English or French. Fork of Anthropic's Token Weather (Apache-2.0).

otto-hud reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • API methods referenced: 10
  • Access from classified calls: L1, reads: reads settings, reads mod state, draws
