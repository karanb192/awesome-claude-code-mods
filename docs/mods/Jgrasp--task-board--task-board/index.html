task-board

A Claude Code mod in Jgrasp/task-board

A To do / Doing / Done board in a side pane, filled by Claude's to-do list, approved plans and a board tool, plus your own cards

task-board reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
