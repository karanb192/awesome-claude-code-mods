firstmate-mod

A Claude Code mod in dctmfoo/firstmate-mod

Quiet rail: a read-only Firstmate band above the prompt that says what needs you and what each worker is doing (live from Herdr), and a /fm-fleet pane, for one configured Firstmate home.

firstmate-mod reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 4
  • API methods referenced: 15
  • Access from classified calls: L2, writes or runs: runs processes, writes the prompt box, reads files, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
