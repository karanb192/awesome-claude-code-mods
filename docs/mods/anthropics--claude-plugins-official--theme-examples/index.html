theme-examples

A Claude Code mod in anthropics/claude-plugins-official In Anthropic directory

An example plugin to read, copy and change: twenty animated backdrops behind the chat in the desktop app, with frosted-glass panels: one per project or per session. /custom-theme list names them. Fireworks go off over the theme when Claude says "merged"; /fireworks sets them off by hand.

theme-examples reaches L0 (draws and remembers) and passed claude plugin validate.
