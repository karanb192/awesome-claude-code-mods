pulse-cache-tax

A Claude Code mod in MrValraven/pulse-mods

Keeps the one-hour prompt cache warm during /keepwarm windows and holds a cold send once with its estimated rewrite cost. Pinging runs only after /keepwarm. Fork of karanb192/cache-tax.

pulse-cache-tax reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.312.

  • Events hooked: 9
  • API methods referenced: 18
  • Access from classified calls: L2, writes or runs: drives Claude, reads env vars, reads settings, persists state, draws
  • Static scan, not a runtime test
