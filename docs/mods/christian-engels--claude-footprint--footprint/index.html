footprint

A Claude Code mod in christian-engels/claude-footprint

Estimated electricity (⚡) and water (💧) behind each Claude Code turn and session, shown on the spinner, the turn's closing line and the hint line; /footprint opens the breakdown with ranges and sources

footprint reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 9
  • API methods referenced: 11
  • Access from classified calls: L1, reads: reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

/plugin install footprint --marketplace christian-engels/claude-footprint
