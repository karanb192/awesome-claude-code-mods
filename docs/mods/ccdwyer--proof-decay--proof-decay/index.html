proof-decay

A Claude Code mod in ccdwyer/proof-decay

Tracks which test, typecheck, lint and build results are still true after later edits, and stops commit messages that claim checks which are stale

proof-decay reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 5
  • API methods referenced: 9
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
