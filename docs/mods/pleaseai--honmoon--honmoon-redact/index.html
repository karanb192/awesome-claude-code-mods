honmoon-redact

A Claude Code mod in pleaseai/honmoon

Client-side secret/PII redaction hooks: keep API keys and sensitive identifiers out of Claude Code's model context by redacting Read/Bash/Grep tool output, blocking prompts that carry secrets, and denying reads of known credential files. Session-transcript scrubbing verified on Claude Code 2.1.263 (updatedToolOutput is what gets persisted); re-verify on other versions.

honmoon-redact reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 2
  • API methods referenced: 6
  • Access from classified calls: L3, network: network, runs processes, draws
  • Static scan, not a runtime test
