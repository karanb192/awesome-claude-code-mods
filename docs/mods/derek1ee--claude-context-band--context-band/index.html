context-band

A Claude Code mod in derek1ee/claude-context-band

Context-window squares by category above the prompt, with a prompt-cache countdown and an optional keep-warm refresh. Reads the context breakdown, the prompt draft's length and the session transcript's cache usage, all locally; a refresh (manual, or auto-refresh if enabled) sends one model request through Claude Code. Inside Herdr, it also flashes the session's entry in Herdr's agent list as the cache nears expiry, through the local herdr command.

context-band reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
