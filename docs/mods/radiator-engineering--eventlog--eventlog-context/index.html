eventlog-context

A Claude Code mod in radiator-engineering/eventlog

Replaces context compaction in the controller's interactive session of a log-driven repo: the conversation is rebuilt from .context/events.jsonl by `eventlog context`, plus the last few turns word for word. Rebuilds at the log's task boundaries and at a fill backstop; /rebuild queues a rebuild for the end of the next turn, and /compact rebuilds from the log at once. Inert in headless sessions, for other EVENTLOG_AS writers, with EVENTLOG_CONTEXT=off, and in a repo without the log. Falls back to the engine's compaction when eventlog fails.

eventlog-context reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
