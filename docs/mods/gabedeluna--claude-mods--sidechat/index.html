sidechat

A Claude Code mod in gabedeluna/claude-mods

A side panel for questions about the current session: it reads the conversation from cache, looks things up read-only, recaps, says what the main thread is doing, draws diagrams as artifacts and sends a note to main.

sidechat reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 26
  • Access from classified calls: L2, writes or runs: runs processes, writes files, drives Claude, writes the prompt box, reads files, reads env vars, reads the prompt box, reads mod state, persists state, draws
