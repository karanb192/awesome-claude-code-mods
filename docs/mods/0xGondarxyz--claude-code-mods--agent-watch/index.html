agent-watch

A Claude Code mod in 0xGondarxyz/claude-code-mods

Shows one line per running subagent above the prompt: model, task, minutes and its latest tool call

agent-watch reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.
