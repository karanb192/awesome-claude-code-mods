dialup

A Claude Code mod in Kvadratni/claude-mods

Plays an old-school dial-up modem handshake while Claude is thinking or working. /modem toggles it.

dialup reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 5
  • API methods referenced: 5
  • Access from classified calls: L0, draws and remembers: plays audio, persists state, draws
  • Static scan, not a runtime test

Install hint

/plugin install dialup --marketplace Kvadratni/claude-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
