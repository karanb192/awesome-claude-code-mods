stage-bar

A Claude Code mod in lippdev/lippstack

A colorful, animated progress bar above the prompt that tracks the stages of the task you asked for. Claude names the stages and moves the bar as it works.

stage-bar reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
