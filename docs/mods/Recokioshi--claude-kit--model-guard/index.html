model-guard

A Claude Code mod in Recokioshi/claude-kit

Choose the model versions Claude and its subagents may use: /models lists the newest of each family from Anthropic's Models API (older versions one key away); block a version, or a family's new ones, and subagents, workflows and /model asking for it are refused or moved to an allowed version. One list shared by every Claude Code window on the machine; a repo can keep its own.

model-guard reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 10
  • API methods referenced: 20
  • Access from classified calls: L3, network: network, reads files, reads mod state, requests an Anthropic credential handle, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install model-guard --marketplace Recokioshi/claude-kit
