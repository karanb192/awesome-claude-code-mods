tokens-sesion

A Claude Code mod in Picaresco/Plugin-Work

Banda sobre el prompt con el contexto (cifra y barra de verde a rojo), el gasto de la sesión, el uso de CPU y RAM del equipo y el límite semanal del plan; hace que el motor compacte, también a mitad de una tarea, al llegar el contexto al umbral, que se cambia arrastrando la marca de la barra, y guarda el resumen de cada compactación. Panel lateral con los subagentes de cada tarea (inicio, fin, duración y tokens), el plan del trabajo paso a paso con lo que tardó cada uno , el modelo y el esfuerzo de cada tipo de agente y el resumen de la sesión; guarda en el proyecto un histórico de cada sesión y, si se activa, mantiene viva la caché en las pausas mientras sea lo más barato.

The scan could not record a complete footprint for tokens-sesion, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.316.
