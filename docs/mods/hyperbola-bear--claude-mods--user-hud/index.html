user-hud

A Claude Code mod in hyperbola-bear/claude-mods

A control panel tucked into the corner above the Claude Code prompt, as cards in seven modules you turn on or off: your other sessions (which need you, which are working), a context battery and where your tokens go (files, chat, MCP, shell, skills and plugins, subagents and more), model and effort pickers in three styles, prompt-cache countdown with a 2-minute keep-warm alert, the guesses Claude acts on for you to mark right or wrong, handoff buttons, and next steps (follow-up prompts after each reply, one key to put in the prompt box).

The scan could not record a complete footprint for user-hud, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.310.

  • Access: unknown, the footprint is incomplete
  • Static scan, not a runtime test
