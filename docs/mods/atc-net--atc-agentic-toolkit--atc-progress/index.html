atc-progress

A Claude Code mod in atc-net/atc-agentic-toolkit

Claude Code mod: a progress bar above the prompt for the active implementation plan (plans/*.md), plus a live subagents pane (/atc-progress) with model, context, tokens, estimated cost and time. Requires Claude Code 2.1.287+.

atc-progress reaches L2 (writes or runs) and passed claude plugin validate.

  • API methods referenced: 17
