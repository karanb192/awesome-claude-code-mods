explorai-loading

A Claude Code mod in Tomy-Phillip/claude-mods

Shows the Explorai logo above the prompt, filling with brand colors as Claude completes its tasks, with a dancer beside it.

explorai-loading reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 4
  • Access from classified calls: L0, draws and remembers: draws
  • Static scan, not a runtime test
