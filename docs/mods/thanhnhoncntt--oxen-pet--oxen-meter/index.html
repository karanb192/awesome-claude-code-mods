oxen-meter

A Claude Code mod in thanhnhoncntt/oxen-pet

Measures the prompt cache for a team, in Claude Code and, with its command-line companion, Codex CLI and Devin CLI: hit rate per session, subagent and model, a warning before a cold resume re-sends a whole context, the quota each session used, and an anonymized export to pool cost and quota data. Records token counts and timings only, never prompts, code or paths.

oxen-meter reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
