rook

A Claude Code mod in 4DvAnCeBoY/rook-claude-plugin

rook by TestMu AI inside Claude Code: Claude runs rook against the agent it is building and gets failures back grouped into root-cause clusters with rook's remedies, writes scenarios, a live pane with per-scenario lanes and openable failures, re-test prompts after agent edits, a status line score, /rook commands and a production-target guard.

rook reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 5
  • API methods referenced: 26
  • Access from classified calls: L2, writes or runs: runs processes, writes files, changes config, drives Claude, writes the prompt box, reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
