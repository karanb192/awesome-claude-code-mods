pin-board

A Claude Code mod in arasovic/claude-code-mods

Pins standing notes with /pin that Claude keeps following after /compact and /clear; shows them in one row above the prompt or as a counter, and keeps them per folder with --keep

pin-board reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 4
  • API methods referenced: 6
  • Access from classified calls: L0, draws and remembers: persists state, draws
  • Static scan, not a runtime test

Install hint

/plugin install pin-board --marketplace arasovic/claude-code-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
