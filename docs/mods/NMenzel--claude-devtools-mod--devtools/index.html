devtools

A Claude Code mod in NMenzel/claude-devtools-mod

A debugger for Claude Code tool calls: breakpoints, pause/continue/reject/step, a timeline, an inspector, Error Lens failure diagnosis, a Permissions view of who refused each call and why, and sanitized trace exports.
