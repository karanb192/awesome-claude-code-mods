ci-budget

A Claude Code mod in StanislavKozachenko/claude-mods

Keeps GitHub Actions spend in sight: the month's minutes and cost for the repo's organisation or account, GitHub budgets, cache and artifacts, risky workflows as they are written, and runs that hang

ci-budget reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
