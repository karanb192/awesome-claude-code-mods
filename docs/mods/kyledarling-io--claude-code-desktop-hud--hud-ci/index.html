hud-ci

A Claude Code mod in kyledarling-io/claude-code-desktop-hud

Shows whether the GitHub Actions run for your branch is running, passed or failed after you push, in the HUD. Needs the HUD plugin and the GitHub CLI signed in.

hud-ci reaches L2 (writes or runs) by its classified calls and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 3
  • API methods referenced: 6
  • Access from classified calls: L2, writes or runs: runs processes
  • Calls in a namespace that is not in the Claude Code 2.1.302 core table: 3 ($.hud.clear, $.hud.declare, $.hud.push), full access unknown
  • Static scan, not a runtime test

Install hint

/plugin install hud-ci --marketplace kyledarling-io/claude-code-desktop-hud

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
