think-first

A Claude Code mod in shawnclybor/think-first

Makes Claude run a sequential-thinking step before its first write in each request, and again before retrying a tool call that just failed. Uses the sequential-thinking server you already run, so the check also works inside cloud Cowork tasks.

think-first reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 2
  • API methods referenced: 2
  • Access from classified calls: L2, writes or runs: sets env vars, reads env vars
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
