live-viewer

A Claude Code mod in moneycode11101-svg/claude-code-live-viewer

Watch Claude's tool calls live in a side-pane tab: Write, Edit and Bash as boxes with streaming code and diffs, other tools as one line, thinking, answers and the todo list.
