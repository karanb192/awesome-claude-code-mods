clawd

A Claude Code mod in smhasan-yad/claude-mod-clawd

Claude Code's pixel mascot, animated with the desktop app's own frames, at the right of the Mod Bar toolbar: it looks around while idle, thinks, and types at a laptop or computer while Claude edits or runs commands, with the current step and elapsed time beside it. Watches tool calls only: no tokens.

clawd reaches L1 (reads) and passed claude plugin validate with warnings on Claude Code 2.1.310.
