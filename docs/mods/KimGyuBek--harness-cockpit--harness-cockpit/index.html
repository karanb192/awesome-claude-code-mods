harness-cockpit

A Claude Code mod in KimGyuBek/harness-cockpit

A Claude Code mod that puts a live status band above the prompt: progress steps, context and rate-limit usage, subagents, a sun-arc clock with an end-of-day countdown, and Clawd. 프롬프트 위 띠에 진행 단계 · 사용량 · 서브에이전트 · 시간 · Clawd 를 보여 주는 보기 전용 mod.

harness-cockpit reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 16
  • API methods referenced: 24
  • Access from classified calls: L3, network: MCP servers, runs processes, writes files, drives Claude, reads files, reads env vars, persists state, draws
  • Static scan, not a runtime test
