modkit

A Claude Code mod in Orfila-antoine/claude-mods

A kit for Claude Code mods: an ordered middleware pipeline, terminal layers and smooth transitions; this plugin is its runnable example

modkit reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.316.

  • Events hooked: 6
  • API methods referenced: 16
  • Access from classified calls: L1, reads: writes the prompt box, reads the prompt box, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
