session-meter

A Claude Code mod in verastack-labs/session-meter

Shows your usage-limit windows, context fullness and session totals in a pane and the status line, with warnings before you hit a limit.

session-meter reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.312.

  • API methods referenced: 12
  • Access from classified calls: L1, reads: reads mod state, draws
