blast-radius

A Claude Code mod in navin0812/claude-mods

Holds destructive Bash calls (rm -rf, git reset --hard, git clean, force push, migrations) and shows the files affected in a pane until you Proceed or Cancel.

blast-radius reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.310.
