vault

A Claude Code mod in yocloud-code/claude-vault

Credential vault for Claude Code: macOS Keychain secrets, per-directory grants, injected env, redacted output, pane with import/export

vault reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.304.

  • Events hooked: 5
  • API methods referenced: 24
  • Access from classified calls: L2, writes or runs: runs processes, writes files, drives Claude, writes the clipboard, reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
