readable-width

A Claude Code mod in Tvrtk0/claude-code-mods

Caps reply and prompt text at 80 columns while code blocks and tables keep the full width, and highlights your own prompts.

readable-width reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.316.

  • Events hooked: 1
  • API methods referenced: 1
  • Access from classified calls: L0, draws and remembers: draws
  • Static scan, not a runtime test

Install hint

/plugin install readable-width --marketplace Tvrtk0/claude-code-mods
