cache-warmer

A Claude Code mod in paulbkim-dev/claude-code-cache-warmer

Keep the main conversation's prompt cache warm by automatically forking its last request, tools denied and billed like any request, shortly before the cache expires; switch its lifetime between 5m and 1h, and show each refresh's cost and estimated saving.

cache-warmer reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
