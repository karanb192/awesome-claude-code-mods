handoff

A Claude Code mod in Recokioshi/claude-kit

Hand work to another session or repo without copy-paste: /handoff writes a note from facts it gathers itself (branch, commits, PRs, worklog) plus a six-section narrative from a fork of the conversation, saves it under ~/.claude/handoffs, copies it, and /handoff pick inserts it in the other session; a waiting note for this repo shows as a toast.

Access

L2 Writes or runsother: $.state.get, other: $.state.set, runs processes, writes files, drives Claude, writes the prompt box, reads files, reads env vars, reads the transcript, persists state, draws

Validation

Passed on Claude Code 2.1.301
