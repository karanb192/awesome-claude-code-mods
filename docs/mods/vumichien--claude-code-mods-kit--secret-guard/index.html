secret-guard

A Claude Code mod in vumichien/claude-code-mods-kit

Hides secrets in tool results before Claude reads them: the secret values of every .env and .env.* from your session's folder up to the drive root, and anything that looks like a secret (KEY=VALUE under a secret name, passwords in URLs, private keys, JWTs, AWS keys, Kubernetes Secrets); tells Claude how to use them without printing them

secret-guard reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 6
  • API methods referenced: 10
  • Access from classified calls: L1, reads: reads files, reads env vars, persists state, draws
  • Static scan, not a runtime test

Install hint

/plugin install secret-guard --marketplace vumichien/claude-code-mods-kit
