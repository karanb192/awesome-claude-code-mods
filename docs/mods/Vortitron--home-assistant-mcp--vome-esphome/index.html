vome-esphome

A Claude Code mod in Vortitron/home-assistant-mcp

A side pane for ESPHome in Claude Code: a map of the device from its YAML (board, network, buses, entities, pins, triggers) with what a save changed lit up, and the build Claude is running as it happens (phase, progress, the latest output, the result), over a dot-matrix chip on the bench. Needs @vortitron/home-assistant-mcp with esphome_activity.
