crab-buddy

A Claude Code mod in ziedgithub/claude-code-mods

A pixel-art Claude crab above the prompt that works, thinks, cheers and sleeps with the session, with a small crab for each subagent, dressed for its kind of work

crab-buddy reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.310.
