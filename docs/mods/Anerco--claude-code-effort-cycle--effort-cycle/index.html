effort-cycle

A Claude Code mod in Anerco/claude-code-effort-cycle

Change Claude Code's effort level per agent: Ctrl+↑ and Ctrl+↓ step the main thread or the subagent in view, shown as a colored meter in the footer (‹ › to click on hover) and in the tasks list's subagent rows
