no-shell-edits

A Claude Code mod in Jvrd97/claude-no-shell-edits

Stop Claude from editing files through Bash (sed -i, heredocs, echo >, tee, python -c) and point it to Edit/Write, so every change shows as a diff and /rewind can undo it.

no-shell-edits reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 3
  • API methods referenced: 9
  • Access from classified calls: L1, reads: reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
