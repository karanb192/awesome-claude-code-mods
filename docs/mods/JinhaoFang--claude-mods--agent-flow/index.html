agent-flow

A Claude Code mod in JinhaoFang/claude-mods

The agent flow pane: /flow opens a live tree of the session's subagents and teammates beside the transcript, fed by engine events, with a text fallback where no pane can be drawn.

agent-flow reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 10
  • API methods referenced: 14
  • Access from classified calls: L0, draws and remembers: persists state, draws
  • Static scan, not a runtime test
