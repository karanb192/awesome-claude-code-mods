baton

A Claude Code mod in hal-9/claude-mods

Context budget guard and handoff relay: measures real context use per model request, stops subagents that run too long or too big, and hands work over to a fresh session before the main agent drowns.

baton reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 9
  • API methods referenced: 16
  • Access from classified calls: L2, writes or runs: drives Claude, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
