notify

A Claude Code mod in StanislavKozachenko/claude-mods

Notifications that say what happened: a long turn finished (with its answer), a permission prompt or a question waiting, an Actions budget running low; on the desktop and, through Claude Code push, on your phone

notify reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 9
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, reads env vars, plays audio, persists state
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
