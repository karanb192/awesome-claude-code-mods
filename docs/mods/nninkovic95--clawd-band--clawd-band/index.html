clawd-band

A Claude Code mod in nninkovic95/clawd-band

A band above the prompt: an animated Clawd sprite, five-hour and weekly usage bars with a countdown to each window's reset, and a context-window bar with a countdown until the prompt cache goes cold

clawd-band reaches L3 (network) and passed claude plugin validate.
