agent-pane

A Claude Code mod in simota/claude-mods

Live pane of the session's subagents: running ones with elapsed time, finished ones with result and duration

agent-pane reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.319.

  • Events hooked: 4
  • API methods referenced: 9
  • Access from classified calls: L1, reads: reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install agent-pane --marketplace simota/claude-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
