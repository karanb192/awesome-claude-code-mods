clauget

A Claude Code mod in devohmycode/claude-mods

The scale, then the diet: and the diet only where the scale says it pays. Each model request inside a turn streams through one hook, whose stop chunk carries the four token counters and the model that answered, so the journal has a line per step, the main loop's and every subagent's apart, and names the cache misses where they happen. /clauget opens the report: the window and the cost, the bill of the prefix by provider with how often each provider's tools were called, the break-even of deferring, the instruction files, and every lever with what it saved and what it cost. Out of the box the mod measures and changes nothing. /clauget on, off or strict turns the levers on from the next session: a policy on the prefix decided once and never moved mid-session, tool results cut to the shape of their fat and filed whole so one Read undoes a cut, a small-prefix explorer agent, a lighter transcript for the compaction, economy tiers that tighten with the plan window, a forecast of when it fills, and prompts deferred to its reset. Each lever was measured on a real session; the ones that lost were closed and are named in the README. Nothing the mod writes reaches the model unless a lever puts it there, and then it is counted in the mod's own column.
