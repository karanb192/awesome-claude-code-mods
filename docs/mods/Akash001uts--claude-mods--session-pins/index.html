session-pins

A Claude Code mod in Akash001uts/claude-mods

Pin notes to a session: /pin keeps them on show above the prompt and in Claude's system prompt, so they hold through compaction and come back on resume

In its last recorded footprint, session-pins reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.312.
