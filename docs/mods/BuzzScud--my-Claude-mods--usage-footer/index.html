usage-footer

A Claude Code mod in BuzzScud/my-Claude-mods

One row in the footer: the context and your usage limits (5-hour, week, a model's own week) as mini bars that shrink together as the window narrows, all four kept down to a 120-column window. /limits on | off.

usage-footer reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 6
  • API methods referenced: 12
  • Access from classified calls: L2, writes or runs: runs processes, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
