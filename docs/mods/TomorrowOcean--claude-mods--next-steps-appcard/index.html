next-steps-appcard

A Claude Code mod in TomorrowOcean/claude-mods

After each turn, suggests up to three next prompts in a card above the input: a What next? title row with a collapse toggle and a close button, and a small card per suggestion. Click a suggestion's label to put its prompt in the input box as a draft you can edit. Starts collapsed.
