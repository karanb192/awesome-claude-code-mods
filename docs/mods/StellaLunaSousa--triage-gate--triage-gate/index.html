triage-gate

A Claude Code mod in StellaLunaSousa/triage-gate

Triages each message with a small model before the main model runs, and asks (native modal) whether to switch model/effort when another one fits better and the switch pays off.

triage-gate reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 6
  • API methods referenced: 18
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, reads settings, reads the transcript, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
