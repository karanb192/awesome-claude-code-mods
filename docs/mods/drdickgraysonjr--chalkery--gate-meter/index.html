gate-meter

A Claude Code mod in drdickgraysonjr/chalkery

Progress of the /unlazy gates bound to this session, one quiet row above the prompt: cells per gate or a pie, met of total, and its state: waiting for a decision, regressed, paused, abandoned, all met. /gates lists them all. Joins handoff-relay, cache-meter and next-steps in one band.

gate-meter reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
