session-telemetry

A Claude Code mod in Covre81/claude-code-mods

Displays timestamp on each response and notices on screen when the responding model switches (including jev-router)

session-telemetry reaches L3 (network) and passed claude plugin validate.

  • Events hooked: 4
  • API methods referenced: 11
  • Access from classified calls: L3, network: network, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
