clock-guard

A Claude Code mod in nekyialabs/claude-code-toolkit

Companion to the clock mod: drops a clock wake that arrives twice for the same firing, which can happen when Claude Code replaces a lost hooks worker and replays a timer's prompt submit. Guard by Ray and Starling.

clock-guard reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 1
  • API methods referenced: 2
  • Access from classified calls: L0, draws and remembers: persists state
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
