pomodoro

A Claude Code mod in sneycampos/claude-pomodoro

Button-first Pomodoro timer above the Claude Code prompt: one-click focus blocks, a live countdown band, break reminders and a config pane.

pomodoro reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 5
  • API methods referenced: 17
  • Access from classified calls: L1, reads: reads mod state, plays audio, persists state, draws
