enhance-prompt

A Claude Code mod in nalpari/claude-mods

Rewrites each prompt so the AI understands it better, shows it above the prompt box, and sends the rewrite only if you allow it

enhance-prompt reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
