turn-stats

A Claude Code mod in StanislavKozachenko/claude-mods

Adds what a turn did to its 'Worked for' line: tool calls by tool, failures, files changed and cost

turn-stats reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 6
  • API methods referenced: 6
  • Access from classified calls: L1, reads: reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
