openai-models

A Claude Code mod in grvermeulen/claude-mods

OpenAI models in Claude Code on your ChatGPT plan: Sign in with ChatGPT, /gpt picker lists them in the /model picker, and the one you pick answers the session's turns with Claude Code's core tools. Experimental.
