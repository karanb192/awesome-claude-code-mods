turn-receipt

A Claude Code mod in yoshihiko555/dotfiles

Keeps a per-turn tally of edits, runs, curls and destructive commands and shows it on the turn footer; any non-read-only Bash counts as a run, a claim (English or Japanese) with no run flags the spinner, a destructive Bash unfolds its tool group, and an edit-without-run turn suggests running the tests.
