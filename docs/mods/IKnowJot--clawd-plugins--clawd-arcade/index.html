clawd-arcade

A Claude Code mod in IKnowJot/clawd-plugins

Clawd-themed games in a side pane while Claude works. Pauses when Claude needs you and tells you when Claude is done.

clawd-arcade reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 8
  • API methods referenced: 9
  • Access from classified calls: L1, reads: reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
