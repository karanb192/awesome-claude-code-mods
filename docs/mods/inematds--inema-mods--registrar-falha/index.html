registrar-falha

A Claude Code mod in inematds/inema-mods

Quando comandos falham no turno, mostra botão que escreve no prompt o pedido de registrar a falha no FALHAS.md (/falha)

registrar-falha reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 5
  • API methods referenced: 7
  • Access from classified calls: L1, reads: writes the prompt box, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
