recording-mode

A Claude Code mod in nateherkai/claude-code-mods

/rec before you record: masks keys, personal details, and business figures on screen and keeps private files closed (/rec strict, /rec off, /rec config)

recording-mode reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
