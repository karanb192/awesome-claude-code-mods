run-lot-pane

A Claude Code mod in pierrebelin/claude-code-toolkit

Side pane following a run-lot run, or a run-plan run with a plan view and navigation between its batches: phases as columns, agents (model, duration, tokens per agent, slowness, stalls, retries, interruptions), estimated end, batch sheet, audit verdict and rounds, run outcome with the knowledge-base merge a plan staged, end toast; steers the run: entries to validate, notes, dependency graph

run-lot-pane reaches L2 (writes or runs) and passed claude plugin validate with warnings.

  • Events hooked: 7
  • API methods referenced: 18
  • Access from classified calls: L2, writes or runs: writes files, writes the clipboard, reads files, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
