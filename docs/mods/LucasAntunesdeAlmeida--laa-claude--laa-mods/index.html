laa-mods

A Claude Code mod in LucasAntunesdeAlmeida/laa-claude

Mods for the laa toolkit: blocks file changes and commits on the default branch, tracks the running laa pipeline above the prompt and in the footer, /laa-help, panes to triage learnings and review findings, and next-step suggestions.

Access
