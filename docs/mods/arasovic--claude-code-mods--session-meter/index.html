session-meter

A Claude Code mod in arasovic/claude-code-mods

Shows a live session pane (/ctx): context breakdown, usage limits with pace, tool calls and model requests; sends the model a one-time note when limits or context cross a threshold, and can let the model compact or clear on its own

session-meter reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 9
  • API methods referenced: 17
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install session-meter --marketplace arasovic/claude-code-mods
