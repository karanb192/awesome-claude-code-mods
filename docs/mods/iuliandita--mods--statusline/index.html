statusline

A Claude Code mod in iuliandita/mods

A two-row status line in the band above the prompt, in the terminal and in Claude Desktop: model and effort, worktree, branch and counts, lines changed, kube context, PR and issue counts, session name and output style; then context, 5h and 7d rate-limit bars with pace, cache, cost and time. No statusLine script. In a git repo with a GitHub or GitLab remote it runs gh or glab for the PR and issue counts (forge option, on by default).

statusline reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.316.
