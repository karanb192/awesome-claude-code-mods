agent-ctx

A Claude Code mod in Tekkiiiii/the-agency

Each agent loop's own context fill, measured per request; a one-line CONTEXT_PCT_ALERT rides that agent's next tool result. Subagents: absolute 200k warn / 250k finish / 300k stop (stop line on every result); main: 70/75/80% of its window. Controllers get CHILD_CTX on Agent and SendMessage results and CHILD_CTX_ALERT when a live child passes 250k/300k

agent-ctx reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 2
  • API methods referenced: 6
  • Access from classified calls: L1, reads: reads files, reads env vars, reads mod state
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
