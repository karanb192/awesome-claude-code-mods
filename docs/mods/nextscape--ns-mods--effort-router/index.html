effort-router

A Claude Code mod in nextscape/ns-mods

Picks low/medium/high/xhigh effort per prompt for Opus/Sonnet/Haiku 5.5+ and Fable/Mythos 5.1+ by how uncertain and costly the work is, raising it mid-turn when a turn runs long; a typed /effort applies at once

Access

L2 Writes or runsother: $.state.get, other: $.state.set, drives Claude, reads settings, persists state, draws
