token-watch

A Claude Code mod in nevermemo/token-watch

Plan usage (5-hour, weekly and any model window) and the context window as thin bars above the prompt. Right-click to collapse to one line; /context-bar to hide, or to read it as text where nothing draws.

token-watch reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 5
  • API methods referenced: 15
  • Access from classified calls: L2, writes or runs: writes files, reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
