clef-gate

A Claude Code mod in dwain-barnes/clef-gate

Asks a local Clef decision model whether an expensive tool call or subagent is actually needed before Claude Code pays for it. Logs every decision; shadow mode by default.

clef-gate reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 16
  • Access from classified calls: L3, network: network, writes files, reads files, reads env vars, reads the transcript, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
