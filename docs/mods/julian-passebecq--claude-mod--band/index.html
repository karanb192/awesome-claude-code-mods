band

A Claude Code mod in julian-passebecq/claude-mod

Jauge : bandeau au-dessus du prompt, en lecture seule, sur UNE ligne ajustée à la largeur (libellés courts puis champs retirés dans l'ordre de jauge.drop_order) : « ◆ 2 │ ctx ▰▰▱▱▱ 19 % │ 5 h ▱▱▱▱▱ 0 % │ sem ▰▰▰▰▱ 74 % │ 4.4k tok/s » (◆ N orange, masqué à 0 ; mini-barres ▰▱ au terminal, fines Svg sur le bureau ; feu vert / orange / rouge sur la barre et le % selon jauge.levels), puis exactement cinq boutons (Julian, 17 oct) : Usage (le /usage intégré, sinon /conso du mod usage) · Règles (/reference config) · Réf (/reference guide) · Cockpit (/cockpit) · Exporter (/export-tout, puis « dernier export HH:MM »). Au-delà du seuil RESUME, un court « relais conseillé » et un bouton RESUME (/handoff) rejoignent la ligne. Seulement quand quelque chose tourne dans cette conversation, des lignes « en cours » sous la ligne (◇ Workflow ▰▰▱▱▱ 2/5 · ▸ phase · agents · durée · fin ~HH:MM, vert / orange 15 min sans écriture / rouge 30 min ou échec, noms coupés d'abord quand c'est trop large, • ses agents, ◦ agents d'arrière-plan ; jauge.en_cours_rows au plus). Rien d'autre au-dessus du prompt (jauge.others_above_prompt: show remet les lignes des autres mods). Champs, boutons et libellés dans band.config.json (jauge, launcher) ; launcher.preset hubs ou all et gauge.style compact gardent les anciennes vues. /jauge ouvre le détail. Boutons « Export conv » et « Export + enfants +N » (export_brief) : un brief Markdown masqué pour une autre IA, copié dans le presse-papiers (exporter/brief.mjs du mod export-eta).
