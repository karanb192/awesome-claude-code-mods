noctis

A Claude Code mod in synex1437/noctis

Runs long Claude Code jobs overnight within your usage limits: pauses just before the 5-hour or weekly limit, resumes the same session after the reset (or relaunches it days later) and works through a list of jobs you hand it with /noctis:start <file>. Also runs in Codex CLI, Antigravity CLI, Droid and Copilot CLI.

noctis reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • API methods referenced: 10
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, reads files, reads env vars, reads settings, draws
