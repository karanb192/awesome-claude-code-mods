retry-analyzer

A Claude Code mod in oleksandrkodua/qa-mods

Detects Claude repeating the same failing tool call (3+ identical failures, or 4+ with the same error) and tells it to change strategy and tell the user. Never blocks.

The validator reported no API methods for retry-analyzer; it passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 2
  • API methods referenced: 0
  • Access: no API methods recorded
  • Static scan, not a runtime test

Install hint

/plugin install retry-analyzer --marketplace oleksandrkodua/qa-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
