blast-radius

A Claude Code mod in oleksandrkodua/qa-mods

Before a risky Bash command runs, says what it will touch. A plain deletion is judged by git: files outside git or tracked and clean get only a short label, a Ukrainian dialog (with the rm line, the number of files and a typed 'Other' decision) is for uncommitted changes, the home folder, more than 20 files and other hard risks. Static analysis plus read-only git, nothing is executed to preview.

blast-radius reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 3
  • API methods referenced: 5
  • Access from classified calls: L2, writes or runs: runs processes, reads env vars, draws
