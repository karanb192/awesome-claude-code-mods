ask

A Claude Code mod in hyperbola-bear/claude-mods

A side chat in a pane that reads the main chat, scrolls and draws: /ask a question, /draw a diagram. Nothing goes back to the main chat unless you send it. Answers are Mermaid drawn as box art in the terminal and as SVG in the desktop app.
