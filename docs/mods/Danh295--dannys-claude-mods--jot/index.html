jot

A Claude Code mod in Danh295/dannys-claude-mods

A notes pane: jot text during a session, keep it across sessions, arrow to a note and press Enter to paste it into the prompt.

jot reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.
