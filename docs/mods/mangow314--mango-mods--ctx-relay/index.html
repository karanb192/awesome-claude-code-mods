ctx-relay

A Claude Code mod in mangow314/mango-mods

A band above the prompt with context size, per-turn cost and the prompt-cache countdown. Past the handoff line it counts down 60 s, writes a handoff file with a fork, runs /clear and resumes in the new conversation; a new conversation lists unclaimed handoff files, press 1 to resume.

Access

L2 Writes or runsother: $.state.get, other: $.state.set, runs processes, writes files, drives Claude, reads files, reads env vars, reads settings, reads the transcript, persists state, draws
