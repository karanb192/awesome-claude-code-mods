task-steps

A Claude Code mod in moonteek/claude-mods

Shows the steps Claude plans for your task, and its progress through them, above the prompt.

task-steps reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 4
  • Access from classified calls: L2, writes or runs: drives Claude, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install task-steps --marketplace moonteek/claude-mods
