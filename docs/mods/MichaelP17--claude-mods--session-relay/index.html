session-relay

A Claude Code mod in MichaelP17/claude-mods

Passes prompts from a planning session to the session that does the work and its answers back, without copy and paste

session-relay reaches L2 (writes or runs) by its classified calls and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 9
  • API methods referenced: 25
  • Access from classified calls: L2, writes or runs: runs processes, writes files, drives Claude, reads files, reads env vars, reads the transcript, reads mod state, persists state, draws
  • Calls in a namespace that is not in the Claude Code 2.1.302 core table: 1 ($.hub.set), full access unknown
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
