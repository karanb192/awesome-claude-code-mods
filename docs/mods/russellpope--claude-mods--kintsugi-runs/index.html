kintsugi-runs

A Claude Code mod in russellpope/claude-mods

Pane of this repo's kintsugi verification runs: the stage pipeline, each stage's exit and time, and a timing bar. /kintsugi-runs toggles it.

kintsugi-runs reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 3
  • API methods referenced: 12
  • Access from classified calls: L2, writes or runs: runs processes, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
