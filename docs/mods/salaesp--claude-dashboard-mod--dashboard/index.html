dashboard

A Claude Code mod in salaesp/claude-dashboard-mod

macOS-style dashboard above the prompt: the context window as a segmented capsule, the session's goals with progress bars, the main loop and its subagents with a Clawd pose for each state, and what needs your attention; /dashboard opens the full panel

dashboard reaches L2 (writes or runs) and passed claude plugin validate with warnings.
