headroom

A Claude Code mod in MWEJ/claude-code-headroom

Your Claude plan limits, a forecast of when you'll run out, and your context window, live in a band above the prompt. Compacts in one click, automatically, or when Claude picks the moment, and keeps the prompt cache warm

The scan could not record a complete footprint for headroom, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.310.
