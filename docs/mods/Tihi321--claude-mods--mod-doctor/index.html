mod-doctor

A Claude Code mod in Tihi321/claude-mods

/mod-doctor checks every installed mod in one report: hook scripts, plugin mods loaded, Node, Claude Code version, errors and ESLint timings in the mods log.

mod-doctor reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
