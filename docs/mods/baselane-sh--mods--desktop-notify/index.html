desktop-notify

A Claude Code mod in baselane-sh/mods

Shows a desktop notification when Claude Code needs your input: osascript on macOS, notify-send elsewhere when it is installed. The text is the project name and a short status only.

desktop-notify reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 1
  • API methods referenced: 2
  • Access from classified calls: L2, writes or runs: runs processes, draws
  • Static scan, not a runtime test

Install hint

/plugin install desktop-notify --marketplace baselane-sh/mods
