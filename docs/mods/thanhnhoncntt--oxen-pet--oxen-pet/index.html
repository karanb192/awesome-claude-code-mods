oxen-pet

A Claude Code mod in thanhnhoncntt/oxen-pet

A pixel Luffy above the Claude Code prompt who acts out each tool call in five gears, an HP/MP/ST HUD for context, rate limits, and prompt cache, a shield that asks before destructive commands, a bug boss for failing tests, and a /pet stats pane. Your own pets live in a folder updates never touch.

oxen-pet reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
