g-line

A Claude Code mod in lifeofgurpreet/g-line

Live status under Claude Code's prompt, and receipts on the turns themselves: context jumps, cache rebuilds and tool failures marked on the turn's own closing line; model, effort, cache countdown and usage pace on the hint line plus one coloured row; heads-up notifications before the cache goes cold; a local dashboard of usage, sessions and history. A mod: no transcript parsing.

The scan could not record a complete footprint for g-line, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.316.

  • Access: unknown, the footprint is incomplete
