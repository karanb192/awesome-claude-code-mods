aleph-zero

A Claude Code mod in mustafarslan/aleph-zero

Local code search for coding agents: ranked code locations by meaning or by name, always matching the working tree, and steering that makes Claude Code use it before recursive grep

aleph-zero reaches L3 (network) and passed claude plugin validate.
