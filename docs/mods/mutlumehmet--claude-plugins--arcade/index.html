arcade

A Claude Code mod in mutlumehmet/claude-plugins

The Claude Code Arcade: pixel games above the prompt, played by your work (an invading octopus, a duck hunt, Bug Command, which you can play along with, Dario, a block town your agents build, a dragon, a slot machine, an Outlaw duel, a Tamagotchi and Tetris). Starts with Octo Invader; the buttons under the game and /arcade switch games and set your default.

Access

L3 Uses the networkother: $.state.get, other: $.state.set, network, runs processes, writes the prompt box, reads files, persists state, draws
