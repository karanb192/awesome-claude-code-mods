context-band

A Claude Code mod in mgstegmaier/claude-plugins

A card above the prompt in the desktop app and the terminal: how full the context window is, what fills it, and what the session has cost, in Anthropic's palette.

context-band reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.
