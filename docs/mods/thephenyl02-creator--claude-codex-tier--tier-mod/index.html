tier-mod

A Claude Code mod in thephenyl02-creator/claude-codex-tier

Tier: the main session manages, helpers do the work. Every hand-off names a model and an effort (max/Fable only after an opus/xhigh failure of that task); web work, big reads and multi-file edits go to tier-mod:reader / tier-mod:editor; a ledger records what each hand-off cost, its check's exit code, and what it saved.
