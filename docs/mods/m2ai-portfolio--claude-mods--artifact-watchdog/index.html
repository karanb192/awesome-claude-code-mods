artifact-watchdog

A Claude Code mod in m2ai-portfolio/claude-mods

Enforces the subagent output contract: watches each Agent dispatch's artifact file, flags a 5-minute stall, wakes an idle Claude once per stall, offers a Stop button

artifact-watchdog reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.310.

  • Events hooked: 7
  • API methods referenced: 18
  • Access from classified calls: L2, writes or runs: drives Claude, reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
