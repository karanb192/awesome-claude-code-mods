cockpit

A Claude Code mod in devohmycode/claude-mods

One pane of tabs beside the transcript, and the $.cockpit noun other plugins fill. /cockpit opens it, and so does the Cockpit button in the band above the prompt: Session reads the context window, the turn count, the model and the cost, with a Raster sparkline of the context the session has spent turn by turn; Usage draws what the session cost: the four token counters the API reports, kept apart by whether the main loop or a subagent spent them, the models that answered, the plan windows as bars with what is left of each, and what every plugin's skill listing adds to the system prompt each turn; Stats reads ~/.claude/history.jsonl for the prompts this machine has typed: a contribution calendar, sessions, projects, active days and streaks, counted as prompts and never as tokens; Files lists what Claude read and wrote: file tools and shell commands alike: heaviest first, with the lines each file moved and the letter git gives it now, each row a button that rides the file on the next prompt and says so once it has; Tools tallies every tool call with its time and its failures, MCP tools by their server and their own name rather than the prefix they all share, and lists the last of them; Agents is the session's record of every subagent it started, each under the one that spawned it, with how long it ran and the status it ended on. A plugin adds its own tab in three lines through $.cockpit.tab, and the cockpit owns the pane, the rail, the hotkeys and the focus; hideTabs leaves any of them off the rail, a plugin’s as readily as a built-in one.
