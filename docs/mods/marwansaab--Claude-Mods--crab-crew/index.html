crab-crew

A Claude Code mod in marwansaab/Claude-Mods

A crew panel for standard subagents (/crew): each agent type is a crab character with its own role, look and lines, animated by its status and progress.

crab-crew reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 9
  • Access from classified calls: L1, reads: reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
