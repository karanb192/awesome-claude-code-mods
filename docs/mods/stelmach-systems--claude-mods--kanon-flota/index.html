kanon-flota

A Claude Code mod in stelmach-systems/claude-mods

Pane „flota sesji”: wszystkie żywe sesje Claude Code na tym Macu z `claude agents --json` (stan z czasem, projekt, nazwa), ctx %, koszt i liczniki wiadomości między sesjami dla sesji z modem ($.store), ping do wybranej sesji. /flota. Zero modelu, zero sieci, zero treści w store.

kanon-flota reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 21
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
