model-picker

A Claude Code mod in juampymdd/claude-code-model-picker

A band above the prompt to pick which model, and which version of it, runs the next requests, with cost, tokens and cache stats an animated pane of charts and live agents for the whole session, and a tab where Claude notes the theory behind what it builds.

model-picker reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • API methods referenced: 22
  • Access from classified calls: L3, network: network, runs processes, drives Claude, reads files, reads mod state, persists state, draws
