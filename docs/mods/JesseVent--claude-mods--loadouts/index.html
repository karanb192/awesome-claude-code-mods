loadouts

A Claude Code mod in JesseVent/claude-mods

Requip for Claude Code: named loadouts of skills, MCP servers and instructions, one equipped per project from the /loadout picker or by Claude itself, the rest switched off. Switching never needs a restart.

loadouts reaches L2 (writes or runs) and passed claude plugin validate.

  • Events hooked: 8
  • API methods referenced: 18
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, reads files, persists state, draws
  • Static scan, not a runtime test

Install hint

/plugin install loadouts --marketplace JesseVent/claude-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
