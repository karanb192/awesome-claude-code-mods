mcp-squeeze

A Claude Code mod in Darvl-52/mcp-squeeze

Squeezes what the MCP tools return before the model reads it: a block, an image or a long token returned again left out, from any server; for Figma, metadata as an outline, an instance whose inside is its component's told in a line, repeated classes declared once, float noise rounded; for Chrome DevTools, a state said once, a snapshot's URLs in letters and a snapshot told by its changes; /squeeze-gain says the tokens saved.

mcp-squeeze reaches L1 (reads) and passed claude plugin validate with warnings.
