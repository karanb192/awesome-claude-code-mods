token-weather-cache

A Claude Code mod in youllook/ClaudeMods

Context, prompt-cache countdown and plan usage above the prompt: four SVG rings on desktop, fill glyphs in the terminal, with expiry toasts. Modified from Anthropic's token-weather example.

token-weather-cache reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.
