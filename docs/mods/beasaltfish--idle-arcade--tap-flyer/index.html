tap-flyer

A Claude Code mod in beasaltfish/idle-arcade

An original tap-to-fly game for Claude Code. Thread your ember through gaps in scrolling pillars. Pauses when Claude finishes; Claude's tool calls drop glowing coins.

tap-flyer reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.319.
