claudetto-browser

A Claude Code mod in xsyetopz/dotclaude

Drives a browser with `agent-browser`, or with CloakBrowser on sites with bot detection when the user chooses it. With the `cloakbrowser` backend, answers each `WebSearch` call that the permission rules allow with a search in CloakBrowser, and needs its binary.

claudetto-browser reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 1
  • API methods referenced: 6
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads env vars, draws
  • Static scan, not a runtime test

Install hint

/plugin install claudetto-browser --marketplace xsyetopz/dotclaude
