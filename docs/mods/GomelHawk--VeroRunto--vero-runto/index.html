vero-runto

A Claude Code mod in GomelHawk/VeroRunto

Click. Run. Done. [ Copy ] and [ Run ] after every ! command in Claude's replies: Run asks first, runs it through Claude Code's Bash tool under your permission rules, and hands the output to Claude.

vero-runto reaches L2 (writes or runs) and passed claude plugin validate with warnings.

  • Events hooked: 5
  • API methods referenced: 16
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, writes the clipboard, reads env vars, reads settings, reads the prompt box, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
