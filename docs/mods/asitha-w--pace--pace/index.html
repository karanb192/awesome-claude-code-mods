pace

A Claude Code mod in asitha-w/pace

Shows when a session gets heavy or its prompt cache is about to go cold, and parks a session so the next one can resume it

pace reaches L2 (writes or runs) by its classified calls and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 9
  • API methods referenced: 30
  • Access from classified calls: L2, writes or runs: runs processes, writes files, drives Claude, writes the prompt box, reads files, reads env vars, reads the transcript, reads mod state, persists state, draws
  • Calls in a namespace that is not in the Claude Code 2.1.302 core table: 4 ($.pace.now, $.pace.park, $.pace.signal, $.pace.targets), full access unknown
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
