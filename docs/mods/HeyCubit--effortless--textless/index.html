textless

A Claude Code mod in HeyCubit/effortless

While Claude works, the chat shows one tall pixel-art card of Clawd instead of every step. Its buttons sit on the card, which minimizes to one line, and under the newest answer; /textless toggles it too.

The scan could not record a complete footprint for textless, so its access is unknown; it passed claude plugin validate with warnings on Claude Code 2.1.304.
