cache-tax

A Claude Code mod in karanb192/cache-tax

A Claude Code mod that keeps the one-hour prompt cache warm during breaks and stops a cold send once with its estimated rewrite cost. Warming uses model requests and costs tokens. Requires Claude Code 2.1.287+.

cache-tax reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 10
  • API methods referenced: 17
  • Access from classified calls: L2, writes or runs: drives Claude, reads env vars, reads settings, persists state, draws
  • Static scan, not a runtime test
