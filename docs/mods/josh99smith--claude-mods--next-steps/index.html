next-steps

A Claude Code mod in josh99smith/claude-mods

Suggests next steps after every prompt and keeps them in a to-do list by category, in a panel you can click (/todo) or drive with commands.

next-steps reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 5
  • API methods referenced: 13
  • Access from classified calls: L2, writes or runs: drives Claude, reads files, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
