timestamps

A Claude Code mod in AraneaDev/claude-timestamp

Time awareness for coding agents, in Claude Code and Codex: in Claude Code, stamps every message with the local time and how long the turn took; in both, tells the agent when a turn runs long, a tool call is slow or work resumes after a gap, remembers how long each command usually takes in a project, and reports where a session's time went.

timestamps reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 7
  • API methods referenced: 10
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
