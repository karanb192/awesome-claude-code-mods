skill-pick

A Claude Code mod in iuliandita/mods

Names the 1 to 5 installed skills that fit each prompt, as many as the ask needs, with a small model and, when TYPESAFE_API_KEY is set, a Jev score per skill; the log shows how often the main model then loads one. Default mode dry only measures. With a key set, the prompt and skill descriptions go to api.typesafe.ai (Jev) from every directory unless jevPaths limits it.

In its last recorded footprint, skill-pick reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.312.
