tower

A Claude Code mod in alaturqua/tower-mods

A web cockpit and a /tower pane over every Claude Code agent across your repos: see who needs you, approve and answer, send prompts and slash commands, start workstreams in git worktrees, and watch changes and PRs. Plus desktop notifications and a status line.

Access
