stock-watch

A Claude Code mod in TroyJLorents-GH/mod-squad

/stock: watch tickers and get a chime when one reaches the low or high you set. Works any time, in any session.

stock-watch reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 16
  • Access from classified calls: L3, network: network, runs processes, reads env vars, reads mod state, plays audio, persists state, draws
