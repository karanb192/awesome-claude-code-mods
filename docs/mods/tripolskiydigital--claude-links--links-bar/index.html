links-bar

A Claude Code mod in tripolskiydigital/claude-links

A links bar above the prompt in Claude Desktop's Code tab: up to 4 pinned links per project or session with favicons, the session's 10 latest links, and a pane of every pinned link. Reads the session transcript; asks a link's own site for its page title and favicon (curl for PNG and ICO icons); opens links with open.
