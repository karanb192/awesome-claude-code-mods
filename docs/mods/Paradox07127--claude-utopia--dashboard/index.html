dashboard

A Claude Code mod in Paradox07127/claude-utopia

Unified workbench: a status band for subagents and mmrun reviews, plus a seven-page pane (Overview / Agents / Reviews / GPU / Timeline / Usage / Progress; Reviews, GPU and Progress show once they have data); the Progress page lists the per-project progress board, recorded after each typed turn that changed files or made a commit
