cache-meter

A Claude Code mod in hal-9/claude-mods

Band above the prompt: prompt-cache countdown, cache hit rate, context fill and a Compact button, plus a keepwarm row from cache-tax that pings the cache through breaks and stops a cold send once with its rewrite cost.

cache-meter reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 20
  • Access from classified calls: L2, writes or runs: drives Claude, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
