secret-redactor

A Claude Code mod in jidhra/claude-mods

Keeps secrets, email addresses and IP addresses out of the session transcript: swaps each one for a stable placeholder on the way in, and puts the real value back on the way into a tool call

secret-redactor reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 3
  • API methods referenced: 2
  • Access from classified calls: L0, draws and remembers: draws
  • Static scan, not a runtime test
