focus-timer

A Claude Code mod in Hula-Hoop-AI/supermods

A focus timer in the band above the prompt: /focus-timer starts a block, the band counts it down with pause, skip and stop buttons, a toast marks each switch, and every fourth break is a long one.

focus-timer reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • API methods referenced: 8
  • Access from classified calls: L1, reads: reads mod state, draws
