claudetto

A Claude Code mod in xsyetopz/claudetto

Trims Claude Code 2.1.329 to what beats vanilla: disables the bundled builtin plugins at load, hands over context at task boundaries, and keeps prompt caching warm.

claudetto reaches L3 (network) and passed claude plugin validate with warnings.

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
