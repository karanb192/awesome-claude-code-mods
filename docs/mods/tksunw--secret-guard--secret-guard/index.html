secret-guard

A Claude Code mod in tksunw/secret-guard

Blocks git commit and git push from Claude when the change carries a secret file or a credential-shaped line, and flags secret files that are not gitignored

secret-guard reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.304.
