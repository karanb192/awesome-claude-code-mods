internet-sources

A Claude Code mod in caique-lima/claude-mod-internet-sources

Side panel that tracks every web page Claude pulled into the session, grouped by domain, with token estimates and markdown export.

internet-sources reaches L2 (writes or runs) and passed claude plugin validate with warnings.
