secrets-veil

A Claude Code mod in yonatangross/orchestkit

Masks secret values in tool results before the model reads them: named vendor variables, value-shape patterns, and high-entropy tokens. No reveal path.

secrets-veil reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 2
  • API methods referenced: 8
  • Access from classified calls: L1, reads: writes the clipboard, reads env vars, draws
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
