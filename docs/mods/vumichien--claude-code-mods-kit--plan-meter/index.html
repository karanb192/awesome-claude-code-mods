plan-meter

A Claude Code mod in vumichien/claude-code-mods-kit

A band above the prompt with how far your plan file is (phases and steps done, what is in progress, what is next) and Claude's own task list, kept current as files change. Starts off: /plan-meter on turns it on

plan-meter reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 4
  • API methods referenced: 12
  • Access from classified calls: L1, reads: reads files, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
