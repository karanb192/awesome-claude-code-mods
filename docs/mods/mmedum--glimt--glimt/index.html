glimt

A Claude Code mod in mmedum/glimt

A quiet side pane: what this session is doing now, its plan, its agents as a tree, and every other Claude Code session with theirs

glimt reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, writes the clipboard, reads files, reads env vars, reads the transcript, reads mod state, persists state, draws
