needs-you

A Claude Code mod in ozlar34/claude-code-mods

CC Alerts: pings you (macOS banner + sound) when a session finishes a long turn or sits blocked on a dialog, only as loudly as needed given whether you're already looking. /ping controls quiet modes.

needs-you reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • API methods referenced: 18
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
