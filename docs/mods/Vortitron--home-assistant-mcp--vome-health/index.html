vome-health

A Claude Code mod in Vortitron/home-assistant-mcp

A side pane for your Home Assistant's health: Vome's score out of 100 and what its check found, by severity with what to do, marked as Claude works on each, then a re-check rolls the score to the new one. Needs @vortitron/home-assistant-mcp with vome_health_report and the Vome integration.

vome-health reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 4
  • API methods referenced: 15
  • Access from classified calls: L3, network: MCP servers, drives Claude, writes the clipboard, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
