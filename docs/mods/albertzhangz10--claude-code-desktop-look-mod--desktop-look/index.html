desktop-look

A Claude Code mod in albertzhangz10/claude-code-desktop-look-mod

Desktop look in terminal: restyles Claude Code to resemble the Claude desktop app, with a welcome stats card, chat bubbles, bullet-free replies, compact tool rows and a Changes sidebar

desktop-look reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 4
  • API methods referenced: 9
  • Access from classified calls: L1, reads: reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
