cc-split-diff-view

A Claude Code mod in neteye-platform/cc-split-diff-view

Draws Edit and Write diffs in two side-by-side columns: removed lines on the left, added lines on the right, in Claude Code's own diff colors. Adds /diffsplit, a pane that reviews all the uncommitted changes the same way
