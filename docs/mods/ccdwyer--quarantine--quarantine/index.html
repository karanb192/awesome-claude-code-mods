quarantine

A Claude Code mod in ccdwyer/quarantine

Wraps web, MCP and third-party tool output as untrusted data and defangs prompt-injection lines before the model reads them

quarantine reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 7
  • Access from classified calls: L1, reads: reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
