cache-timer

A Claude Code mod in Sanexxxx777/claude-cache-timer

A countdown in the prompt footer: under the hint line on the terminal, left of the model picker on the desktop: time left on the prompt cache and how much of the last request it served, or, when the cache was written again while it should have been warm, why (a model switch, an effort change); after a model switch, before anything is sent, what the other model will write. In Ghostty a big cache also raises a macOS notification before it expires and on a rebuild nobody asked for. Olive while there is plenty, warmer at 10, 5 and 2 minutes left (scaled down for a 5-minute cache). The lifetime follows Claude Code's own rules: 1 hour on a subscription, 5 minutes on an API key or usage credits.

cache-timer reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
