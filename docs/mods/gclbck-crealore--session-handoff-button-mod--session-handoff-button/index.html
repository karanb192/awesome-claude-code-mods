session-handoff-button

A Claude Code mod in gclbck-crealore/session-handoff-button-mod

A Session Hand-off button above the prompt, colored by context usage; reads Context clean and cannot be pressed while green. From orange on, one press writes the handoff, saves it to a temp .md, clears the session and continues in the fresh one with a short message while the handoff goes in as hidden context. Past 65% it stops your next prompt once and recommends the button.
