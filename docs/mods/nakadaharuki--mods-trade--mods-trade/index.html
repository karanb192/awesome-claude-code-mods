mods-trade

A Claude Code mod in nakadaharuki/mods-trade

トレード専用の Claude Code の画面一式。主役は「任せる」画面: Claude が Mod の中の道具で相場を巡回し、足を読み、Hyperliquid の値段で模擬口座（$10,000）を売買する。押すと（または C:dev rade のような任せるフォルダーで開くと）定時に Claude が起き、段の帯（相場 → 候補 → 足 → 判断 → 発注 → 記録）・Claude の思考がそのまま流れる字幕・前に出るカード・見ている銘柄に切り替わるチャート（建値・損切り・利確の線）・打ち込まれる分析と発注のコード・効果音が、タブもスクロールも無い 1 枚で動き続ける。入力欄の上の帯には AI の状態と純資産、Hyperliquid の値段と資金調達、注文の控え。ほかに総覧・アラート・米国株（Alpaca Paper・鍵は任意）・予測市場・SEC・市場の時計と経済指標（/trade <名前>）と、＋ → プラグイン のスキル 7 つ。データは Hyperliquid・Polymarket・SEC EDGAR・連邦準備制度と労働統計局の公式の予定・Alpaca の公式 API だけ。変えたい時は /trade settings。
