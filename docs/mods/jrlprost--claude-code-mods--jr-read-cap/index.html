jr-read-cap

A Claude Code mod in jrlprost/claude-code-mods

Stops Claude from reading a long file whole: a Read of a file over 1,000 lines without a range is refused with a hint to grep first and read only the lines it needs. Saves context and tokens.

jr-read-cap reaches L1 (reads) and passed claude plugin validate with warnings.

  • Events hooked: 1
  • API methods referenced: 2
  • Access from classified calls: L1, reads: reads files
  • Static scan, not a runtime test

Install hint

/plugin install jr-read-cap --marketplace jrlprost/claude-code-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
