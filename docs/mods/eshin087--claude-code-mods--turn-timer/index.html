turn-timer

A Claude Code mod in eshin087/claude-code-mods

Saves how long every turn took as a row in the chat, logs every prompt's timing, and adds /timings to look back.

turn-timer reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
