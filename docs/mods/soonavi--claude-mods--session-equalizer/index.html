session-equalizer

A Claude Code mod in soonavi/claude-mods

A ten-band equalizer above the prompt that moves with the session's work: reading, finding, editing, writing, shell, tests, git, GitHub, web and other. Red on a failure, flat while waiting on you. /eq hides it.

session-equalizer reaches L1 (reads) and passed claude plugin validate with warnings on Claude Code 2.1.310.

  • Events hooked: 6
  • API methods referenced: 9
  • Access from classified calls: L1, reads: reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
