finish-line

A Claude Code mod in estevanhernandez-stack-ed/sanduhr-mods

When a turn creates a tag (git tag, gh release create), a Claude sprite runs across the band above the prompt and crosses a checkered finish line, and the tag's name lands beside it. /finish-line [tag] replays it. Reads nothing, writes nothing, no network.

finish-line reaches L1 (reads) and passed claude plugin validate with warnings.
