comfyui-local

A Claude Code mod in anderson-spider/claude-mods

Generate images, video and audio, keep workflows in your library, and manage node packs and restart the server on your self-hosted ComfyUI (and ComfyUI-Manager) through its HTTP API, using the url plugin option; unofficial, with slash commands ported from Comfy-Org/comfy-skills.

comfyui-local reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 2
  • API methods referenced: 8
  • Access from classified calls: L3, network: network, runs processes, writes files, drives Claude, reads files, reads settings
