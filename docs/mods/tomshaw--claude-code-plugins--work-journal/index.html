work-journal

A Claude Code mod in tomshaw/claude-code-plugins

Daily, weekly and monthly reviews of your work in Claude Code, summarized from the prompts you typed: projects, threads, decisions and open items. /journal opens it in a pane, /journal web as a webpage.

work-journal reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 3
  • API methods referenced: 15
  • Access from classified calls: L2, writes or runs: runs processes, writes files, drives Claude, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
