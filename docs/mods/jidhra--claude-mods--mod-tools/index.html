mod-tools

A Claude Code mod in jidhra/claude-mods

A Mod Tools button in the prompt footer that opens a panel for picking the model and effort, showing or hiding mod panes, and switching your installed mods on and off.

mod-tools reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 11
  • Access from classified calls: L2, writes or runs: runs processes, changes config, drives Claude, reads files, reads settings, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install mod-tools --marketplace jidhra/claude-mods
