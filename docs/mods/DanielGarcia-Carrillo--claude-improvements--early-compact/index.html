early-compact

A Claude Code mod in DanielGarcia-Carrillo/claude-improvements

Has Claude write a checkpoint once context passes a threshold, then compacts early with that checkpoint as the brief and resumes the work

early-compact reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • API methods referenced: 11
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, draws
  • Static scan, not a runtime test
