plan-progress

A Claude Code mod in zycck/claude-mods

Live plan progress bars above the Claude Code prompt: stages, steps, a pixel fill and soft sounds for decision, error and done

plan-progress reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 16
  • API methods referenced: 29
  • Access from classified calls: L3, network: network, runs processes, changes config, drives Claude, reads files, reads env vars, reads settings, reads mod state, plays audio, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
