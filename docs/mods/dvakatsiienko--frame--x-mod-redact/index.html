x-mod-redact

A Claude Code mod in dvakatsiienko/frame

keeps secrets out of every transcript: api keys, tokens and private keys read as a stable placeholder in every kept row, and come back only inside the tool call that names them

x-mod-redact reaches L1 (reads) and passed claude plugin validate with warnings on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 3
  • Access from classified calls: L1, reads: reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
