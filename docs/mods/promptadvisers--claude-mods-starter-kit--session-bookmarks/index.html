session-bookmarks

A Claude Code mod in promptadvisers/claude-mods-starter-kit

Explicit bookmarks for Claude Code sessions you want to come back to. /bm saves one, /bm open lists them with a copyable resume command.

session-bookmarks reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 22
  • Access from classified calls: L2, writes or runs: runs processes, writes files, drives Claude, writes the clipboard, reads files, reads env vars, reads the transcript, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
