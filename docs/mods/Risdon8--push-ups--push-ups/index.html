push-ups

A Claude Code mod in Risdon8/push-ups

Predicts how long Claude's turn will take and gives you push-ups to do while you wait, in a bar above the prompt. Local only: no model calls, no tokens.

push-ups reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 5
  • API methods referenced: 8
  • Access from classified calls: L1, reads: reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
