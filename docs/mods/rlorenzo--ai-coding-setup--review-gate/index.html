review-gate

A Claude Code mod in rlorenzo/ai-coding-setup

The review gate as a tool.check function hook. Every shell call is decided in process, so the non-commit calls -- almost all of them -- cost no subprocess at all, and a blocked commit can be put to you as a question instead of refused outright. The decision itself is still bin/review-gate, run only for a command that mentions a commit, so both routes read the same receipts and cannot disagree.

review-gate reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
