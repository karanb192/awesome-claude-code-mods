watchdog

A Claude Code mod in matteoantoci/claude-code-watchdog

Watchdog agents review each update of the agent you work with and push short notes to it. It spawns review subagents and auto-allows only its own review spawn and reviewer reads of files the main agent already read.

The scan could not record a complete footprint for watchdog, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.304.

  • Access: unknown, the footprint is incomplete
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
