pr-pane

A Claude Code mod in robinalexandre/claude-code-kit

A pane listing the PRs pr-watch tracks: status, CI, votes and what each one waits for, plus your pipeline runs and the issues you follow; open one in the browser, refresh them live.

pr-pane reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 5
  • API methods referenced: 15
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
