copy-commands

A Claude Code mod in ya8282/claude-code-mods

Holds the shell blocks Claude prints for you to run, and copies them on a keypress or /copy-commands

copy-commands reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.
