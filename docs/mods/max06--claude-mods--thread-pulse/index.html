thread-pulse

A Claude Code mod in max06/claude-mods

Makes running tool calls visible: live cards for every shell command with output as it runs (Command Watch), a status line for long calls, and a live line in Claude project thread checklists.

thread-pulse reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 4
  • API methods referenced: 17
  • Access from classified calls: L3, network: MCP servers, runs processes, writes files, reads files, reads env vars, draws
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
