pixel-pet

A Claude Code mod in eranltd/pixel-pet

Bit the pixel puppy, in two layouts. Side pane: the session's status and ticket beside the chat (TL;DR, PRs, experiments, config drafts, links, people) over Slack, its Code Review, its Related Sessions and running agents, and a sticky context footer with model and cache, every section foldable. Band: sessions board (waiting, running, merged, idle), merge-ready lane, push guard and failure classifier, CI why, preview chip, Slack inbox with per-message dismiss, needs-you inbox, usage projection, hygiene guards, actions pane with a favorite, /bit rituals, worktree janitor, merge impact watch; plus plan progress, cache line with Summarize, start fresh, critique, ELI5

pixel-pet reaches L1 (reads) and passed claude plugin validate with warnings.
