claude-maru-run

A Claude Code mod in lemonlatte/claude-maru-run

An orange-and-white cat chases a butterfly across seven rows above the prompt for as long as Claude works, bounding after it, leaping when it dips low, and going over in a heap when it misses; the trees and grass of the lot slide past behind it as it runs. Needs function hooks (early access) and an interactive terminal.
