usage-meter

A Claude Code mod in shaheershoaib/usage-meter

An always-visible usage meter above the prompt with live 5-hour, weekly and usage-credit bars that climb smoothly as usage rises, and a Request more usage button that sends a usage-credit request to your organization admins, plus a /more-usage command.

usage-meter reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • API methods referenced: 14
  • Access from classified calls: L3, network: network, writes the clipboard, reads mod state, requests an Anthropic credential handle, persists state, draws
