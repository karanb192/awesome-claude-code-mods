jev-effort

A Claude Code mod in gebeer/jev-effort

Sets the main conversation's reasoning effort per prompt with TypeSafe's Jev (via OpenRouter), reading recent conversation context. Shadow mode by default: logs what it would do without changing anything.

jev-effort reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.
