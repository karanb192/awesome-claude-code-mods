image-preview

A Claude Code mod in ezoushen/claude-mods

Render image paths inline: a thumbnail in the user's prompt row (aspect-fill, max 10 rows) and in agent reply rows when the model mentions a path. Recognises a file path ending in a supported image extension (quoted or with escaped spaces too), or an [Image #N] token for a pasted picture.

image-preview reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
