gateway-switch

A Claude Code mod in zchee/claude-code-mods

Switches a running session between api.anthropic.com and the local Model Gateway: onto the gateway once Remote Control has registered, on /gateway on, or as each session starts after /gateway setup, and back to api.anthropic.com whenever the gateway stops answering.

gateway-switch reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 19
  • Access from classified calls: L3, network: network, runs processes, writes files, sets env vars, drives Claude, reads files, reads env vars, draws
  • Static scan, not a runtime test
