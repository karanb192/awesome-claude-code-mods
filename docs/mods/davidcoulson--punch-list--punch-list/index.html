punch-list

A Claude Code mod in davidcoulson/punch-list

One to-do list of things waiting on you, shared by every Claude Code session: Claude adds an item whenever it tells you to do something, a band above the prompt shows what's open, and /todo lists, ticks off and snoozes them.

punch-list reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 5
  • API methods referenced: 25
  • Access from classified calls: L3, network: MCP servers, runs processes, writes files, drives Claude, reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
