sandbox-guard

A Claude Code mod in oleksandrkodua/qa-mods

Denies Edit/Write/Bash writes to Claude config paths the sandbox cannot write (settings, skills, plugins, hooks, projects, ...) and tells Claude to hand the user a ready Terminal command instead of trying workarounds.

sandbox-guard reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 2
  • API methods referenced: 1
  • Access from classified calls: L1, reads: reads env vars
  • Static scan, not a runtime test

Install hint
