frontier-pacer

A Claude Code mod in n0ah37/frontier-pacer

One line above the prompt: context tokens, session cost, active time, a prompt-cache countdown and your plan limits with pace

frontier-pacer reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.
