voice-reply

A Claude Code mod in Tina0529/claude-voice-reply

Claude Code desktop (macOS) mod: when a turn finishes in the session you are looking at, speak a short spoken-style summary of the answer aloud (edge-tts, falls back to macOS say). One 🔊 button above the prompt toggles it for all sessions.

voice-reply reaches L2 (writes or runs) and passed claude plugin validate.
