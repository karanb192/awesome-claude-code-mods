live-vibe

A Claude Code mod in potto007/ottomation

/live: full-duplex voice (Kyutai streaming STT with semantic end of turn, or Silero and Whisper; Kokoro TTS) through a sidecar; /vibe: director mode that delegates all work to subagents; /livevibe: talk with a fast voice front that hands the work to Claude as director.

live-vibe reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 8
  • API methods referenced: 15
  • Access from classified calls: L3, network: network, runs processes, changes config, drives Claude, reads mod state, draws
