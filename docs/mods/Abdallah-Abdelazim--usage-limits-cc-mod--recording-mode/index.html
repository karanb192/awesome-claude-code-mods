recording-mode

A Claude Code mod in Abdallah-Abdelazim/usage-limits-cc-mod

Masks secrets on screen and tells the model to keep them off screen, for screen recordings.

In its last recorded footprint, recording-mode reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.308.
