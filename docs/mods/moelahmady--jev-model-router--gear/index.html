gear

A Claude Code mod in moelahmady/jev-model-router

Routes each turn's reasoning effort with TypeSafe's Jev decision model, keeping the prompt cache (Claude Code 2.1.280+). Model routing is available but off by default and refused above maxSwitchTokens, since a model switch re-writes the whole context.

gear reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 3
  • API methods referenced: 7
  • Access from classified calls: L3, network: network, drives Claude, draws
