osmosis

A Claude Code mod in raylrcheng/osmosis

Learn Mandarin by osmosis: swaps some English words in Claude's replies for Chinese on screen only. Hover a word for its meaning, click it for more, /osmosis for settings.

osmosis reaches L0 (draws and remembers) and passed claude plugin validate with warnings.
