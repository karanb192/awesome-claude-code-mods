language-improve

A Claude Code mod in TurboKach/cc-language-improve

Checks your prompt draft's English with Haiku after a pause and shows the whole draft corrected in the band above the prompt, with the changed words colored by kind of error and a short reason for each. Mute the kinds of error you do not want to see.

language-improve reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
