todo

A Claude Code mod in joaosavi/cockpit

Keeps the native task list in front of the agent: the open tasks at session start and right after each compaction, a reminder that a new request becomes a task before any other work, completed tasks logged to an archive, and the app's task panel kept in line with the task files.

todo reaches L2 (writes or runs) and passed claude plugin validate with warnings.
