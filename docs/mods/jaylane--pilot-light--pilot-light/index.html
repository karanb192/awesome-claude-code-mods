pilot-light

A Claude Code mod in jaylane/pilot-light

Band above the prompt: prompt-cache countdown, context size, 5h/7d limits, API-equivalent cost, cost of a cold next message, silent keep-alive pings under a dollar cap, and a Handoff & Clear button.
