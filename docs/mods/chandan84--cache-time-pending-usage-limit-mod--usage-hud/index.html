usage-hud

A Claude Code mod in chandan84/cache-time-pending-usage-limit-mod

Three-box HUD above the prompt: tokens and API-equivalent cost across all sessions (daily and per-session breakdown), context-window meter with a soft limit, and prompt-cache warmth countdown with last-turn tokens and cost.

usage-hud reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
