office

A Claude Code mod in charlie947/mod-maker

A pixel-art office in a local web page: every Claude session gets a desk, walks to the filing cabinet when it reads, types when it edits, flies paper planes when it messages, and shows a live Done-by clock

office reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.310.

  • API methods referenced: 12
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, reads files, reads env vars, plays audio, persists state
