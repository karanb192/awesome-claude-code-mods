appshot

A Claude Code mod in mareksulik/appshot

Press both ⌘ keys to give Claude the window you're looking at: a screenshot plus its text, including text scrolled offscreen (macOS)

appshot reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
