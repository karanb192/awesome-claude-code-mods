worklist

A Claude Code mod in FynnXland/fynn-mods

To-do sidebar next to the chat: queue tasks, even while Claude is working. When Claude is clearly done, the to-do is checked off and the next one starts; otherwise the list stops with a reason and buttons (Continue keeps the order). Runs by default, never pauses on its own. Survives /clear. History per project. /todo, /todos help

worklist reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
