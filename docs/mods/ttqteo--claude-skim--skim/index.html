skim

A Claude Code mod in ttqteo/claude-skim

Skim Claude's replies: Claude marks the few sentences you must read, the mod draws them highlighted and dims the rest, and strips the marks before the reply is stored.

skim reaches L1 (reads) and passed claude plugin validate.

  • Events hooked: 7
  • API methods referenced: 12
  • Access from classified calls: L1, reads: reads settings, reads the system prompt, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
