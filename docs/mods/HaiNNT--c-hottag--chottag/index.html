chottag

A Claude Code mod in HaiNNT/c-hottag

Drive chottag (c-hottag) from Claude Code: switch the serving account, set the remote account, log accounts in, check limits and the install. On Claude Code 2.1.287+ a mod adds a status card, notices, /ct commands and a /login guard.

chottag reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
