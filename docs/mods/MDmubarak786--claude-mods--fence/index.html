fence

A Claude Code mod in MDmubarak786/claude-mods

Limit which paths Claude may edit in a project with one /fence command. Edits outside the fence are refused with a reason Claude can act on.

fence reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 3
  • API methods referenced: 6
  • Access from classified calls: L0, draws and remembers: persists state, draws
  • Static scan, not a runtime test
