usage-band

A Claude Code mod in kcsujeet/kc-claude-kit

A row of pills above the prompt: model, git branch, context fill, 5h and 7d rate limits with reset times, input/output/cache tokens, and session cost, with usage figures turning amber from 70% and red from 90%

usage-band reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
