laravel-tooling

A Claude Code mod in tomshaw/claude-code-plugins

Runs Pint and Larastan after Claude edits PHP, and Pest on demand, then shows the results in a live pane and the status line. /laravel-tooling opens the pane, /laravel-tooling run checks everything, /laravel-tooling tests [filter] runs Pest.

laravel-tooling reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 5
  • API methods referenced: 13
  • Access from classified calls: L2, writes or runs: runs processes, writes the prompt box, reads files, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
