mod-firewall

A Claude Code mod in bbarney7/claude-code-mods

A firewall for Claude Code mods: watches what every other mod does (network, processes, secret files, env vars) and asks, blocks or logs

mod-firewall reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.316.

  • Events hooked: 12
  • API methods referenced: 15
  • Access from classified calls: L1, reads: reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install mod-firewall --marketplace bbarney7/claude-code-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
