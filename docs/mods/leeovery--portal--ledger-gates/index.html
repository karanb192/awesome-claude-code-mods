ledger-gates

A Claude Code mod in leeovery/portal

Draws Ledger's gates in the band above the prompt: rows a click puts in the prompt and a second click sends: instead of a menu the model has to reproduce; carries a handoff into a fresh conversation; appends the engine's note to a Ledger conversation's compaction, so Claude re-reads what it works from and carries on with the build's agents it already dispatched; says the phase in the spinner; and draws the board, a pane beside the conversation and a banner above the prompt.

The scan could not record a complete footprint for ledger-gates, so its access is unknown; it passed claude plugin validate with warnings.

  • Access: unknown, the footprint is incomplete
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
