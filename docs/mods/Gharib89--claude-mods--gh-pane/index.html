gh-pane

A Claude Code mod in Gharib89/claude-mods

A docked pane of the session repo's issues and PRs in run order, each row with its labels in their colours, a toggle that expands it to its full title, label chips and facts, and a CI mark on its PR, with buttons that fill the next command, plus two for this session's ship runs: send the merge reply at the merge gate, then, once the PR is merged there or by ship on its own, clear and run the next command.

gh-pane reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 17
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, writes the prompt box, reads the prompt box, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
