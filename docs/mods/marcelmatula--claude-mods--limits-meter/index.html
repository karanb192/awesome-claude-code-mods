limits-meter

A Claude Code mod in marcelmatula/claude-mods

Session (5 h) and weekly usage limits as small progress bars with reset countdowns, plus whether the prompt cache is still warm and for how long and the session's name, centred under the prompt; /limits hides or shows them

limits-meter reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 7
  • API methods referenced: 12
  • Access from classified calls: L1, reads: reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install limits-meter --marketplace marcelmatula/claude-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
