perf-delta

A Claude Code mod in simota/claude-mods

/perf runs a benchmark command several times and compares it with its baseline (saved earlier, or a git ref run in a temporary worktree): median wall time, peak memory and the spread of the runs, and whether the difference is larger than the noise
