contextmanager

A Claude Code mod in devohmycode/claude-mods

Watches a session for wasted context and time, shows a one-click card when a waste behaviour repeats, and lets the user steer or stop it.

In its last recorded footprint, contextmanager reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.300.
