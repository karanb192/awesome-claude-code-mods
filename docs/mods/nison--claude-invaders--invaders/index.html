invaders

A Claude Code mod in nison/claude-invaders In Anthropic directory

A tiny Space Invaders to play above the prompt while Claude works; pauses when Claude finishes and keeps your level.

invaders reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 7
  • API methods referenced: 13
  • Access from classified calls: L1, reads: reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
