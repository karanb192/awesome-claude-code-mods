collapse-tools

A Claude Code mod in 0xnicholasy/claude-mod-collapse-tools

Claude Fold: Collapses each tool call to one clickable line in a color you pick, showing the model's own description of the call where it has one.

collapse-tools reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.
