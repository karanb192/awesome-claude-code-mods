auto-session-name

A Claude Code mod in tartinerlabs/claude-code-mods

Names each session from its first prompt, and again a few prompts in when that one was short, so it is easy to find in /resume.

auto-session-name reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • API methods referenced: 4
  • Access from classified calls: L2, writes or runs: drives Claude, reads mod state
