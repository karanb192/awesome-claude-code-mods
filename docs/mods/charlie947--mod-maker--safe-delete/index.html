safe-delete

A Claude Code mod in charlie947/mod-maker

Claude never deletes a file for good: rm, find -delete and git clean move files to the Bin, with a receipt and /undo-delete

safe-delete reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
