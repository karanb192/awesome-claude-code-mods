cc-tamagotchi

A Claude Code mod in davidurco/cc-tamagotchi

A Tamagotchi that lives in Claude Code: it hatches, eats the work Claude does, leaves bugs behind, gets sick, throws tantrums and grows into one of eight adults. An animated pixel LCD in the terminal, an egg-shaped device in the desktop app. Zero tokens.

cc-tamagotchi reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 10
  • API methods referenced: 17
  • Access from classified calls: L1, reads: reads mod state, plays audio, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
