account-switcher

A Claude Code mod in SmelterLabs/claude-account-switcher

Bill a Claude Code session to a different Claude subscription per project (a .claude/account marker), on demand (/account <name>), or with one click in the band above the prompt, through a local token-swapping relay. The desktop app keeps its own login.

account-switcher reaches L2 (writes or runs) and passed claude plugin validate with warnings.

  • Events hooked: 4
  • API methods referenced: 14
  • Access from classified calls: L2, writes or runs: sets env vars, reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
