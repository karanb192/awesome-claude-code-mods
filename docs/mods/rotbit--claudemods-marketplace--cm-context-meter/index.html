cm-context-meter

A Claude Code mod in rotbit/claudemods-marketplace

Puts context-window fill, 5-hour/7-day plan usage and session cost in the status line, and warns once when the context gets full.

cm-context-meter reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 3
  • API methods referenced: 4
  • Access from classified calls: L0, draws and remembers: draws
  • Static scan, not a runtime test
