agents-info

A Claude Code mod in pazimor/marketplace

Agents info Mod (Claude Code 2.1.287, Mods API in early access): starting agent, timeline of agents per prompt (new, resumed, forked), resolved model and effort of each, tokens per agent × model × effort, 5 h / 7 day limits with forecast, alerts. Read-only: alters and blocks nothing.
