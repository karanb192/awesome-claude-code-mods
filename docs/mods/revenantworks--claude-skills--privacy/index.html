privacy

A Claude Code mod in revenantworks/claude-skills

Revenantworks privacy mod for Claude Code 2.1.287+: masks secrets and stream keys before Claude reads them (restoring a value only into the gitignored file it came from), flags a credential keywarden marked for rotation, and marks web, MCP and mail results and messages from routines or other sessions as data. Kept apart from the dash plugin, so safety never depends on the dashboard. Never blocks your work; keeps no record; contacts no service.

In its last recorded footprint, privacy reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.308.
