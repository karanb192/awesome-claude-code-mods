status-meter

A Claude Code mod in s-hiraoku/claude-mods

Shows context, 5-hour and 7-day limit usage as SVG meters above the prompt in the Desktop app

status-meter reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.310.
