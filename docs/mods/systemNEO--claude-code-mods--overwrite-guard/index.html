overwrite-guard

A Claude Code mod in systemNEO/claude-code-mods

Stops Claude from rewriting whole existing files: Write on an existing file and shell commands that replace one (>, tee, cp, mv, python/node writes) are refused with a request to use Edit.

overwrite-guard reaches L1 (reads) and passed claude plugin validate.

  • Events hooked: 1
  • API methods referenced: 6
  • Access from classified calls: L1, reads: reads files, reads env vars, draws
  • Static scan, not a runtime test

Install hint

/plugin install overwrite-guard --marketplace systemNEO/claude-code-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
