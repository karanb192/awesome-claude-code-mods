prompt-offload

A Claude Code mod in KilimcininKorOglu/claude-code-mods

Writes a prompt longer than the limit (2000 characters by default) to a temp file and sends the model its first 200 characters with the path, so one paste does not fill the context.

prompt-offload reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • API methods referenced: 8
  • Access from classified calls: L2, writes or runs: runs processes, writes files, reads env vars, persists state, draws
