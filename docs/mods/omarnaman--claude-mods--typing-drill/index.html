typing-drill

A Claude Code mod in omarnaman/claude-mods

While Claude implements a feature, it queues the most instructive snippets of the new code as typing exercises you type in a pane.

typing-drill reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.312.
