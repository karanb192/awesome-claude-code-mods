mod-notification

A Claude Code mod in ouquoi/claude_mod_notification

Sends a notification (phone included, via ntfy) when Claude has finished or is waiting for your answer and you have not come back after a configurable delay. Uses no tokens.

mod-notification reaches L3 (network) and passed claude plugin validate with warnings.

  • Events hooked: 5
  • API methods referenced: 6
  • Access from classified calls: L3, network: network, draws
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
