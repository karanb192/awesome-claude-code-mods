task-band

A Claude Code mod in genoooool/claude-task-band

A status band above the Claude Code prompt (desktop app) that shows which scheduled tasks and sessions are running, need your reply, or finished while you were away. One click opens the session.

task-band reaches L3 (network) and passed claude plugin validate with warnings.

  • Events hooked: 2
  • API methods referenced: 16
  • Access from classified calls: L3, network: MCP servers, runs processes, writes files, reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
