glitch-pets

A Claude Code mod in Sri-Ln/glitch

Glitch pets: pick one of six pixel critters; it sits at the end of the HUD row, shows moods and says a word now and then; leads the crew pane when Claude splits work across a crew of agents.

glitch-pets reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.316.
