auto-handoff

A Claude Code mod in Amel-DZRV/claude-code-auto-handoff

Shows a context bar with a red handoff mark, the prompt-cache countdown and per-request tokens. When context passes a threshold it writes a handoff summary, clears the session and loads the summary into the fresh one. /keepwarm pings the prompt cache while you are away (pings spend tokens).

auto-handoff reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
