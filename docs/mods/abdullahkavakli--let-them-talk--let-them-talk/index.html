let-them-talk

A Claude Code mod in abdullahkavakli/let-them-talk

Adds /let-them-talk, which starts Let Them Talk and opens it in your browser; shows Claude Code's suggested next prompt in its Send box; and runs a Chat in IDE started from it on the model picked there.

let-them-talk reaches L3 (network) and passed claude plugin validate with warnings.

  • Events hooked: 7
  • API methods referenced: 8
  • Access from classified calls: L3, network: network, runs processes, drives Claude, writes the prompt box, reads env vars
