explore-model

A Claude Code mod in rlorenzo/ai-coding-setup

Pins the model that background recon subagents run on. An agent.spawn hook sets the Explore subagent's model to haiku, so a session driven by an expensive model stops billing its codebase searches at that tier, without shadowing the built-in agent definition and without the CLAUDE.md load a replacement definition would cost.

explore-model reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.310.
