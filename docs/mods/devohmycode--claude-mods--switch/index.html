switch

A Claude Code mod in devohmycode/claude-mods

A pane of the models and the effort levels, each switched with one click. /switch opens it; /switch opus or /switch high switches without it. A click runs the engine's own /model or /effort, so the status line follows; the pane shows the model and the effort the last request was actually sent with.
