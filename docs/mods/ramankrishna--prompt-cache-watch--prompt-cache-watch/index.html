prompt-cache-watch

A Claude Code mod in ramankrishna/prompt-cache-watch

Shows how much of each request the prompt cache served, and tells you when the cache was rebuilt and the likely reason.

prompt-cache-watch reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.
