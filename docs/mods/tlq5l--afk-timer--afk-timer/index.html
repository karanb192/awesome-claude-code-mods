afk-timer

A Claude Code mod in tlq5l/afk-timer

Shows how long you have been away from a Claude Code session and warns when its prompt cache has likely expired, so you can /clear instead of paying to re-read a big conversation

afk-timer reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 12
  • API methods referenced: 8
  • Access from classified calls: L1, reads: reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
