no-attribution

A Claude Code mod in claudemodz/mods

Removes the Co-Authored-By commit trailer and the "Generated with Claude Code" PR footer, or replaces them with your own text. Deterministic: no CLAUDE.md rule needed.

The validator reported no API methods for no-attribution; it passed claude plugin validate on Claude Code 2.1.310.
