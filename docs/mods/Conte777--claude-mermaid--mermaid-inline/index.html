mermaid-inline

A Claude Code mod in Conte777/claude-mermaid

Mermaid diagrams in Claude Code: every ```mermaid block Claude writes is drawn as a picture right where the fence was in the transcript, with an open-SVG button, and as box art where the terminal cannot show pictures. Fork of galElmalah/claude-mods claude-mermaid. Needs function hooks (early access), node and resvg.
