shell-shim

A Claude Code mod in MichaelP17/claude-mods

Fixes the zsh pitfalls Claude's bash-style commands trip over: = words, unmatched globs, word splitting, aliases that hide programs, a missing timeout: before the command runs

shell-shim reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 2
  • API methods referenced: 5
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads env vars, draws
