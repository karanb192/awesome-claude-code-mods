bad-time

A Claude Code mod in FatihBastan/bad-time

Opens Bad Time Simulator (a fan game by Jcw87, recreating the Sans fight from UNDERTALE by Toby Fox) in its own window while Claude works. Not affiliated with either.

bad-time reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 8
  • API methods referenced: 17
  • Access from classified calls: L2, writes or runs: runs processes, writes files, writes the prompt box, reads files, reads env vars, plays audio, persists state, draws
  • Static scan, not a runtime test

Install hint
