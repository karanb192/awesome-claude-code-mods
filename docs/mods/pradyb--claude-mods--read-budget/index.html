read-budget

A Claude Code mod in pradyb/claude-mods

Stops Claude from re-reading the same large, unchanged file in full again and again in one session: past a limit it is pointed to Grep or a ranged Read instead.

read-budget reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 3
  • API methods referenced: 1
  • Access from classified calls: L1, reads: reads files
  • Static scan, not a runtime test

Install hint

/plugin install read-budget --marketplace pradyb/claude-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
