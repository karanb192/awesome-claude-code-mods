workbench

A Claude Code mod in joharraza/claude-deck

Keeps git and dev servers in view: warns when you are on main with changes, have commits not on GitHub, or hit a merge conflict, with Push, Branch off and Stop servers buttons, and asks before Claude commits or pushes on main. The deck band shows it.

workbench reaches L2 (writes or runs) and passed claude plugin validate.

  • API methods referenced: 14
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, writes the prompt box, reads mod state, persists state, draws
