themes

A Claude Code mod in danishmughal/claude-code-themes

Draws Claude's replies in color: headings, bold, italics, inline code, links, list markers and highlighted code blocks, in a Monokai Pro theme. Display only: the stored transcript and what Claude reads are unchanged.
