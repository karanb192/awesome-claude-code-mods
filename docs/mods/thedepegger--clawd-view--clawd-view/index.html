clawd-view

A Claude Code mod in thedepegger/clawd-view

A calm, plain-English view of Claude Code: a step-by-step checklist above the prompt, usage stats when there's room, and Clawd the pixel mascot acting out each step. Tool calls and commands stay out of sight.

The scan could not record a complete footprint for clawd-view, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.304.

  • Access: unknown, the footprint is incomplete
