calm-aside

A Claude Code mod in kulovema2012/calm-mode

Calm Aside: a read-only side chat. /aside opens a pane where you ask about the session so far; a tool-less fork of the session answers, and nothing goes back into the main chat.

calm-aside reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 7
  • API methods referenced: 10
  • Access from classified calls: L2, writes or runs: drives Claude, reads the transcript, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
