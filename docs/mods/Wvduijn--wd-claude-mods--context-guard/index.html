context-guard

A Claude Code mod in Wvduijn/wd-claude-mods

Live context meter above the prompt; asks Yes/No to save a handoff and clear when the window fills, and feeds that handoff into the next session

context-guard reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.312.

  • Events hooked: 5
  • API methods referenced: 19
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, writes the prompt box, reads files, reads the transcript, reads mod state, persists state, draws
