prompt-upgrade

A Claude Code mod in aecheman27-gif/claude-mods

/improve <prompt>: a pane asks 2-4 clickable questions about what you want, then writes a fuller prompt you can run, edit or copy. Two small model calls per upgrade, only when you ask.

prompt-upgrade reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 12
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, writes the clipboard, reads the transcript, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
