sub-human

A Claude Code mod in tatimblin/sub-human

Work together from separate Claude Code sessions, on one machine or over a link: one command joins a shared room, @room posts your exact words, Claudes message each other natively, a room plan is edited in plan mode with versions, tasks are shared, and sign-off opens in each person's plan view.
