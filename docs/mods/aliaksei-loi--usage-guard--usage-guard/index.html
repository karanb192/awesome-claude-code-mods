usage-guard

A Claude Code mod in aliaksei-loi/usage-guard

Winds sessions and subagents down before the 5-hour or 7-day subscription limit: one wind-down note per band, a handoff file, spawn and loop denies near the limit, optional resume after the reset

usage-guard reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 19
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, reads files, reads env vars, reads the transcript, reads mod state, draws
