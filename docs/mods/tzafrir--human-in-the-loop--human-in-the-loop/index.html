human-in-the-loop

A Claude Code mod in tzafrir/human-in-the-loop In Anthropic directory

Claude assigns you the tasks only you can do. They wait in a My tasks pane, counted under the prompt, until you answer or reject them, so nothing Claude needs from you gets lost in the chat.

human-in-the-loop reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 15
  • API methods referenced: 25
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, reads the prompt box, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
