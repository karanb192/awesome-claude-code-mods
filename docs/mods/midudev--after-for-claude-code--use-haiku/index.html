use-haiku

A Claude Code mod in midudev/after-for-claude-code

Start a prompt with _ and that turn runs on Haiku, shown as you type, while it runs and under the answer.

use-haiku reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.
