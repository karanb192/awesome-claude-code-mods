desktop-statusline

A Claude Code mod in centminmod/claude-plugins In Anthropic directory

Status band above the prompt in the Claude Desktop app's Code tab: folder, git branch and state, session age, prompt count and cost, a context meter, 5-hour and weekly plan usage limit meters with reset countdowns, last-turn model, duration and cache hit rate, idle time against the prompt-cache TTL, compactions, server-side tool use, subagents by state, and one row per workflow run with live done/failed counts. A notification (or toast) at 80% and 95% of a usage limit. Draws only on the desktop surface, so a CLI statusLine is left alone.

desktop-statusline reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 9
  • API methods referenced: 14
  • Access from classified calls: L2, writes or runs: runs processes, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
