pixel-cat

A Claude Code mod in matthlh/claude-mods

A little pixel cat that wanders above the Claude Code prompt, watches your usage limits and announces when work finishes; or switch packs for an adventurer who mines, chops trees and fights zombies

pixel-cat reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • API methods referenced: 15
  • Access from classified calls: L2, writes or runs: drives Claude, reads mod state, persists state, draws
