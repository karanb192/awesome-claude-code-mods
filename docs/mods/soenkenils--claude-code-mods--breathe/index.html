breathe

A Claude Code mod in soenkenils/claude-code-mods

A breathing guide while Claude works: box breathing (or an even or calm pattern) as words and a bar above the prompt in the terminal, and an aurora orb that expands and contracts in Claude Desktop. When the turn ends it finishes the breath you are in.

breathe reaches L1 (reads) and passed claude plugin validate.

  • Events hooked: 5
  • API methods referenced: 7
  • Access from classified calls: L1, reads: reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install breathe --marketplace soenkenils/claude-code-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
