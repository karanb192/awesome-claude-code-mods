dcc-plugin-agents-md

A Claude Code mod in xsyetopz/dotclaude

Loads `AGENTS.md` files where Claude Code loads `CLAUDE.md`: the user folder, each ancestor of the working directory, nested folders on each read or edit, and the folders of `permissions.additionalDirectories`. Skips a file that a `CLAUDE` file already loads.

In its last recorded footprint, dcc-plugin-agents-md reaches L1 (reads) by its classified calls and passed claude plugin validate on Claude Code 2.1.301.

  • Events hooked: 4
  • API methods referenced: 6
  • Access from classified calls: L1, reads: reads files, reads env vars, reads settings
  • Unclassified calls: 2 ($.state.get, $.state.set), full access unknown
