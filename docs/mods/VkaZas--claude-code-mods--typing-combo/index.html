typing-combo

A Claude Code mod in VkaZas/claude-code-mods

A fighting-game combo counter above the prompt: big digits that hit harder the faster you type, with hit-stop, ranks, keys per second and your best.

typing-combo reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.
