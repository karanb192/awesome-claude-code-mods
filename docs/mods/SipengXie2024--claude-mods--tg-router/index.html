tg-router

A Claude Code mod in SipengXie2024/claude-mods

Telegram Router: dispatches each request to a background worker, routes replies to that worker, posts its answers, and shows a progress card per run; load with --plugin-dir in the claude-telegram session only.

tg-router reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.319.

  • Events hooked: 5
  • API methods referenced: 14
  • Access from classified calls: L3, network: network, drives Claude, reads files, reads env vars, persists state, draws
