clawd

A Claude Code mod in yushiran/cc-clawd

A pixel pet in the band above the prompt: Clawd (the Claude Code crab) or any pet you define. Reacts to what Claude is doing; any mod can drive it with $.clawd and hand it band rows; any program can drop a signal file. 60 Hz, real pixels where the terminal draws images, interactive on the desktop app

In its last recorded footprint, clawd reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.296.
