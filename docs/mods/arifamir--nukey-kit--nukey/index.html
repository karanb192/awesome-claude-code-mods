nukey

A Claude Code mod in arifamir/nukey-kit

Nukey the microwave sits above the prompt and acts out what Claude is doing: reading, writing code, thinking, searching and more, with a DING! when the turn is done. A control panel beside it shows context and rate-limit usage.

In its last recorded footprint, nukey reaches L0 (draws and remembers) by its classified calls and passed claude plugin validate on Claude Code 2.1.296.
