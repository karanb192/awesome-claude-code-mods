windvane-keeper

A Claude Code mod in 20alexl/windvane

Brings windvane back when Claude Code unloads it mid-session, so its tools return without /reload-plugins.

windvane-keeper reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • API methods referenced: 9
  • Access from classified calls: L2, writes or runs: changes config, reads files, reads env vars, reads settings, draws
