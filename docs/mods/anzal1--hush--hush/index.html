hush

A Claude Code mod in anzal1/hush

Free internet radio above the prompt, and any song through hum's visible YouTube player, with the synced lyric line, a DJ Clawd and an optional big panel with a sharp quadrant-block cover, a dithered aurora and karaoke-style lyrics. The music steps down when Claude asks you a question. No account. macOS.

hush reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.
