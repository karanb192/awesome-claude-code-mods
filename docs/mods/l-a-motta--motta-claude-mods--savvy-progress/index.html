savvy-progress

A Claude Code mod in l-a-motta/motta-claude-mods

A row under each Agent and Workflow call with an activity strip (a tick per tool call, colored as tool-borders colors it), a roll call of crabs in the band above the prompt while agents work, and an agents panel (/agents-info): each subagent's model, tool calls by kind, last actions as they stream, files touched, answer, cost and time; failed agents pinned, stopped and overdue ones marked; a strip of crabs grouped by status, named and wearing their model's color, on top. On top, a timeline of your turns: a session ruler in clock time with idle time folded, then each turn's agents as lanes, newest first, older turns folded. $.savvyProgress.open() lets another mod open the panel.

savvy-progress reaches L2 (writes or runs) and passed claude plugin validate with warnings.
