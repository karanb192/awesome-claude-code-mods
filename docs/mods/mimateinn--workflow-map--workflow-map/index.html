workflow-map

A Claude Code mod in mimateinn/workflow-map

Live workflow map: one row above the prompt (what is running, what is next, segmented progress) that expands into a card graph of parallel steps, plus a full stage-by-stage view and a flowchart of parallel groups, with your mid-plan interjections clearly marked (whether they were recorded, what each one changed shown on the plan, the plan before it, a timeline), an honest time-left range, owners and timing per step, sub-agent sync and plan history.
