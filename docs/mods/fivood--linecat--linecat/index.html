linecat

A Claude Code mod in fivood/linecat

A cat walks a line your Claude Code session unfolds, wearing what Claude is doing overhead; plus retro paper-panel styling for messages, tool rows and a usage monitor

linecat reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 11
  • API methods referenced: 13
  • Access from classified calls: L1, reads: reads settings, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
