A Claude Code mod in noopz/commonplace

A knowledge vault Claude reads and keeps for any folder of notes: graph-indexed vault tools, private domains that stay sealed, connections to what you already wrote surfaced under answers, and [[note]] links in replies that are checked against the vault.
