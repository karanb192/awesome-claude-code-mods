gtm-operator

A Claude Code mod in cmj-hub/gtm-operator-claude-mod

The GTM operator mod for Claude Code: scores every go-to-market draft with its own skill pack's scorer, flags stale and inconsistent drafts across packs, pack dashboards, a guided sprint, analytics, and a guard that keeps brand-config.json and SOUL.md merged.

gtm-operator reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 7
  • API methods referenced: 24
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, writes the prompt box, writes the clipboard, reads files, reads env vars, reads mod state, persists state, draws
