sessions

A Claude Code mod in ilya-paskhover/claude-code-mods

A side pane listing the Claude Code sessions running on this machine, all folders, with each one's status (working or idle), last activity and a Switch button for desktop sessions; in a cloud session, your recent cloud sessions with a link to each.

sessions reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 15
  • Access from classified calls: L3, network: MCP servers, runs processes, reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
