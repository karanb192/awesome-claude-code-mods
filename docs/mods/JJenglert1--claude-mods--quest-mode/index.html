quest-mode

A Claude Code mod in JJenglert1/claude-mods

Turns a goal into a retro RPG quest: Claude does each stage, you give the orders and the verdict, with a pixel map, XP and a boss battle (/quest).

quest-mode reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 7
  • API methods referenced: 19
  • Access from classified calls: L2, writes or runs: drives Claude, writes the clipboard, reads files, reads mod state, plays audio, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
