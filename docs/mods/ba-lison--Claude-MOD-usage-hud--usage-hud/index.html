usage-hud

A Claude Code mod in ba-lison/Claude-MOD-usage-hud

Band above the prompt: the Rei Clawd showing what the session is doing, 5-hour window and context gauges that heat to red past 75%, and a handoff that saves to disk and continues in a fresh session.
