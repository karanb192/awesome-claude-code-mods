no-hands

A Claude Code mod in elparko/look-claude-no-hands

Hands-free voice mode for Claude Code on Apple Silicon Macs: talk any time, hear short spoken replies, interrupt or add to work mid-task, run slash commands, and message or stop subagents by voice. Speech runs locally with Whisper and Kokoro.

no-hands reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
