smart-compact

A Claude Code mod in Gharib89/claude-mods

Lets Claude compact its own context at a step boundary it picks, with its own instructions, then resume the work.

smart-compact reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
