bash-rewrite

A Claude Code mod in chami1221-eng/my-ai-workbench

Rewrites Bash commands that a PreToolUse guard would deny (heredoc or python -c containing backslashes, cd followed by relative file names) into an equivalent form before the guard sees them. Forms it cannot rewrite safely pass through unchanged and are still stopped by the guard.

bash-rewrite reaches L2 (writes or runs) and passed claude plugin validate with warnings.

  • Events hooked: 3
  • API methods referenced: 9
  • Access from classified calls: L2, writes or runs: writes files, reads env vars, persists state, draws
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
