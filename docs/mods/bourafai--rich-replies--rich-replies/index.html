rich-replies

A Claude Code mod in bourafai/rich-replies

Claude Code terminal mod: TL;DR boxes, foldable sections, ▶ run for shell blocks, tool badges with error lines and stack links, a read-only SQL console, a REST client, a JSON tree, lint after edits, and /changes, /pr, /exec. Everything is off until you turn it on.
