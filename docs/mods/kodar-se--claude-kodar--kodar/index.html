kodar

A Claude Code mod in kodar-se/claude-kodar

Reports what this Claude Code session is working on to your kodar hub, so one dashboard shows every session across machines and accounts.

kodar reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 8
  • API methods referenced: 17
  • Access from classified calls: L3, network: network, runs processes, reads files, reads env vars, reads settings, requests an Anthropic credential handle
  • Static scan, not a runtime test
