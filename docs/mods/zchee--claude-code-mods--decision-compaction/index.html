decision-compaction

A Claude Code mod in zchee/claude-code-mods

Hands back the conversation itself in place of a compaction summary, less the tool calls and results a System One decision model judges no longer needed. The model can be TypeSafe Jev, Cloudflare Clef, Codiv OpenJev, Perplexity pplx-decider, OpenAI GPT-6 Luna, or Jev through OpenRouter, decisions-api.dev or decisionapi.net.

decision-compaction reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • API methods referenced: 9
  • Access from classified calls: L3, network: network, drives Claude, reads env vars, reads settings, draws
