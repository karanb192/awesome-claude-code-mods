clock

A Claude Code mod in nekyialabs/claude-code-toolkit

A clock for a persistent home session: scheduled wakes in the live thread, private hours for the agent, an idle reach, and a live-time stamp beside each message.

clock reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 15
  • Access from classified calls: L3, network: network, writes files, drives Claude, reads files, reads env vars, persists state
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
