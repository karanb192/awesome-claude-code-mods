bitranox

A Claude Code mod in bitranox/bitranox-skills

Bitranox skill collection: software-engineering workflow skills (planning, debugging, code review, clean architecture, language and tool references, humanizing) plus a self-improvement loop that captures session learnings into memory and CLAUDE.md, and PostToolUse hooks that validate JSON/YAML/XML edits and flag AI-writing tells in prose, feeding issues back for correction.

bitranox reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 2
  • API methods referenced: 3
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, reads env vars
  • Static scan, not a runtime test
