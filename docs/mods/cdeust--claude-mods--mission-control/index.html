mission-control

A Claude Code mod in cdeust/claude-mods

A graphical pane of the harness at work: every agent of the turn as a swimlane coloured by phase, bar height its effort, with advisor calls and failed tool calls marked; the effort each phase is calibrated to; and each phase's learning curve from the insights ledger, with the calibration's moves. Drawn in pixels where the terminal has the kitty graphics protocol (kitty, Ghostty, outside tmux), in coloured cells everywhere else (iTerm2, tmux). /mission opens it.

mission-control reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.
