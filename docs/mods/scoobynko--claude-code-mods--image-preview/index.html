image-preview

A Claude Code mod in scoobynko/claude-code-mods

/image-preview opens a pane listing every image of the session, pasted or returned by a tool, and shows the one you pick.

image-preview reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 16
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads env vars, reads the transcript, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
