outward-gate

A Claude Code mod in ozlar34/claude-code-mods

Confirm dialog before outward-facing sends and out-of-vault deletes; off switch for unattended runs; always-on audit log.

outward-gate reaches L2 (writes or runs) by its classified calls and passed claude plugin validate on Claude Code 2.1.304.
