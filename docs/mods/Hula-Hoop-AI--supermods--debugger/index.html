debugger

A Claude Code mod in Hula-Hoop-AI/supermods

A step debugger for the agent loop: pause at prompts, model requests, responses, tool calls and results; inspect and edit them; play, step or stop.

Access

L2 Writes or runsother: $.state.get, other: $.state.set, other: $.tool.list, runs processes, drives Claude, reads the transcript, draws
