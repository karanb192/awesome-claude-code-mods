games

A Claude Code mod in musingfox/cc-plugins

[Experimental] Mini games to play while Claude works: /2048, /mines (Minesweeper), /dino (Chrome's offline runner) and /gomoku (Gomoku against the computer, a friend or a matched stranger) each open a game pane, even mid-turn (Claude Mod; tested on Claude Code 2.1.291)

games reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.
