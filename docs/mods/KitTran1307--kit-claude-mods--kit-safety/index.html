kit-safety

A Claude Code mod in KitTran1307/kit-claude-mods

A safety net for risky commands: saves a snapshot of what a command would delete or overwrite, asks you in plain language before it runs, restores everything in one step with /safety restore, and hides well-known API keys and passwords in what Claude reads.
