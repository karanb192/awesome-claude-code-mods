break-time

A Claude Code mod in cloudcruncher/claude-mod-garage

Coffee-break reminder: tracks active time and opens an animated ASCII pane with a countdown and stretch tips.

break-time reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.319.
