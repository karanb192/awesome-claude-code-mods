side-pane

A Claude Code mod in xixiaofinland/side-pane

Pins the options and open questions Claude asks you to choose from in a side pane, so you never scroll back to find "option 2"

side-pane reaches L2 (writes or runs) and passed claude plugin validate.

  • API methods referenced: 15
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, writes the clipboard, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
