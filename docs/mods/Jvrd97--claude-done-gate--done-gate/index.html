done-gate

A Claude Code mod in Jvrd97/claude-done-gate

Claude cannot say "done" while the tests fail: a Stop gate runs your test command after every turn that changed files, and existing test files are locked so they cannot be patched green.

done-gate reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 9
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
