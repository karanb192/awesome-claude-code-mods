cache-shot-clock

A Claude Code mod in cjavdev/mods

A shot clock for the prompt cache's TTL: a small countdown in the bar under the prompt, and a big LED clock above it for the last seconds before the next turn pays a full cache write.

cache-shot-clock reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 10
  • API methods referenced: 7
  • Access from classified calls: L2, writes or runs: runs processes, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
