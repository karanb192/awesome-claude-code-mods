session-band

A Claude Code mod in IT-BAER/claude-forge

Prompt cache status band (c / ctx / rwc / sc / plan limits) with hover help, cold-send guard, keep-warm, /board, /handoff that also picks up handoff files, and an autonomous mode that clears and continues each handoff. Fork of Cache Keeper by Nate Herk.

The scan could not record a complete footprint for session-band, so its access is unknown; it passed claude plugin validate with warnings on Claude Code 2.1.304.

  • Access: unknown, the footprint is incomplete
