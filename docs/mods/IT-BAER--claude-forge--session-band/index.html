session-band

A Claude Code mod in IT-BAER/claude-forge

Prompt cache status band (c / ctx / rwc / sc / plan limits) with hover help, cold-send guard, keep-warm, /board, and /handoff that also picks up handoff files. Fork of Cache Keeper by Nate Herk.
