lk-attention

A Claude Code mod in connectwithub/loopkeeper

Look away while Claude works: a GNOME notification, a sound, a toast and a band when it needs you or finishes something long, plus an /attention inbox.

lk-attention reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 10
  • API methods referenced: 19
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads env vars, reads mod state, plays audio, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
