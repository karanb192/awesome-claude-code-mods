tool-status

A Claude Code mod in asemptote/claude-mods

Names the running tool call on the spinner, with what it is doing under it and its time, and the time since the last call while none runs. Each tool row gets a line naming the call, with +added/-removed lines, its input and output size in characters, its time and any failure, numbered from the prompt in the ctrl+o transcript; /tool-detail sets how much of every row shows (none, compact, input, output, full), and clicking a row's line steps that row alone (right or ctrl+click steps back). Past none the line heads the row and a dim rule closes it, and Bash and PowerShell commands are drawn highlighted, each heredoc, here-string or multi-line -c argument in its own language. Other parties' messages fold the same way in the ctrl+o transcript.
