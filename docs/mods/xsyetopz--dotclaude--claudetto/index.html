claudetto

A Claude Code mod in xsyetopz/dotclaude

Adds a lean output style, six role agents, and a status line command. Adds hooks that check edits and `git` calls, bound the context of subagents, and check Markdown line breaks and drift.

The scan could not record a complete footprint for claudetto, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.304.

  • Access: unknown, the footprint is incomplete
  • Static scan, not a runtime test

Install hint

/plugin install claudetto --marketplace xsyetopz/dotclaude

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
