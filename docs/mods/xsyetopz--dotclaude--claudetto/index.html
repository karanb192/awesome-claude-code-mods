claudetto

A Claude Code mod in xsyetopz/dotclaude

Tunes Claude Code for coding at the lowest token cost, through its official extension points only: settings, hooks, agents, commands, and an output style. It patches nothing.

claudetto reaches L2 (writes or runs) and passed claude plugin validate with warnings.

  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
