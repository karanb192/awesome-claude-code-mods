flightdeck

A Claude Code mod in scasella/claude-flightdeck

Flightdeck: a live agent dashboard for Claude Code. Main model vitals, an on-call architect, every permission check, subagent cards and swimlanes, a turn receipt and a session log, all from real session events

flightdeck reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 15
  • API methods referenced: 9
  • Access from classified calls: L1, reads: reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install flightdeck --marketplace scasella/claude-flightdeck

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
