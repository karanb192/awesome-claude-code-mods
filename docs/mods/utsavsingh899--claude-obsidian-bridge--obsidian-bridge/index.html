obsidian-bridge

A Claude Code mod in utsavsingh899/claude-obsidian-bridge

Mirrors each Claude session into an Obsidian note and takes replies that you write in that note.

obsidian-bridge reaches L2 (writes or runs) and passed claude plugin validate.
