pets

A Claude Code mod in YeomYuJun/claude-mods

An animal (dog, cat, turtle, duck, penguin or the Claude mascot) roams an isometric world (8 map sets) in a docked terminal panel and reacts to session signals (prompts, tool calls, turn ends).

pets reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 14
  • API methods referenced: 17
  • Access from classified calls: L1, reads: reads env vars, reads settings, persists state, draws
  • Static scan, not a runtime test

Install hint

/plugin install pets --marketplace YeomYuJun/claude-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
