high-command

A Claude Code mod in dot-agi/high-command

See the messages your teammates, named subagents, and other Claude Code sessions send you, grouped by peer with unread counts: a pane, a band above the prompt, and /highcommand.

high-command reaches L1 (reads) and passed claude plugin validate with warnings on Claude Code 2.1.310.

  • API methods referenced: 15
  • Access from classified calls: L1, reads: reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
