party

A Claude Code mod in pourya7/claude-code-mods

A raid frame for every live session on the machine: who is working, who is waiting on you and for how long, per-PR locks so two sessions never act on one PR, and /broadcast to the rest of the party.

party reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 18
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, writes the clipboard, reads files, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

/plugin install party --marketplace pourya7/claude-code-mods
