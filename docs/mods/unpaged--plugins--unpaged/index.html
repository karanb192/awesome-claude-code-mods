unpaged

A Claude Code mod in unpaged/plugins

Renders Claude Code and GitHub Copilot plans as whiteboards on Unpaged. /unpaged:visual-plan turns the plan in your conversation into a canvas of phases, tasks, and dependencies and listens to its @agent comments (delivered automatically inside Claude Code or GitHub Copilot; in Claude Code a line above the prompt shows what you listen to, and on older Claude Code builds a background Monitor polls instead); approving the plan stamps the canvas EXECUTING. While the plan is implemented the session keeps a Decision log on the canvas; /unpaged:as-built then compiles the as-built record: what shipped vs the plan, every decision and its why, the data flow, a reviewer's guide: as a frozen canvas nested under the plan. Every plan is filed in the Visual plans folder of your Unpaged library. /unpaged:architecture draws the repository's architecture document from its code and compares it after every pull request the session opens (keeping a line above the prompt in Claude Code and logging verdicts in GitHub Copilot), with update to rewrite what no longer holds.
