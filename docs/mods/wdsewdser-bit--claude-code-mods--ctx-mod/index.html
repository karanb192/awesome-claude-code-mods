ctx-mod

A Claude Code mod in wdsewdser-bit/claude-code-mods

Proactive context management: a task ledger, a searchable history and zero-summary window switches.

ctx-mod reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
