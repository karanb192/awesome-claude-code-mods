android-logcat

A Claude Code mod in NathanWA/claude-android-mods

Bounds the model's adb logcat calls, redacts secrets from adb output, keeps a pid-scoped logcat buffer with a grep tool and a /logcat pane.

android-logcat reaches L2 (writes or runs) and passed claude plugin validate.

  • Events hooked: 4
  • API methods referenced: 15
  • Access from classified calls: L2, writes or runs: runs processes, writes files, drives Claude, reads files, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
