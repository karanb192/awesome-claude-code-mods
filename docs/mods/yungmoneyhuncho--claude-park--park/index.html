park

A Claude Code mod in yungmoneyhuncho/claude-park

Stops paying full price to come back to a long Claude Code session: warns before the prompt cache expires, auto-compacts while it is still warm, leaves a handoff note, and tracks the tokens saved.

park reaches L2 (writes or runs) and passed claude plugin validate with warnings.
