context-board

A Claude Code mod in yogeshvar/mod-claude

Compact context card above the prompt: stacked category bar, percent, a wrapping legend, and a one-line kit strip of loaded skills, agents, CLAUDE.md, and plugins.

context-board reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.
