gatekeeper

A Claude Code mod in davidcoulson/crab-workshop

Your open PRs and what each waits on (/gates): the template boxes only you can tick, CodeRabbit threads and change requests, Codecov, CI, conflicts and drafts ready for you, sorted so what needs you comes first. A band above the prompt counts them; Claude can ask through the gates tool.

gatekeeper reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
