lossless-compact

A Claude Code mod in MusicStudioNYC/lossless-compact

Lossless compaction for Claude Code: nothing is summarized; everything removed is archived verbatim with provenance and restorable by id (Jev or a local ruleset). /lossless to inspect and restore.

lossless-compact reaches L3 (network) and passed claude plugin validate with warnings on Claude Code 2.1.304.
