run-suggested

A Claude Code mod in hematteo/run-suggested

Turns the shell commands Claude suggests into numbered shortcuts above the prompt: one key runs a command, with live output, a stop key, and your permission rules deciding what needs a second press

run-suggested reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.319.

  • Events hooked: 4
  • API methods referenced: 11
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, reads settings, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
