accountable-review

A Claude Code mod in wyeworks/accountable-review

Turns a pull request into a published review agenda: what changed, the judgments a reviewer has to make with the exact lines that settle each one, the order to read the code in, and the impact outside the diff through the unchanged code the change gives new meaning to: so a reviewer can explain the change before judging it. Ships review-map for Rails, for Elixir/Phoenix, for Rust: a Rust backend or Rust in general: and for React: a Next.js app or React in general: with or without a separate client, and setup-ci to generate one automatically on every review-ready pull request.

accountable-review reaches L1 (reads) and passed claude plugin validate.
