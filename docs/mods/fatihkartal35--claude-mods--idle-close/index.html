idle-close

A Claude Code mod in fatihkartal35/claude-mods

Closes a Claude Desktop session's process after it has been idle for a while (30 minutes, or what /idle-close <minutes> set), to free its memory. The session stays in the sidebar and restarts when you message it.

idle-close reaches L2 (writes or runs) and passed claude plugin validate with warnings.

  • Events hooked: 8
  • API methods referenced: 11
  • Access from classified calls: L2, writes or runs: runs processes, reads env vars, reads machine details, reads mod state, persists state
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
