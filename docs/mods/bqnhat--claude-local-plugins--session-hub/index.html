session-hub

A Claude Code mod in bqnhat/claude-local-plugins

One Mod status pane for Claude Code Desktop with an icon rail: Progress (live plan bars with step times and history, forked from zycck/claude-mods plan-progress), Next steps (up to three suggested next prompts; a click puts one in the composer), Skills & agents (the skills and agents called this session, each tagged personal, project, plugin or built-in, plus the rule and CLAUDE.md files loaded) and Cache (cache reads, writes and hit rate per turn, and what the cache saved). One footer entry opens the pane; the terminal keeps the progress band and the next-steps band

The scan could not record a complete footprint for session-hub, so its access is unknown; it passed claude plugin validate with warnings on Claude Code 2.1.310.

  • Access: unknown, the footprint is incomplete
  • Static scan, not a runtime test
