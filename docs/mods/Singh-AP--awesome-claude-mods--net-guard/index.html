net-guard

A Claude Code mod in Singh-AP/awesome-claude-mods

Stops data exfiltration and surprise network calls: checks every curl, wget, ssh, scp, git push and WebFetch against allow and deny lists, and asks before data goes to a host you haven't approved.

net-guard reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 3
  • API methods referenced: 5
  • Access from classified calls: L0, draws and remembers: persists state, draws
  • Static scan, not a runtime test
