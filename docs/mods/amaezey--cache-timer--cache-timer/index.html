cache-timer

A Claude Code mod in amaezey/cache-timer

A cache countdown above the prompt with Auto compact or status check before it goes cold, Compact now and Handoff buttons, real step details in the step line, and /timer to hide or show it.

cache-timer reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.310.
