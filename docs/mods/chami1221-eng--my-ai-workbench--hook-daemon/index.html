hook-daemon

A Claude Code mod in chami1221-eng/my-ai-workbench

Answers heavy Python command hooks (PreToolUse / PostToolUse / Stop / UserPromptSubmit) from one resident process instead of spawning Python on every tool call. Falls back to the normal settings hooks whenever the resident process is unavailable.

hook-daemon reaches L3 (network) and passed claude plugin validate with warnings.

  • Events hooked: 8
  • API methods referenced: 12
  • Access from classified calls: L3, network: network, runs processes, drives Claude, reads env vars, reads settings, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
