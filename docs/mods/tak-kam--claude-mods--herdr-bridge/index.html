herdr-bridge

A Claude Code mod in tak-kam/claude-mods

Tells herdr what Claude Code is doing and asking: the prompt as the pane's title, the question or permission it waits on, and a summary of each turn

herdr-bridge reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 7
  • API methods referenced: 6
  • Access from classified calls: L2, writes or runs: runs processes, reads env vars, reads mod state
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install herdr-bridge --marketplace tak-kam/claude-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
