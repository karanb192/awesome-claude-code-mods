ccbar

A Claude Code mod in emaballarin/ccplugins

ccbar: a quiet status band above the prompt, drawn natively by Claude Code's function hooks: the model and its effort, the repository (GitHub owner/name and branch, optionally as links; staged+unstaged diff), a context bar coloured by the /context categories with used/total and load, the session's new tokens (cache reads of the re-sent conversation left out, or counted too when set) counted once per API response, and the session and weekly rate limits with their reset countdowns. Colour carries meaning (identity, mode, load), and refreshes are paced: a 60 s idle tick plus every turn end. Function hooks only: no command hooks, no MCP, no settings patching.

ccbar reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 19
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads env vars, reads settings, reads mod state, draws
