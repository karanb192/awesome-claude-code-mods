mcp-accounts

A Claude Code mod in JesseVent/claude-mods

Several logins for any OAuth MCP server (Slack workspaces, Supabase accounts, anything else by URL), each signed in once, with the active one picked per project by /account and the others blocked. Switching never needs a restart.

mcp-accounts reaches L3 (network) and passed claude plugin validate.

  • Events hooked: 5
  • API methods referenced: 15
  • Access from classified calls: L3, network: MCP servers, writes files, drives Claude, reads files, persists state, draws
  • Static scan, not a runtime test

Install hint

/plugin install mcp-accounts --marketplace JesseVent/claude-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
