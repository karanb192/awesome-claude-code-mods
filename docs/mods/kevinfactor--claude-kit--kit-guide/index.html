kit-guide

A Claude Code mod in kevinfactor/claude-kit

Explains the X Factor kit: a one-time welcome above the prompt and /kit, a pane listing what each mod does and how to use it.

kit-guide reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.
