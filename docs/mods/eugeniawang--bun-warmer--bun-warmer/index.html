bun-warmer

A Claude Code mod in eugeniawang/bun-warmer

Keeps the prompt cache warm with a periodic ping for sessions with a large context, counts subagent work as activity, never blocks a prompt a human did not type, flags silent subagents, and writes an informational state file. Inspired by cache-tax by Karan Bansal (MIT).

bun-warmer reaches L2 (writes or runs) and passed claude plugin validate with warnings.

  • Events hooked: 9
  • API methods referenced: 19
  • Access from classified calls: L2, writes or runs: runs processes, writes files, drives Claude, reads files, reads env vars, reads settings, requests an Anthropic credential handle, draws
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
