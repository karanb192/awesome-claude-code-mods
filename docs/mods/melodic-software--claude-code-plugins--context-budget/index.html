context-budget

A Claude Code mod in melodic-software/claude-code-plugins

Measures a Claude Code session's fixed startup context payload per item at a pinned binary version, including per-tool attribution of the built-in tool pools that /context reports only as totals, derived by A/B deny differencing. Falls back from an SDK meter to a headless /context parser, then to an error rather than a wrong number. Keeps a before/after ledger per lever. Shows a live context breakdown in a pane or above the prompt. Report-only by default; fix applies one approved project trim.

context-budget reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.
