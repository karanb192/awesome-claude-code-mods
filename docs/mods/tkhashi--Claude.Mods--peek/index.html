peek

A Claude Code mod in tkhashi/Claude.Mods

Folds every tool call in the transcript to one line, and reads the conversation in a pane a page at a time: under your prompt, what Claude did between two of its messages, the pages before and after a press away

peek reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 17
  • Access from classified calls: L1, reads: reads settings, reads the transcript, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
