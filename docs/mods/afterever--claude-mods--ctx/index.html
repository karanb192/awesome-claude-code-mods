ctx

A Claude Code mod in afterever/claude-mods

Context window details like the Desktop app's panel: /ctx opens a pane that docks beside the transcript, and a 📊 button above the prompt toggles it.

Access

L2 Writes or runsother: $.state.get, other: $.state.set, runs processes, drives Claude, reads env vars, persists state, draws
