ctx

A Claude Code mod in afterever/claude-mods

Context window details like the Desktop app's panel: /ctx opens a pane that docks beside the transcript, and a 📊 button above the prompt toggles it.

ctx reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 12
  • API methods referenced: 20
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, reads env vars, reads settings, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
