limit-resume

A Claude Code mod in tyree88/tempered_plugins

Auto-resumes a turn killed by a rate limit or API error once the limit resets; shows 5h/7d usage and warns at 85%.

limit-resume reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
