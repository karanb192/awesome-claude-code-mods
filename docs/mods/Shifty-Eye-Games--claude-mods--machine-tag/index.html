machine-tag

A Claude Code mod in Shifty-Eye-Games/claude-mods

Prefixes session titles with this machine's emoji tag (💻 MBP, 🪶 Air, 🎮 Rig, 🔥 5090, ⚡ 4090), so pinned and listed sessions show which computer they run on

machine-tag reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.304.

  • Events hooked: 4
  • API methods referenced: 7
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, persists state
