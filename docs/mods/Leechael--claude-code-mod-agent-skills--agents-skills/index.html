agents-skills

A Claude Code mod in Leechael/claude-code-mod-agent-skills

Discover Agent Skills under .agents/skills (project) and ~/.agents/skills (user), expose them as slash commands, list them in prompt.context, and optionally intercept the Skill tool so names from those trees load without living under .claude/skills.
