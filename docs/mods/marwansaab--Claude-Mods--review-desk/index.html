review-desk

A Claude Code mod in marwansaab/Claude-Mods

A review desk panel (/reviews): Claude publishes open questions, decisions, findings, write plans, animated explainers and read-throughs; you answer, ask and submit in the panel, and the outcome goes back to Claude.

review-desk reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
