glitchdeck

A Claude Code mod in 0hte/glitchdeck

A mod that docks a live pane beside your conversation: what Claude is doing right now, every agent, workflow and background task it started as a process you can open, how fast it is writing, and every prompt you sent, one click away from its place in the transcript

glitchdeck reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.319.

  • Events hooked: 15
  • API methods referenced: 22
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, writes the clipboard, reads files, reads env vars, reads the transcript, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
