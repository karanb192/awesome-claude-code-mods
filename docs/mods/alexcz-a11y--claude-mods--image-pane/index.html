image-pane

A Claude Code mod in alexcz-a11y/claude-mods

在终端右侧停靠栏里显示本会话的图片：你发给 agent 的图，以及 agent（含子 agent）读到、截到、工具返回的图。只在终端里工作，Claude Desktop 里整个 mod 不做任何事。
