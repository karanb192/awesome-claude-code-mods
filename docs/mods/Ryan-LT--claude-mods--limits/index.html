limits

A Claude Code mod in Ryan-LT/claude-mods

Never get surprised by a rate limit again. An always-on band above the prompt shows your 5-hour and weekly Claude usage with live bars, reset countdowns and context-window fill. It turns red when your pace will run out before the reset, and warns you at 75%, 90% and 100%.

limits reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.319.
