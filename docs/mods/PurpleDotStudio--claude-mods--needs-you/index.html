needs-you

A Claude Code mod in PurpleDotStudio/claude-mods

Saves what the session needs from you and shows it in a side panel with two tabs: Asks (questions, approvals, blockers) and Inbox (news that needs no answer).

needs-you reaches L2 (writes or runs) and passed claude plugin validate.

  • Events hooked: 6
  • API methods referenced: 16
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, writes the clipboard, reads the prompt box, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
