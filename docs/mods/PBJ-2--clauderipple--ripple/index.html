ripple

A Claude Code mod in PBJ-2/clauderipple

Picks the reasoning effort for every prompt and the worker for every delegated task, can keep the prompt cache warm, and shows where ClaudeRipple sent each request.

The scan could not record a complete footprint for ripple, so its access is unknown; it passed claude plugin validate.

  • Access: unknown, the footprint is incomplete
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
