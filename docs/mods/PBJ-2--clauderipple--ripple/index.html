ripple

A Claude Code mod in PBJ-2/clauderipple

Picks the reasoning effort for every prompt and the worker for every delegated task, can keep the prompt cache warm, and shows where ClaudeRipple sent each request.

In its last recorded footprint, ripple reaches L3 (network) and has no recorded validation result.

  • Events hooked: 18
  • API methods referenced: 46
  • Access from classified calls: L3, network: network, MCP servers, runs processes, writes files, drives Claude, writes the prompt box, writes the clipboard, reads files, reads env vars, reads settings, reads the transcript, reads the prompt box, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
