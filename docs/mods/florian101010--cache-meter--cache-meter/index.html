cache-meter

A Claude Code mod in florian101010/cache-meter

Stop wasting tokens: keeps your prompt cache warm through breaks with /keepwarm, shows when it expires and what each answer costs.

cache-meter reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.312.
