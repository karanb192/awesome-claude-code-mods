ledger

A Claude Code mod in BuddyLim/claude-code-mod-ledger

The record of orchestrated work: runs of units and tasks, the subagents spawned for them, each gate's verdict and the findings reviewers report, summed up in the status line while there is something to say. It can follow a superpowers plan document as its input. Run /ledger.

ledger reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 11
  • API methods referenced: 23
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, writes the prompt box, reads files, reads the prompt box, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
