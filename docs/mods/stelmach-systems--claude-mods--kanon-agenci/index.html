kanon-agenci

A Claude Code mod in stelmach-systems/claude-mods

Panel „co robią agenci”: subagenci sesji ze statusem, REALNYM modelem każdego żądania (turn.step), tokenami i liczbą narzędzi; rozjazd tagu [S5.5] w opisie z modelem; licznik spawnów widzianych przez mod obok progu hooka kanon-agent-limit. /agenci [tekst|zamknij].

kanon-agenci reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 6
  • API methods referenced: 9
  • Access from classified calls: L1, reads: reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
