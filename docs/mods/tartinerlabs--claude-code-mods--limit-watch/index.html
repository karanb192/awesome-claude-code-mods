limit-watch

A Claude Code mod in tartinerlabs/claude-code-mods

Draws the 5-hour and weekly usage limits and the session's cost above the prompt, limits coloured by use, with reset countdowns and toasts at 80% and 95%.

limit-watch reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 3
  • API methods referenced: 8
  • Access from classified calls: L1, reads: reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
