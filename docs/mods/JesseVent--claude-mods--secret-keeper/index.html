secret-keeper

A Claude Code mod in JesseVent/claude-mods

Keeps the secrets you paste out of Claude's context and the transcript, stores them per project in the macOS Keychain, and hands them to Bash as environment variables. Optional PII hiding.

secret-keeper reaches L2 (writes or runs) and passed claude plugin validate.

  • Events hooked: 6
  • API methods referenced: 10
  • Access from classified calls: L2, writes or runs: runs processes, sets env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install secret-keeper --marketplace JesseVent/claude-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
