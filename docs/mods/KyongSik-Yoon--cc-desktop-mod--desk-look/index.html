desk-look

A Claude Code mod in KyongSik-Yoon/cc-desktop-mod

Claude Code mod that redraws the terminal transcript to look like the Code tab of the Claude desktop app: prompt bubbles, markdown tables, mermaid diagrams, folded tool calls, agent cards, plan cards in the transcript, a progress band of the current step and what runs now, GitHub/GitLab PR bar, diff, activity, context, background tasks, session monitor and Markdown preview panes. The Asana and Slack panes and the plan approval card are the separate desk-asana, desk-slack and desk-plan plugins
