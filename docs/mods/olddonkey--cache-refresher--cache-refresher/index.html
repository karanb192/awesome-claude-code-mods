cache-refresher

A Claude Code mod in olddonkey/cache-refresher

Shows when your prompt cache expires and what rebuilding it would cost. Optional auto-refresh, off by default, keeps it active while you are away and uses a little plan usage or API credit.

cache-refresher reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
