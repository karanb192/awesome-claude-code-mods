opum-lore

A Claude Code mod in opum-ai/lore-cli

Drive the lore CLI: author, retrieve, and maintain OKF documentation bundles, including explicit multi-repository workspaces. Cut from the same lore-cli repository and tag as the CLI itself, so this skill can never describe a version you don't have. Also ships the Lore pane: a pane that browses, reads (rendered and raw), searches, creates and edits the repository's documentation bundle through the lore CLI, editable in the session's own repository.
