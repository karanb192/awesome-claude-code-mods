contexto-costo

A Claude Code mod in Vincitorecode/mods-equipo

Barra de contexto bajo cada llamada (principal y subagentes), banda con contexto, costo y límites; /costo abre el detalle. · Context bar under each tool call, a band with context, cost and limits; /costo opens the details.

contexto-costo reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.
