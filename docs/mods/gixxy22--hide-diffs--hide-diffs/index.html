hide-diffs

A Claude Code mod in gixxy22/hide-diffs

Shows a one-line summary instead of the diff under Edit, Write, NotebookEdit and Bash calls (ctrl+q), and folds each shell command to one line (alt+q)

hide-diffs reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.
