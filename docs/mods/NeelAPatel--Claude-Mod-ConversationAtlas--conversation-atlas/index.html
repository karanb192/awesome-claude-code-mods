conversation-atlas

A Claude Code mod in NeelAPatel/Claude-Mod-ConversationAtlas

A live side pane that maps a long Claude Code session: goal, current path, possible detours, decisions, open questions, checkpoints, working files and what to resume next. It observes on its own and asks before changing your intent.

conversation-atlas reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 11
  • API methods referenced: 24
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, writes the prompt box, reads files, reads the transcript, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
