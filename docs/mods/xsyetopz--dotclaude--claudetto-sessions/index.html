claudetto-sessions

A Claude Code mod in xsyetopz/dotclaude

Measures the start of a Claude Code session by source, and the usage of each run: model calls, context that each call reads again, and skills that a period did not use.

In its last recorded footprint, claudetto-sessions reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
