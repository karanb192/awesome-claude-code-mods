session-bus

A Claude Code mod in yojoaquin/claude-session-bus

Lets Claude Code sessions (cloud and local) message each other and set each other's model and effort over an encrypted relay channel.

session-bus reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 5
  • API methods referenced: 18
  • Access from classified calls: L3, network: network, drives Claude, reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
