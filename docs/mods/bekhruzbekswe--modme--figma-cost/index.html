figma-cost

A Claude Code mod in bekhruzbekswe/modme

Read-only pane that shows what Figma design work costs in a session: spend, screens, iterations per screen, failures and tokens by agent. Spends no model tokens.

figma-cost reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 5
  • API methods referenced: 9
  • Access from classified calls: L3, network: MCP servers, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
