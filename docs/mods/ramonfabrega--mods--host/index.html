host

A Claude Code mod in ramonfabrega/mods

The box this session runs on: one band above the prompt with cpu, load, memory, swap traffic, disk, worktree trees, claude processes, ssh peers, tailscale; a pane behind it with the breakdown and the hungriest processes. /host toggles the band, /host pane the pane.
