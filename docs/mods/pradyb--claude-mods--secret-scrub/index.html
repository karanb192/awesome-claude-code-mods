secret-scrub

A Claude Code mod in pradyb/claude-mods

Catches API keys, tokens and private keys in the prompt you are about to send, and masks or blocks them before they reach the model.

secret-scrub reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 1
  • API methods referenced: 1
  • Access from classified calls: L0, draws and remembers: draws
  • Static scan, not a runtime test

Install hint

/plugin install secret-scrub --marketplace pradyb/claude-mods
