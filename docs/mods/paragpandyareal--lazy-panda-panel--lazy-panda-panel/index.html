lazy-panda-panel

A Claude Code mod in paragpandyareal/lazy-panda-panel

Review docs without lifting a paw. Your files open right where you’re working. Excel, Word, PDF, Markdown, Confluence (ADF), HTML and pictures: highlight a part, comment, and Claude edits the real file. Nothing to install (Word, Excel and PDF files over 4 MB need Python).
