aim

A Claude Code mod in Singh-AP/awesome-claude-mods

Pin one goal for the session: it sits above the prompt with a timer, and Claude is told to stay on it and flag unrelated work instead of drifting.

aim reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 5
  • API methods referenced: 13
  • Access from classified calls: L1, reads: reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install aim --marketplace Singh-AP/awesome-claude-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
