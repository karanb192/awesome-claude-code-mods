tldr-window

A Claude Code mod in icpmacdo/claude-mod-tldr-window

A side pane that keeps a TL;DR of what this Claude window is working on, refreshed after each turn from the cached transcript

tldr-window reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.310.

  • Events hooked: 7
  • API methods referenced: 20
  • Access from classified calls: L2, writes or runs: drives Claude, reads the transcript, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
