savvy-progress

A Claude Code mod in zaripovfarrukh/claude-code-mods

Live panel and progress band for subagents: model, context fill, tokens, estimated cost and time. Toggle with /agents-info.

savvy-progress reaches L1 (reads) and passed claude plugin validate with warnings on Claude Code 2.1.310.

  • API methods referenced: 8
  • Access from classified calls: L1, reads: reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
