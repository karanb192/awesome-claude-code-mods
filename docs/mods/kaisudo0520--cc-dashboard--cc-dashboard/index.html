cc-dashboard

A Claude Code mod in kaisudo0520/cc-dashboard

A live agent dashboard built on Flightdeck: main model vitals (with Fable weekly usage), the architect, every permission check, subagent cards and swimlanes (codex exec runs included), a turn receipt and a session log, plus Codex usage, the branch (unreviewed / changed files) and other sessions waiting on you. Real session data only.
