mokkan

A Claude Code mod in vicmpen/mokkan

Cross-session reminders: /mokkan toggles a live pane with your TODOs, Reminders and Archived tabs, /mokkan <command> runs push, in, edit, ack, done and the rest at once, and the /mokkan:mokkan skill lets Claude do it for you.

mokkan reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
