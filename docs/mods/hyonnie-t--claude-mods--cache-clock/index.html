cache-clock

A Claude Code mod in hyonnie-t/claude-mods

Shows how long the prompt cache stays warm, and when it expires, exactly how many tokens your next message will re-send uncached. No tokens spent.

cache-clock reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.316.

  • Events hooked: 2
  • API methods referenced: 7
  • Access from classified calls: L0, draws and remembers: persists state, draws
  • Static scan, not a runtime test
