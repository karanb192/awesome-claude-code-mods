goblin-scout

A Claude Code mod in JasonWarrenUK/goblin-mode

Scouted it, wrote it in the roadbook, lost the pencil. It keeps your plan as a map of what waits on what. Roadbooks as a dependency graph: JSON source of truth, mechanical status recompute, projected waypoint lists, Mermaid diagrams, an HTML chart, the interview, review and next-waypoint skills that drive it, and /scout-waypoints, a pane that shows the ready waypoints and starts a trail on one.
