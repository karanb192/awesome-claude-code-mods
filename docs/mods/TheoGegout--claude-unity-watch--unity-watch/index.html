unity-watch

A Claude Code mod in TheoGegout/claude-unity-watch

A live Unity pane for Claude Code: editor state, test runs with progress and history, builds, console errors and git, with one-click setup (Unity CLI, Pipeline package, editor install, Open Unity)

unity-watch reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 4
  • API methods referenced: 19
