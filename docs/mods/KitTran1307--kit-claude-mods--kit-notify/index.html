kit-notify

A Claude Code mod in KitTran1307/kit-claude-mods

A sound and a system notification when Claude finishes or needs you, a queue for prompts you type while Claude works (sent one at a time, with a remove button each), and a "while you were away" card when you come back. English and Vietnamese.

kit-notify reaches L2 (writes or runs) and passed claude plugin validate.

  • Events hooked: 12
  • API methods referenced: 19
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, writes the prompt box, reads env vars, reads settings, reads machine details, reads the prompt box, reads mod state, plays audio, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
