starfield

A Claude Code mod in cprentice9/ccmods

A theme for the desktop app: the usual dark gray with the dotted night sky from the foot of claude.dev behind the conversation, with its crescent moon and ringed planet. While Claude works, Clawd the astronaut floats in it, with a mini astronaut for each running subagent.

starfield reaches L1 (reads) by its classified calls and passed claude plugin validate.

  • API methods referenced: 9
  • Access from classified calls: L1, reads: reads mod state, draws
  • Calls in a namespace that is not in the Claude Code 2.1.302 core table: 1 ($.theme.set), full access unknown
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
