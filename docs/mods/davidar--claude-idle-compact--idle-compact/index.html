idle-compact

A Claude Code mod in davidar/claude-idle-compact In Anthropic directory

Compacts an idle interactive session shortly before its prompt cache expires, so coming back later doesn't re-read the whole context uncached.

idle-compact reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
