buffer-pane

A Claude Code mod in jidhra/claude-mods

A pane beside the transcript that holds the next things to tell the agent: write blocks of text while a turn runs, then press [+] to put one block into the prompt box.

In its last recorded footprint, buffer-pane reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.308.
