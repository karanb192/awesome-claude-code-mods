attachments

A Claude Code mod in thefuga/claude-x

The draft's attachments as chips above the prompt: each pasted picture, pasted text, @-mentioned file or folder and, with the issues mod, @# issue, with a glyph for its type, its path and what it is, and a × to take it out of the draft.
