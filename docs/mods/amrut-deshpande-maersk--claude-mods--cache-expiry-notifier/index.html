cache-expiry-notifier

A Claude Code mod in amrut-deshpande-maersk/claude-mods

Notifies you X minutes before your prompt cache expires so you can send a turn before paying the full re-cache cost.

cache-expiry-notifier reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
