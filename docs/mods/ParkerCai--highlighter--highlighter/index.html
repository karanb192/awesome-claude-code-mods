highlighter

A Claude Code mod in ParkerCai/highlighter

After each reply, Claude Haiku picks what to highlight: yellow for what needs your decision, blue for the key result, red for warnings, green for verified results. Color codes such as #0066CC are shown on their own color. The main model is never told. /highlight reads the last replies of a chat that has none; /highlight-preview shows what each color means.

highlighter reaches L2 (writes or runs) and passed claude plugin validate.

Install hint

/plugin install highlighter --marketplace ParkerCai/highlighter

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
