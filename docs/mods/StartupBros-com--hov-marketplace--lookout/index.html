lookout

A Claude Code mod in StartupBros-com/hov-marketplace

A second pair of eyes while Claude works. Every few model steps it asks one tool-less fork of the session (served from the prompt cache) whether there is something you should know and might miss, and shows the answer above the prompt. No model call while nothing draws the session.

lookout reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.316.

  • Events hooked: 6
  • API methods referenced: 9
  • Access from classified calls: L2, writes or runs: drives Claude, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
