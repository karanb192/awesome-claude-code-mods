cache-clock

A Claude Code mod in tylergraydev/cc-mods

A prompt-cache countdown in the status line, and a Compact / Handoff / Clear band once the cache has lapsed

cache-clock reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 7
  • API methods referenced: 15
  • Access from classified calls: L2, writes or runs: drives Claude, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
