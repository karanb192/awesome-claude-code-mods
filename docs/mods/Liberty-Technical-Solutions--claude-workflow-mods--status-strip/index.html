status-strip

A Claude Code mod in Liberty-Technical-Solutions/claude-workflow-mods

One quiet strip above the prompt: repo, docs, deploy, context and cache, each with its own button. Includes Compress with a confirmation and a cache settings dropdown.

status-strip reaches L3 (network) and passed claude plugin validate with warnings on Claude Code 2.1.304.
