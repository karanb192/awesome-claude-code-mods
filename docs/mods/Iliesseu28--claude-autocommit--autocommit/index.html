autocommit

A Claude Code mod in Iliesseu28/claude-autocommit

Turns every turn Claude takes into a clean git commit: only the files that turn changed, a Conventional Commits message written by Haiku, a secret scan before every commit, undo and squash. Plus a band above the prompt with model, effort, context and commits.
