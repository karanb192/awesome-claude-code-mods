acp-ui

A Claude Code mod in huydepzai121/claude-acp-ui

Restyles the Claude Code terminal like an ACP chat: prompt and tool cards, inline diffs, a status band, footer stats, a /dash pane and a done toast

acp-ui reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 9
  • API methods referenced: 23
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, writes the prompt box, reads the prompt box, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
