daily-command-center

A Claude Code mod in tenfoldmarc/claude-code-mods

Every morning Claude asks for the three tasks you need to do today, then pins them in a side pane next to your revenue and key numbers.

daily-command-center reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 4
  • API methods referenced: 13
  • Access from classified calls: L3, network: network, runs processes, reads mod state, plays audio, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
