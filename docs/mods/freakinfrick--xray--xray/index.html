xray

A Claude Code mod in freakinfrick/xray

xray's Claude Code host: two glanceable cards under the spinner, what Claude is doing and its to-do list, plus a session genome (every step, one colored cell). The same core also runs in omp, pi, Hermes, Grok Build and dsh-tui.
