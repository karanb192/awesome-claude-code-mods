message-timestamps

A Claude Code mod in derekwden-droid/message-timestamps

Shows the time above each prompt you send and each reply Claude starts, in the terminal and the desktop app's Code tab, as clock times or as time since. /timestamps switches between clock, relative and off.

message-timestamps reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 8
  • API methods referenced: 13
  • Access from classified calls: L1, reads: reads files, persists state, draws
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
