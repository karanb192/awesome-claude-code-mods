token-weather

A Claude Code mod in Nasrallah-Adel/claude-token-weather

A live forecast of the context window above the prompt, with the 5-hour and 7-day usage windows, the session cost, today's spend and the subagent tally on the same line; buttons, a /weather command and a pane; and optional actions: auto-compact at a threshold, prompt guards on the rate window or a cost cap, a model downshift offer, native notifications and sound.

token-weather reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • API methods referenced: 25
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, plays audio, persists state, draws
