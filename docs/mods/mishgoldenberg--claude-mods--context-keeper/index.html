context-keeper

A Claude Code mod in mishgoldenberg/claude-mods

Live context-window panel: what fills it, checkpoints before you compact or clear, and nudges before you hit the wall.

context-keeper reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.304.
