outgoing-secret-guard

A Claude Code mod in NarenDawar/narens-claude-toolkit

Redacts API keys, tokens and private keys from your prompts before the model sees them, and blocks network-bound tool calls that carry one.

outgoing-secret-guard reaches L0 (draws and remembers) and passed claude plugin validate with warnings.

  • Events hooked: 2
  • API methods referenced: 1
  • Access from classified calls: L0, draws and remembers: draws
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
