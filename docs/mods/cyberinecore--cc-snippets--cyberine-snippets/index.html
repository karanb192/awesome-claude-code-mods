cyberine-snippets

A Claude Code mod in cyberinecore/cc-snippets In Anthropic directory

Keyboard picker for your saved prompts: search snippet files, fill their placeholders, and drop them into the Claude Code prompt box, plus create, edit, duplicate, move, pin, delete and restore snippets without leaving the session. Snippets are plain Markdown files, not skills, so they cost the model no context until you use one. To work, it watches what you type in the prompt box for the ;; trigger and reads your draft only to insert a snippet or save it as one; a snippet marked submit is sent as a prompt only after you pick it; while you edit a snippet body, Enter saves it instead of sending. It stores usage counts and your last placeholder values locally and makes no network requests.

The scan could not record a complete footprint for cyberine-snippets, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.310.
