glanceflow

A Claude Code mod in Antreas-Strb/glanceflow

GlanceFlow: see what Claude is doing, at a glance. Hides tool rows and shows one plain-English checklist above the prompt, with progress, helpers, history, a team report, pause and continue, and a password guard.
