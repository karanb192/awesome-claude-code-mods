devrep

A Claude Code mod in pomesaka/dotclaude

update_devrep tool: while turned on for a session, the agent keeps a short report of where the work stands (doing now, next, and free sections) in a pane, so the user can pick the session back up without reading the transcript

devrep reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
