muninn

A Claude Code mod in tauantcamargo/claude-mods

Muninn, Odin's raven of memory: your ai-memory in Claude Code. A /muninn pane (and a /mods tab) with the project's memory, the last handoff, search and recent pages, a status-line count and a toast when a handoff arrives.

muninn reaches L3 (network) by its classified calls and passed claude plugin validate on Claude Code 2.1.316.

  • Events hooked: 7
  • API methods referenced: 24
  • Access from classified calls: L3, network: network, runs processes, writes the clipboard, reads files, reads env vars, reads mod state, persists state, draws
  • Calls in a namespace that is not in the Claude Code 2.1.302 core table: 1 ($.skins.palette), full access unknown
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
