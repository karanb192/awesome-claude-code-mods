dca-factory-cockpit

A Claude Code mod in domain-centric-development/dca-marketplace

Claude Code only, optional: the dca-factory cycle as a cockpit in a pane: the foundation (describe, set up) beside the cycle discover, backlog, run, decide, delivered: live, with a background worker. Draws what factory.sh prints; the factory works the same without it.

dca-factory-cockpit reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 5
  • API methods referenced: 22
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, writes the prompt box, reads files, reads settings, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
