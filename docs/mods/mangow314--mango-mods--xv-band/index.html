xv-band

A Claude Code mod in mangow314/mango-mods

A row above the prompt with live status of xvendor (xv) cross-vendor jobs: one line per running job or job finished in the last 10 minutes (vendor, round, state, time, latest action, job suffix). Needs xvendor.

L2 Writes or runsother: $.state.get, other: $.state.set, runs processes, reads files, reads env vars, draws
