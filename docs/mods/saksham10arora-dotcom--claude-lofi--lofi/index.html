lofi

A Claude Code mod in saksham10arora-dotcom/claude-lofi

A lofi soundtrack that follows the session: calm while Claude is idle, focus while it works, flow during heavy editing, a chime when tests pass and a low note when they fail. Off until /lofi on. Original music, synthesised for this mod. Needs function hooks (early access).

lofi reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 5
  • API methods referenced: 6
  • Access from classified calls: L0, draws and remembers: plays audio, persists state
  • Static scan, not a runtime test
