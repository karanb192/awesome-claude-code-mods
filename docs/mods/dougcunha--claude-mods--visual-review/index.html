visual-review

A Claude Code mod in dougcunha/claude-mods

The /visual-review command shows the design of the changes against a base branch as a diagram in the browser: classes and modules with their relations, size and quality notes, and the database tables. Comment on the diagram and send the review back to the session in one step.

visual-review reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 7
  • API methods referenced: 20
  • Access from classified calls: L2, writes or runs: runs processes, writes files, drives Claude, reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
