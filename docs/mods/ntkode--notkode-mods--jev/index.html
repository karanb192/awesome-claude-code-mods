jev

A Claude Code mod in ntkode/notkode-mods

Jev picks the tool that fits Claude's next step and Claude gets it as a hint, shown live and measured against a control group. Native to Claude Code: no gateway, no proxy.

The scan could not record a complete footprint for jev, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.310.

  • Access: unknown, the footprint is incomplete
  • Static scan, not a runtime test
