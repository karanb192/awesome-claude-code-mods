pult

A Claude Code mod in Egor062020/claude-code-pult

A control panel for Claude Code: quick-reply chips and a status band above the prompt, and a scrolling pane of cards for context, limits, prompt cache, deadlines from your notes, work areas and an SSH server. English and Russian.
