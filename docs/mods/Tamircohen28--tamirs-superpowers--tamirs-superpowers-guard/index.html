tamirs-superpowers-guard

A Claude Code mod in Tamircohen28/tamirs-superpowers

In-process guard for tamirs-superpowers: holds a destructive shell command (force push, rm -rf, git reset --hard, ...) until you answer Proceed or Cancel, and refuses a file write in the main checkout while an orchestration objective is active. Companion to the core plugin; Claude Code and Claude Desktop only.

tamirs-superpowers-guard reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.
