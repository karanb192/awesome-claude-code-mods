code-mode

A Claude Code mod in kzarzycki/claude-mods

Claude Code's Code Mode as a mod: one `repl` tool runs JavaScript in a persistent kernel with $, file, edit, write, tools and agent(). Preferred beside the other tools, or the one way to work when the session denies them.

code-mode reaches L3 (network) by its classified calls and passed claude plugin validate with warnings.

  • Events hooked: 6
  • API methods referenced: 14
  • Access from classified calls: L3, network: network, runs processes, drives Claude, reads env vars, draws
  • Calls in a namespace that is not in the graded core table: 1 ($.decision.ask), full access unknown
  • Static scan, not a runtime test

Install hint

/plugin install code-mode --marketplace kzarzycki/claude-mods
