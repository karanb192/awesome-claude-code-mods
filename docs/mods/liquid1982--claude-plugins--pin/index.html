pin

A Claude Code mod in liquid1982/claude-plugins

Marks conversation content wrapped in <pin>...</pin> tags as compaction-proof: pinned content is re-injected verbatim into the transcript after every compaction (manual /compact, auto-compaction, plugin-triggered, or precompute).

pin reaches L1 (reads) and passed claude plugin validate with warnings on Claude Code 2.1.304.

  • Events hooked: 2
  • API methods referenced: 4
  • Access from classified calls: L1, reads: reads the transcript, draws
  • Static scan, not a runtime test
