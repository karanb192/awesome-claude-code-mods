md-prompt

A Claude Code mod in nogu66/md-prompt In Anthropic directory

Paints Markdown onto Claude Code's prompt box as you type: fenced code becomes a syntax-highlighted card (even before you close the fence), and inline code, bold, italic, lists, task lists, quotes, tables, links and headings are styled. Paint only, your text is never changed.

md-prompt reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
