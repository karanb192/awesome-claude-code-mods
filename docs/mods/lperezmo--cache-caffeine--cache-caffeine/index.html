cache-caffeine

A Claude Code mod in lperezmo/cache-caffeine In Anthropic directory

Keeps the prompt cache warm while you step away: a short poke before the cache expires, so the next turn reads the cache instead of writing it again. A row above the prompt turns it on and off and edits the message. Near the usage limit it books Claude a wake right after the reset.

cache-caffeine reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
