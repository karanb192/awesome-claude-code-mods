session-pings

A Claude Code mod in fixter-dev/session-pings

Mac notifications titled with the session name, saying what Claude needs from you: done, a question, or a permission. Works out of the box; install terminal-notifier (brew install terminal-notifier) to make notifications clickable, which brings you back to the app you were using.

session-pings reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 6
  • API methods referenced: 9
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, reads files, reads env vars, persists state, draws
