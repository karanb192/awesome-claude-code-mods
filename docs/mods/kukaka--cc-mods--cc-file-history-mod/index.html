cc-file-history-mod

A Claude Code mod in kukaka/cc-mods

AbovePrompt band (auto-shows the edit count) + Pane (file-grouped list with [Revert]). Click the band's [View] (or /file-history) to open the Pane and revert.

cc-file-history-mod reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 6
  • API methods referenced: 13
  • Access from classified calls: L2, writes or runs: runs processes, writes files, reads files, reads env vars, draws
  • Static scan, not a runtime test
