cc-dock

A Claude Code mod in New-Retr0/claude-dock

A dock above the prompt: plan usage windows, main and subagent context fill, and the shells running now with what each one is doing.

cc-dock reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 13
  • API methods referenced: 32
  • Access from classified calls: L3, network: network, runs processes, drives Claude, writes the prompt box, reads files, reads env vars, reads settings, plays audio, persists state, draws
  • Static scan, not a runtime test

/plugin install cc-dock --marketplace New-Retr0/claude-dock
