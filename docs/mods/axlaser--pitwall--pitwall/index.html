pitwall

A Claude Code mod in axlaser/pitwall

A pit wall for Claude Code: a live box above the prompt (context, model, effort, git, tokens), a side panel of rate limits, the session's cost and who spent it, the prompt cache, the advisor and subagents you can stop, fourteen themes that repaint Claude Code, and alert sounds

pitwall reaches L0 (draws and remembers) and passed claude plugin validate with warnings.

  • Events hooked: 2
  • API methods referenced: 1
  • Access from classified calls: L0, draws and remembers: draws
  • Static scan, not a runtime test

Install hint

/plugin install pitwall --marketplace axlaser/pitwall

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
