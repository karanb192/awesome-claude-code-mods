cache-tax

A Claude Code mod in Berkay2002/berkays-mods

Keeps the one-hour prompt cache warm during breaks (/keepwarm) and shows a cold send's estimated rewrite cost; this copy warns by default instead of refusing. Warming costs tokens. Copy of karanb192/cache-tax 2.2.1.

cache-tax reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.304.

  • Events hooked: 9
  • API methods referenced: 18
  • Access from classified calls: L2, writes or runs: drives Claude, reads env vars, reads settings, persists state, draws
