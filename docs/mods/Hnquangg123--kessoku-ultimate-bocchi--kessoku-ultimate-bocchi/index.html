kessoku-ultimate-bocchi

A Claude Code mod in Hnquangg123/kessoku-ultimate-bocchi

Kessoku Ultimate Bocchi Theme: a Bocchi the Rock!-inspired charcoal-and-pink skin for all of Claude Code (an engine theme plus every render site), a live Kessoku Band panel with the band on stage as animated pixel-art sprites under spotlights and their subagents as songs on a setlist (solo any member) and band subagent types Claude can delegate to by name, and themed Cache Tax, Blast Radius, Filetree, Reflect and Replay Theater gags.
