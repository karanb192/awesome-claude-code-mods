slots

A Claude Code mod in WorldInnovationsDepartment/claude_slots

Pins a small pixel-art slot machine in a neon cyberpunk style to the bottom-right of the screen, above the prompt: pull the trigger on every prompt, the reels keep turning while Claude works, and you might win a FEATURE, a CLIENT, or a LIFE.

slots reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.319.

  • Events hooked: 5
  • API methods referenced: 10
  • Access from classified calls: L0, draws and remembers: persists state, draws
