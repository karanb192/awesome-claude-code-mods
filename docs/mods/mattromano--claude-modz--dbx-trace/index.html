dbx-trace

A Claude Code mod in mattromano/claude-modz

Flight recorder for Databricks: every query, script and guardrail block Claude makes, in a band above the prompt and a per-session HTML trace with deep links

dbx-trace reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 8
  • API methods referenced: 17
  • Access from classified calls: L3, network: MCP servers, runs processes, writes files, drives Claude, reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
