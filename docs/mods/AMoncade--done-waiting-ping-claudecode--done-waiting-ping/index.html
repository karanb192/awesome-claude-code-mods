done-waiting-ping

A Claude Code mod in AMoncade/done-waiting-ping-claudecode

A desktop notification and/or a sound when a long Claude Code turn is done or when Claude is waiting on you (permission, question, plan). Native on Windows, also macOS and Linux. Choose popup, sound or both, done or waiting or both, and the sounds.

done-waiting-ping reaches L2 (writes or runs) and passed claude plugin validate.

  • Events hooked: 7

  • Access from classified calls: L2, writes or runs: runs processes, reads env vars, persists state, draws
