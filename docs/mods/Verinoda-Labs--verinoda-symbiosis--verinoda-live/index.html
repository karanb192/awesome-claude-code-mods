verinoda-live

A Claude Code mod in Verinoda-Labs/verinoda-symbiosis

Verinoda in Claude Code: keeps the code index fresh while Claude edits, checks each edit for names that do not exist, reviews commits, lists what could be changed for you to choose (/verinoda-improve), and shows it all in a Turkish pane with an animated mascot.

verinoda-live reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 10
  • API methods referenced: 17
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
