session-dashboard

A Claude Code mod in comdoly-life/claude-session-dashboard

Live dashboard pane (Korean UI): top tabs for every Claude Code session on the machine by folder and for this session's folder, this one and its folder marked, each messaged or ended from its tab; the main session, subagents, agent teams and workflows, each with what it is doing, progress (done/total), tokens and run time, plus detail tabs; above the prompt, the 5-hour / weekly limit bars with what is left, chips for the model and effort, and toggles for workflows and ultracode

session-dashboard reaches L1 (reads) and passed claude plugin validate with warnings.

  • Events hooked: 17
  • API methods referenced: 12
  • Access from classified calls: L1, reads: reads settings, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
