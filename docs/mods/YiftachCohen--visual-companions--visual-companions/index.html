visual-companions

A Claude Code mod in YiftachCohen/visual-companions

Draws agent ```viz blocks as compact visuals, keeps the latest headline above the prompt, /catchup shows recent ones. Costs the model ~400 cached prompt tokens + ~80 per visual.

visual-companions reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.304.
