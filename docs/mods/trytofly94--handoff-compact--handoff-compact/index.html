handoff-compact

A Claude Code mod in trytofly94/handoff-compact

Replaces Claude Code's compaction with a structured handoff: a fork of the session writes it from the prompt cache, and the conversation continues from exactly that handoff.

handoff-compact reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 3
  • API methods referenced: 14
  • Access from classified calls: L2, writes or runs: runs processes, writes files, drives Claude, reads files, reads env vars, reads the transcript, draws
