widget-bridge

A Claude Code mod in kirishimarisano-rgb/Mods-Claude-code-0-powerd-by-claude

Sends each local session's status (what Claude is doing, task progress, context and usage) to the Claude Widget desktop app on this computer, and takes its Stop button

widget-bridge reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 8
  • API methods referenced: 12
  • Access from classified calls: L3, network: network, drives Claude, reads mod state, persists state
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
