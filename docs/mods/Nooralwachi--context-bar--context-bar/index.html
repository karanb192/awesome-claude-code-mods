context-bar

A Claude Code mod in Nooralwachi/context-bar

Draws the context window as a stacked bar above the prompt, one color per /context category. Toggle with /context-bar.

context-bar reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 5
  • API methods referenced: 7
  • Access from classified calls: L0, draws and remembers: persists state, draws
  • Static scan, not a runtime test
