brickfall

A Claude Code mod in reporails/arcade

A brick breaker in a Claude Code pane, after Arkanoid: steer with the mouse, catch capsules, chain volt bricks, over a shimmering iridescent field. A real picture in kitty and Ghostty, block characters elsewhere.

brickfall reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.
