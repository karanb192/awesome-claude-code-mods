mcs-playwright-test-progress-mod

A Claude Code mod in mcs-dave/mcs-fusion-playwright-test-progress-mod

Live dashboard for a Playwright (or any) test run: a pane, a progress band above the prompt and a status-line entry, read from a small status.json that the test runner writes.

mcs-playwright-test-progress-mod reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.
