prompt-queue

A Claude Code mod in Demo-0416/claude-code-mods

Codex-style queued follow-up inputs: the queue key while a turn runs holds the prompt until the turn ends, one per turn; alt+↑ edits the last one; an interrupt puts them back in the composer

prompt-queue reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 5
  • API methods referenced: 10
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, reads files, reads env vars, reads the prompt box, reads mod state, draws
