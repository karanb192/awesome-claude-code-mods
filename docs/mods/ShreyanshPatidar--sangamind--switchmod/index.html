switchmod

A Claude Code mod in ShreyanshPatidar/sangamind

SwitchMod: useful extras for Claude Code, each one a switch. A usage meter above the prompt, an output viewer for long results and images, secret hiding, a stop for repeated failures, a check before risky commands, a work log, and coordination between parallel chats. /switchmod turns each on or off.

switchmod reaches L0 (draws and remembers) and passed claude plugin validate with warnings.

  • Events hooked: 1
  • API methods referenced: 3
  • Access from classified calls: L0, draws and remembers: draws
  • Static scan, not a runtime test

Install hint

/plugin install switchmod --marketplace ShreyanshPatidar/sangamind

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
