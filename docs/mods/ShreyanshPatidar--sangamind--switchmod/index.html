switchmod

A Claude Code mod in ShreyanshPatidar/sangamind

SwitchMod: useful extras for Claude Code, each one a switch. A usage meter above the prompt, an output viewer for long results and images, secret hiding, a stop for repeated failures, a check before risky commands, a work log, and coordination between parallel chats. /switchmod turns each on or off.

The scan could not record a complete footprint for switchmod, so its access is unknown; it passed claude plugin validate with warnings on Claude Code 2.1.310.
