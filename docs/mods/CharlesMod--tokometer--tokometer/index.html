tokometer

A Claude Code mod in CharlesMod/tokometer

A token speedometer beside the prompt: live tokens per second across this session, its subagents and every other local Claude Code session, scaled to your all-time peak.

tokometer reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.304.
