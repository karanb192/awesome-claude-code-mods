savvy-status

A Claude Code mod in rakavanagh/savvy-status

Savvy Status: one pane per session with the Main Agent on top and every subagent below as a crab dressed for its role. Hover any agent to see a live file tree of what it is reading and writing; hover the gear crab (bottom right) for the delegation switch, model / effort / look per role, a concurrency cap and your orchestration rules.
