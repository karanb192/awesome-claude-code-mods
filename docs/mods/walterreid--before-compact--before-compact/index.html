before-compact

A Claude Code mod in walterreid/before-compact

Keeps your last turns, verbatim, across compaction. PreCompact hooks save the last turns verbatim, yours and the assistant's as two bundles (and the full arc beside them); SessionStart hooks re-inject each as its own block after compaction. /before-compact:recover does it on demand; /before-compact opens a monitor pane with the summary the engine installed.

before-compact reaches L2 (writes or runs) and passed claude plugin validate.
