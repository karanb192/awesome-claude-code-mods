cc-jev-pruner

A Claude Code mod in masseater/cc-jev-teacher

Keeps Claude Code's context small with a decision model on OpenRouter: compacts without a summary by dropping tool calls the task no longer needs, trims long Bash output to the parts that matter, and finds the code behind a behavior with Jevgrep

cc-jev-pruner reaches L3 (network) and passed claude plugin validate with warnings on Claude Code 2.1.310.

  • Events hooked: 3
  • API methods referenced: 12
  • Access from classified calls: L3, network: network, writes files, drives Claude, reads files, reads env vars, reads the transcript, draws
  • Static scan, not a runtime test
