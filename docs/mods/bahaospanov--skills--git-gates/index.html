git-gates

A Claude Code mod in bahaospanov/skills

Gates git work: no commit, push or merge without the user's say-so in the current turn; a push to a branch that already landed is refused; an MR whose branch lacks the target's latest commit is refused; a pushed series must leave the project working at every commit; commit messages (format and the issue it is about, then a Haiku review of the body) and MR descriptions kept tidy.
