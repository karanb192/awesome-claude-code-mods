jevmate

A Claude Code mod in GastonGelhorn/jevmate

A fast decision layer for coding agents. Jev ranks files, picks the tests a change can break, sorts failures and reviews diffs by risk, so Claude reads only what matters and judges only what Jev is unsure of. Also: long output trimmed, compaction that keeps what the work still needs and saves the rest on disk, safety signals on Bash and fetched content, and the session's numbers above the prompt. Thresholds measured, not guessed.

jevmate reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
