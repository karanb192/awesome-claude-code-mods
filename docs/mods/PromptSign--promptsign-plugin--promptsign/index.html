promptsign

A Claude Code mod in PromptSign/promptsign-plugin

Verifies signatures on the instruction files Claude Code loads, meaning CLAUDE.md, skills, and agent definitions, before they reach model context. It re-checks a skill bundle before the Skill tool runs it. Sigstore keyless, offline verification against a pinned trust root, no telemetry.

promptsign reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 3
  • API methods referenced: 3
  • Access from classified calls: L2, writes or runs: runs processes, reads env vars, draws
  • Static scan, not a runtime test
