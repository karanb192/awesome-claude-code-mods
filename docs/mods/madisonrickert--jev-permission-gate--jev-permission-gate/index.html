jev-permission-gate

A Claude Code mod in madisonrickert/jev-permission-gate

Uses TypeSafe's Jev to allow or deny routine tool calls in auto mode, and hands uncertain ones to the built-in classifier

jev-permission-gate reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 7
  • API methods referenced: 13
  • Access from classified calls: L3, network: network, writes files, reads files, reads env vars, reads the transcript, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
