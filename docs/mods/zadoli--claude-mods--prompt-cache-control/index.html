prompt-cache-control

A Claude Code mod in zadoli/claude-mods

Prompt-cache meter above the Claude Code prompt: how many tokens each request read from, wrote to and sent past the cache, a live countdown to the cache's expiry, and what to do about it (keep going, compact or clear). The TTL follows Claude Code's own rules for your account (1 hour on a Claude subscription, 5 minutes on an API key, cloud provider or usage credits, plus the TTL variables and setting) and corrects itself from request timing. /cache opens a per-turn table; /keepwarm pings the cache after idle stretches so it never lapses (ported from cache-tax).

prompt-cache-control reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
