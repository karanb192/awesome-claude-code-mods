mods-toolbox

A Claude Code mod in rube-de/cc-skills

Mods Toolbox - Function-hook mods (Claude Code 2.1.291+): Clean View, a calm checklist above the prompt for non-technical users that hides tool calls, diffs and command output while showing the plan, the current step and its progress; the Agent Dock, which splits each request across a chosen team of parallel helpers shown as live cards; and the Status Line Dock, which builds Claude Code's status line from blocks with a live preview; one Toolbox popup above the prompt holds the mods' settings and switches Claude's model and effort
