session-bridge

A Claude Code mod in tsurutanmen/session-bridge

Talk to your Claude Code sessions from other sessions, your voice, or any local program. Meetings between two sessions, and a talk button that reads replies aloud.

session-bridge reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
