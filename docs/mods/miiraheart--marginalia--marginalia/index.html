marginalia

A Claude Code mod in miiraheart/marginalia

Select text in the conversation, then quote it into your prompt (it stays outlined), ask about it, turn it into a task or keep it. Theme mods can draw its bar in their own style.

marginalia reaches L2 (writes or runs) by its classified calls and passed claude plugin validate on Claude Code 2.1.316.

  • Events hooked: 14
  • API methods referenced: 23
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, writes the prompt box, writes the clipboard, reads files, reads env vars, reads the selection, reads the prompt box, reads mod state, draws
  • Calls in a namespace that is not in the Claude Code 2.1.302 core table: 2 ($.prismantis.markdown, $.skins.markdown), full access unknown
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
