usage-drill

A Claude Code mod in l-a-motta/motta-claude-mods

A Usage pane: each rate limit (5h, 7d) as one line, motta-statusline's bar with a tick where the window's time stands, its percent and when it resets, then a verdict in its color (on track, tight, ahead of pace, runs out at 21:05). Under details, 5h and 7d side by side: the readings this window against an even pace, burn rate, hourly budget, cost per turn, this session's share, past windows, and when each clears; then the weekly limit's activity, a GitHub-style grid of days by hours and a cross of the spend by model family; a row only where it has something to say. Toasts when a limit passes a threshold or turns orange or red. No request sent: it reads only the limits each response reports, kept between sessions. Opened by /usage-drill, or by $.usageDrill.open() from another mod (motta-statusline's 5h and 7d).

usage-drill reaches L0 (draws and remembers) and passed claude plugin validate with warnings.

  • API methods referenced: 10
  • Access from classified calls: L0, draws and remembers: persists state, draws
