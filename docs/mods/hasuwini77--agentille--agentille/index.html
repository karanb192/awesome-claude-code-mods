agentille

A Claude Code mod in hasuwini77/agentille

One typed command runs the work: /agt plans, builds and reviews with the right model per step, steps aside on small tasks, and ends on one short card. Also typed-only: /storm picks what to build next, /agt-spawn and "open two sessions" open panes beside you, /agentille-init writes your voice profile, /agentille-project and /agentille-claude-md tend a CLAUDE.md; the /agt-* commands read or tidy. A guard holds every run below its integration ceiling. No profile or config needed; every surface has a switch.
