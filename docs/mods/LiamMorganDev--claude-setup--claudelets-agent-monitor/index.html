claudelets-agent-monitor

A Claude Code mod in LiamMorganDev/claude-setup

Live pane of the current request: % complete, tokens and what each agent and subagent is doing, with a pixel Claude per agent dressed for its job, numbered when two share a type, nested under their parent; a Team roster of your ~/.claude/agents with status and last use; toasts (silently) when Claude needs you, gets stuck or finishes; masks secrets; finish summary and a 30-day request history

claudelets-agent-monitor reaches L3 (network) and passed claude plugin validate with warnings.
