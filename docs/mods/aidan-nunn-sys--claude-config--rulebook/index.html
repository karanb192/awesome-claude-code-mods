rulebook

A Claude Code mod in aidan-nunn-sys/claude-config

Hard rules on tool calls, kept in ~/.claude/rulebook.json; Claude adds a rule when you correct it. /rules lists or removes them.

rulebook reaches L2 (writes or runs) and passed claude plugin validate with warnings.

  • Events hooked: 4
  • API methods referenced: 11
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
