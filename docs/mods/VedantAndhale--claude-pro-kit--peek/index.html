peek

A Claude Code mod in VedantAndhale/claude-pro-kit

Typing "status" while background shells or subagents run opens a pane with each task's exact elapsed time, the tail of its output and any percent it printed, instead of sending the prompt to Claude. /peek opens it too. No tokens spent.

peek reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 10
  • API methods referenced: 10
  • Access from classified calls: L1, reads: reads files, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install peek --marketplace VedantAndhale/claude-pro-kit

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
