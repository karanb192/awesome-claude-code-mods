A Claude Code mod in Dos2Locos/claude-code-mods

Clean View y Context Bar en una caja: oculta las herramientas, muestra la tarea en curso con su progreso y el uso de la ventana de contexto.

clean-bar reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.
