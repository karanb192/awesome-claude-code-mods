auto-handoff

A Claude Code mod in m2ai-portfolio/claude-mods

Writes a /next handoff automatically once a 1M-token session crosses 300k tokens, so the next session can /prime from it

auto-handoff reaches L3 (network) and passed claude plugin validate with warnings on Claude Code 2.1.304.

  • Events hooked: 7
  • API methods referenced: 18
  • Access from classified calls: L3, network: MCP servers, runs processes, writes files, drives Claude, writes the clipboard, reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
