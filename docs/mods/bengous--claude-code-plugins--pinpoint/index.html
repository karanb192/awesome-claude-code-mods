pinpoint

A Claude Code mod in bengous/claude-code-plugins

Point at your running app and talk to Claude: the session's address serves the app with an overlay that picks an element by a click or a zone by a drag, takes a quick label or a note, and keeps each selection in a batch you send at once; the batch reaches the session as a prompt, each element described by its selector, role, accessible name, box and styles, each zone with an image of it
