heads-up

A Claude Code mod in soenkenils/claude-code-mods

Watches the running session and shows a heads-up when something is off: failing tools or tests in a row, edits outside the project, a context spike, or a run that stalls.

heads-up reaches L1 (reads) and passed claude plugin validate.

  • Events hooked: 7
  • API methods referenced: 11
  • Access from classified calls: L1, reads: reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install heads-up --marketplace soenkenils/claude-code-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
