statusline-anywhere

A Claude Code mod in NathanAB/statusline-anywhere

Shows your Claude Code status line in the Claude Desktop app. Runs the statusLine command you already have and draws its output above the prompt. Changes nothing in the terminal.

statusline-anywhere reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 3
  • API methods referenced: 14
  • Access from classified calls: L2, writes or runs: runs processes, reads env vars, reads settings, draws
  • Static scan, not a runtime test
