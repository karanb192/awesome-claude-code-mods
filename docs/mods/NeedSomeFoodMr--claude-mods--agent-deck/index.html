agent-deck

A Claude Code mod in NeedSomeFoodMr/claude-mods

A pane showing the main loop and every subagent of the session as pixel crabs, each under its role's hat: a short name, role, model, plan progress, context fill, tokens, estimated cost and time, with totals on top and the finished ones kept below; while agents work, one line above the prompt says how the run stands.

agent-deck reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.304.

  • Events hooked: 13
  • API methods referenced: 16
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, reads settings, reads the prompt box, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
