turn-monitor

A Claude Code mod in SentientNr6/claude-mods

Shows each finished turn's time, tokens, context fill, CPU load and free memory in a band above the prompt, and logs every turn to a JSONL file. CPU, memory and the log need Windows.

turn-monitor reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.310.

  • Events hooked: 7
  • API methods referenced: 13
  • Access from classified calls: L2, writes or runs: runs processes, writes files, reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install turn-monitor --marketplace SentientNr6/claude-mods
