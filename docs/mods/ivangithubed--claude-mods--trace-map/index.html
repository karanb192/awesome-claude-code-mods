trace-map

A Claude Code mod in ivangithubed/claude-mods

A pane that shows live what Claude is doing: the turn's phase, the last tool, and every file it touched

trace-map reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Access from classified calls: L1, reads: reads settings, persists state, draws
