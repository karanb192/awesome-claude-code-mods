cache-meter

A Claude Code mod in Spendry/claude-code-mods

Shows above the prompt how warm the prompt cache is, what a cache miss would cost to rewrite, context fill, and the session's API-rate cost

cache-meter reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 6
  • API methods referenced: 9
  • Access from classified calls: L0, draws and remembers: persists state, draws
  • Static scan, not a runtime test

Install hint

/plugin install cache-meter --marketplace Spendry/claude-code-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
