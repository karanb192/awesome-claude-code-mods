task-router

A Claude Code mod in omeerdvrn/o-mods

Routes every task to a worker subagent on the right model tier (Haiku, Sonnet, Opus) by rules you own, tracks it in a registry, and shows each model as a Claude crab in a status sidebar. Works with Superpowers: it plans, the router executes.

task-router reaches L2 (writes or runs) and passed claude plugin validate.

  • Events hooked: 6
  • API methods referenced: 9
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
