jev-gate

A Claude Code mod in MongLong0214/jev-gate

Jev Gate in one plugin: the orchestration gate, the extractive compactor, the Jev effort and model router and the jev_evidence tool. Every part is on by default; each has its own on/off option.

jev-gate reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.
