md

A Claude Code mod in davekiss/md

Read, write and review markdown with Claude in a pane inside Claude Code: drafts stream in, comments stay on their words, and Claude suggests edits you accept or reject.

md reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
