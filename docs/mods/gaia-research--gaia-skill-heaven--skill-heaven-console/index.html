skill-heaven-console

A Claude Code mod in gaia-research/gaia-skill-heaven

Optional PREVIEW console for Claude Code that observes Skill Heaven summons and never changes them: a status entry, a Lens band above the prompt, and a /heaven pane (Session, Scope, Flow, Trust). Early-access Mods API; desktop paint still needs a local probe.
