cc-pokedex

A Claude Code mod in deonmenezes/claude-mods-pokedex

Catch wild creatures above the Claude Code prompt: where your prompt leads (water, grass, fire, bugs, plans, builds) decides what appears. Pick a partner that draws under the logo, beside the spinner and above the prompt, and levels up and evolves as Claude works. Needs function hooks (early access) and an interactive terminal.

cc-pokedex reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 7
  • API methods referenced: 9
  • Access from classified calls: L0, draws and remembers: persists state, draws
