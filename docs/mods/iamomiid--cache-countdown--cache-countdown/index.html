cache-countdown

A Claude Code mod in iamomiid/cache-countdown

A fuse above the prompt that burns down with the prompt cache, with context and rate limit meters and buttons to keep the cache warm or compact

cache-countdown reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 9
  • API methods referenced: 14
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, reads files, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
