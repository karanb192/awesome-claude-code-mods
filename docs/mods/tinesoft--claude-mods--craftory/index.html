craftory

A Claude Code mod in tinesoft/claude-mods

An SDLC framework, built on top of Matt Pocock's skills, as a mod. A phase rail above the prompt takes a feature from idea to merged PR (Align, Spec, Tickets, Build, Review, Ship, Retro).
