cache-tax

A Claude Code mod in Fraktalis/claude-mods

Warns before a message that would re-read the whole conversation on a cold prompt cache, shows the cache state in the status line, and can keep it warm with /keepwarm.

cache-tax reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 5
  • API methods referenced: 10
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, reads the prompt box, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install cache-tax --marketplace Fraktalis/claude-mods
