tools-usage

A Claude Code mod in Fazzani/claude-mods

Side pane listing the tools used in the session (built-in, MCP, skill, agent, plugin, hook) with calls and token consumption.

tools-usage reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 6
  • API methods referenced: 8
  • Access from classified calls: L1, reads: reads env vars, reads settings, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
