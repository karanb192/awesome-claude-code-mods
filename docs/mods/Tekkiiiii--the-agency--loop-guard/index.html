loop-guard

A Claude Code mod in Tekkiiiii/the-agency

Stall detector per agent loop: 5 identical tool calls in a row warn that loop and leave the session-state.json stall marker for the next SessionStart

loop-guard reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 1
  • API methods referenced: 6
  • Access from classified calls: L2, writes or runs: writes files, reads files, reads env vars, reads mod state
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
