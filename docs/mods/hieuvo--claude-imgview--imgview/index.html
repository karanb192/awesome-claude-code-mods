imgview

A Claude Code mod in hieuvo/claude-imgview

Preview images inside Claude Code: hover the chip under a reply that names an image file to pop its picture up, click it to open the picture in a pane, or use /img <path>. Pixels on kitty and Ghostty, colored block characters on every other terminal.

imgview reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 6
  • API methods referenced: 15
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
