prayer-times

A Claude Code mod in mkbuilds4/mods

The next Muslim prayer time under Claude Code's prompt, a gentle reminder at adhan, and a pane with today's sky, the timetable, a weekly prayer tracker and the Qibla. Calculated on your machine; no network.

prayer-times reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 3
  • API methods referenced: 12
  • Access from classified calls: L1, reads: reads mod state, plays audio, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
