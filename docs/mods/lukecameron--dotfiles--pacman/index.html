pacman

A Claude Code mod in lukecameron/dotfiles

/pacman: Pac-Man played over the conversation on screen, eating it character by character while Claude works; Esc puts it back. Needs function hooks (CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1).

pacman reaches L0 (draws and remembers) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 8
  • Access from classified calls: L0, draws and remembers: draws
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
