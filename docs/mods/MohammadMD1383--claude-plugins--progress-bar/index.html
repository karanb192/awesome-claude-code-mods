progress-bar

A Claude Code mod in MohammadMD1383/claude-plugins

A progress bar above the prompt for long work: Claude fills one in through a tool, and any shell script or command reports its own through a unix socket (pbar), with a warning when a job stalls or dies. See how far along things are without asking.
