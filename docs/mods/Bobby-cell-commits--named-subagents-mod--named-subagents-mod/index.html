named-subagents-mod

A Claude Code mod in Bobby-cell-commits/named-subagents-mod

Gives every subagent a themed name in the task tree, and lists the running agents under those names in a side pane: what each is doing, its tokens, its conversation a press away.

named-subagents-mod reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
