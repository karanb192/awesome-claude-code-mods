gh-inbox

A Claude Code mod in kajidog/cc-mods-gh-inbox

Shows GitHub events (comments, reviews, commits, CI failures, merges) for the checked-out branch's pull request, for pull requests you choose to watch and for repositories you register, to read and hand to Claude; shows above the prompt where the pull requests you opened, and those you are asked to review, stand; /inbox pr lists pull requests and shows one, to hand its reviews to Claude, watch it, or merge, close, draft or approve it once you confirm it in a pane.

gh-inbox reaches L2 (writes or runs) by its classified calls and passed claude plugin validate.

  • API methods referenced: 21

  • Unclassified calls: 1 ($.ui.place), full access unknown
