where-am-i

A Claude Code mod in davidcoulson/crab-workshop

Shows which machine and repo a session runs in (Mac or the claude-code container, repo, branch, fork) in the status line, and nudges Claude when it reaches for the container from the Mac or runs a repo's tests on the wrong host.

where-am-i reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 3
  • API methods referenced: 6
  • Access from classified calls: L2, writes or runs: runs processes, reads files, draws
