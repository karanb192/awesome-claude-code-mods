chatroom

A Claude Code mod in adamnroman/claude-chatroom

One public, unmoderated chat room for everyone with this mod. It shows on the right of the screen while Claude works and hides when Claude waits for you. Messages go to a chat server; nothing from the room reaches Claude.

chatroom reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.
