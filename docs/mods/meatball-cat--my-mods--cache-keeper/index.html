cache-keeper

A Claude Code mod in meatball-cat/my-mods

Keeps a big chat's prompt cache warm, warns before an expensive cold restart, shows every local chat on one board (/board), and hands a chat off to a fresh one (/handoff)

cache-keeper reaches L2 (writes or runs) and passed claude plugin validate.

  • API methods referenced: 29
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, writes the prompt box, reads files, reads env vars, persists state, draws
