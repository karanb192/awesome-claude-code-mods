cutroom

A Claude Code mod in leepokai/claude-mod-cutroom

Cutroom: a cutting-room pane for HyperFrames projects inside Claude Code: frame preview, timeline, trim/split/move/delete/undo, Studio selection bridge, and point-and-ask edits sent to Claude.
