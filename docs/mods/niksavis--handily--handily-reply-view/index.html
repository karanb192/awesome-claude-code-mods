handily-reply-view

A Claude Code mod in niksavis/handily

Long replies fold to their first lines, tables draw without box lines, each table and code block gets a copy button, and each prompt you type opens under a coloured rule labelled you.

handily-reply-view reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 8
  • Access from classified calls: L1, reads: writes the clipboard, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
