better-memory

A Claude Code mod in xobotyi/cc-foundry

Keeps Claude Code's auto memory to facts that still hold: gates memory writes and sifts new entries when the session goes idle

better-memory reaches L2 (writes or runs) and passed claude plugin validate with warnings.
