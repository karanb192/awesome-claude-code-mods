memory-lens

A Claude Code mod in yonatangross/orchestkit

Recalls the few memories related to each prompt: one line for the human, one context entry for the model. Local files only, no network on the hot path.

memory-lens reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 4
  • API methods referenced: 6
  • Access from classified calls: L1, reads: reads files, reads env vars, draws
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
