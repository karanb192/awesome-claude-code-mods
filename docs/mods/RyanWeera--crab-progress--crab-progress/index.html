crab-progress

A Claude Code mod in RyanWeera/crab-progress

Progress bar with Token Optimizer marks, subagent panel and file tree with a mascot that reacts to what Claude is doing, and waves when it needs you. Merges token-optimizer (alexgreensh), filetree (data-goblin) and savvy-progress (johnnyvizz).
