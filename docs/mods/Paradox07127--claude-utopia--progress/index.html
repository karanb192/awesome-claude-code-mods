progress

A Claude Code mod in Paradox07127/claude-utopia

A per-project progress board: after each typed turn that edited files or made a commit, the plugin records its work as nodes through a Sonnet completion, kept under ~/.claude/progress/ or committed with the project; the plugin mirrors it to an optional Artifact canvas
