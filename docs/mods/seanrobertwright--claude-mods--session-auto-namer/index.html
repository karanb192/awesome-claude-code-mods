session-auto-namer

A Claude Code mod in seanrobertwright/claude-mods

After a session's first prompt, a button above the prompt suggests a name for the session, such as an issue's number and title; one press renames it.

session-auto-namer reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.304.
