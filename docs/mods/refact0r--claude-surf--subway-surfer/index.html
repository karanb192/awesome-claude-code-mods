subway-surfer

A Claude Code mod in refact0r/claude-surf

Play Subway Surfers (or watch any video) in a pane, rendered as glyphs with a foreground and a background color.

subway-surfer reaches L3 (network) and passed claude plugin validate with warnings on Claude Code 2.1.310.

  • Events hooked: 5
  • API methods referenced: 15
  • Access from classified calls: L3, network: network, runs processes, reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
