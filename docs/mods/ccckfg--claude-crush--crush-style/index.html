crush-style

A Claude Code mod in ccckfg/claude-crush

Crush CLI look for Claude Code: Charm palette, bordered tool rows, gradient spinner, session sidebar

crush-style reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 10
  • API methods referenced: 18
  • Access from classified calls: L2, writes or runs: runs processes, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
