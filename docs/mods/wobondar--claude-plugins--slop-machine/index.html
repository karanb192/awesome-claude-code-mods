slop-machine

A Claude Code mod in wobondar/claude-plugins

A three-reel slot machine in the band, a pane, a toast and the spinner, paid in Claude Dollars you earn by prompting and Claude earns by calling tools.

slop-machine reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 7
  • API methods referenced: 12
  • Access from classified calls: L1, reads: reads mod state, plays audio, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install slop-machine --marketplace wobondar/claude-plugins
