k9s

A Claude Code mod in holdennguyen/claude-code-setup

A live, interactive k9s terminal in a pane (k9s runs under a private tmux server, so kube auth and context come from the shell that launched Claude Code), plus two tools so the model can read the k9s screen and send it keys. While k9s runs, Bash calls that invoke kubectl are refused and the model is pointed at those tools; kubectl works as usual otherwise. One server per Claude Code process, a watchdog and a start-up sweep keep orphans from surviving, and an idle stop keeps k9s from polling the cluster unseen.

k9s reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
