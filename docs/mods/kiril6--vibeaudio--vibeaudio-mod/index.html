vibeaudio-mod

A Claude Code mod in kiril6/vibeaudio

Control VibeAudio from inside Claude Code: /vibeaudio opens a pane (mute, genre, volume, music, speech, banners, the share card, a setup check, per-project settings), shows when you are muted, and has an optional band above the prompt. A mod: it runs inside Claude Code with your permissions. Needs Claude Code 2.1.287+ and the vibe CLI (npm i -g vibeaudio).

vibeaudio-mod reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
