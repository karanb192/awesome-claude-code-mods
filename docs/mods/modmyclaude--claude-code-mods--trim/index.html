trim

A Claude Code mod in modmyclaude/claude-code-mods

Long shell output, folded before Claude reads it. Errors, the start and the end stay; you see about how many tokens that saved.

trim reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 5
  • API methods referenced: 9
  • Access from classified calls: L1, reads: reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
