task-progress

A Claude Code mod in anguscyk/claude-mods-task-progress

Shows a progress band above the prompt: a task progress bar with per-task durations, or the turn's tool calls as steps when there is no task list, plus elapsed time. Collapsed by default; press to expand.

task-progress reaches L1 (reads) and passed claude plugin validate.

  • Events hooked: 6
  • API methods referenced: 6
  • Access from classified calls: L1, reads: reads files, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
