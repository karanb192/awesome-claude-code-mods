crew-map

A Claude Code mod in D3K1D/claude-crew-mods

Claude Crew: a live website beside the chat (type /crew) showing what Claude, its helpers and the chats it started are doing: each one's status, steps, cost and context, what needs you, the files touched, and a filterable log where every action opens to its diff, output or error. Logs are kept and can be saved with a summary.
