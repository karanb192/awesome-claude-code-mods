prompt-strip

A Claude Code mod in MahadSalim/claude-mods

Strips, rewrites and reorders what Claude Code loads into every session: system prompt sections, first-message context, per-turn reminders, tool descriptions, skill bodies, the subagent listing and command descriptions, and adds sections of your own. Edited in its dashboard at http://127.0.0.1:5199, opened with /prompt-strip; needs node on the PATH.

prompt-strip reaches L3 (network) and passed claude plugin validate with warnings.

  • Events hooked: 11
  • API methods referenced: 9
  • Access from classified calls: L3, network: network, runs processes, writes files, reads files, reads env vars, reads the system prompt, draws
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
