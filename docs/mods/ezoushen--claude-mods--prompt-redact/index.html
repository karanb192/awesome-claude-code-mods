prompt-redact

A Claude Code mod in ezoushen/claude-mods

Replaces secrets and credentials with stable placeholders inside Claude Code before the model or the session file ever sees them: prompts, tool results and replies, plus attachments and compaction summaries where the platform lets this mod see them: and restores real values only in Edit/Write/NotebookEdit arguments. 220-rule corpus plus checksum detectors, a benign-shape allowlist, fail-closed scanning, a /redact pane and a redacted-values skill. No network, no subprocess, no model call.

prompt-redact reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 9
  • API methods referenced: 7
  • Access from classified calls: L1, reads: reads files, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
