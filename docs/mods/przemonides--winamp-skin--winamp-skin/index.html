winamp-skin

A Claude Code mod in przemonides/winamp-skin

Classic Winamp 2.x skin for Claude Code: main window above the prompt, playlist pane, /winamp to switch back to the classic look

winamp-skin reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 6
  • API methods referenced: 12
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
