clawd-usage

A Claude Code mod in Toshkee/clawd-usage

Clawd waves his ultracode wand and does his banner tricks above the prompt beside live meters of context, rate limits and cost

clawd-usage reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 5
  • API methods referenced: 12
  • Access from classified calls: L3, network: network, reads settings, reads mod state, requests an Anthropic credential handle, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
