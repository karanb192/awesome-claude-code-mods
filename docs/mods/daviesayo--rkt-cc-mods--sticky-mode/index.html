sticky-mode

A Claude Code mod in daviesayo/rkt-cc-mods

Keep a skill on for the whole session, like Cursor's Custom Modes. Run any skill and press Keep on, or run /mode <skill>. /mode off or Exit mode turns it off.

sticky-mode reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 6
  • API methods referenced: 14
  • Access from classified calls: L1, reads: reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install sticky-mode --marketplace daviesayo/rkt-cc-mods
