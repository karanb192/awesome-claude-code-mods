agent-room

A Claude Code mod in pappusinghadip/pappu-claude-mods

Put 2-3 Claude Code sessions in one room (planner, coder, reviewer...): a live pane shows every message between them, who is working, a message limit, and pause / stop-all controls

agent-room reaches L2 (writes or runs) and passed claude plugin validate.

  • Events hooked: 8
  • API methods referenced: 18
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, reads files, reads env vars, persists state, draws
  • Static scan, not a runtime test

/plugin install agent-room --marketplace pappusinghadip/pappu-claude-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
