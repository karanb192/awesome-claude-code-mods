desktop-statusline

A Claude Code mod in jiroamato/claude-mods

Status bar above the prompt on the desktop surface: model, effort, folder, git branch, context usage, cost and elapsed time, with a pane to remove built-in tools, read the system prompt as sent, and trace every request to the model
