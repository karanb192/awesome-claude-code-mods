commit-msg

A Claude Code mod in tomshaw/claude-code-plugins

Writes an accurate conventional commit message for your staged changes, using the Claude session that made them to explain why. Matches your repo's commit style; edit, regenerate and copy it from a pane. /commit-msg [simple|body|full] [note].
