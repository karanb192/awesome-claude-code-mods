x-mod-guard

A Claude Code mod in dvakatsiienko/frame

reads every Bash call, fork spawn and Write before it runs: a Write over a tracked file the session never read, a floor command, a system, overwrite, prune or remote-delete command, a known hazard shape, a coder spawn whose brief has no x brief check stamp, or a fork with no why-fork line is refused with its safe door, never a dialog; each refusal and escape is kept in its own store as an event and a per-day count, which x-mod-stash's band reads as its 🛡️ counter row

x-mod-guard reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.304.

  • Events hooked: 3
  • API methods referenced: 17
  • Access from classified calls: L2, writes or runs: runs processes, reads files, reads env vars, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
