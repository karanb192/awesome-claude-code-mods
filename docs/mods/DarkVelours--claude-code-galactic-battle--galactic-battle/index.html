galactic-battle

A Claude Code mod in DarkVelours/claude-code-galactic-battle

Draws an animated space battle above the prompt while Claude works, driven by what Claude does (tool results, helpers), with a double-bladed lightsaber gauge for context and quota, blaster sounds and optional music.

galactic-battle reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 15
  • Access from classified calls: L2, writes or runs: runs processes, changes config, reads files, reads env vars, reads mod state, plays audio, persists state, draws
