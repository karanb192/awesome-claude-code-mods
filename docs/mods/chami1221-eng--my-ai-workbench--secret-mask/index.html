secret-mask

A Claude Code mod in chami1221-eng/my-ai-workbench

Redacts tokens, API keys and passwords from every row that enters the conversation (tool results, hook context, input, replies) before it is stored. The secret never reaches the model or the transcript.

secret-mask reaches L0 (draws and remembers) and passed claude plugin validate with warnings.

  • Events hooked: 4
  • API methods referenced: 3
  • Access from classified calls: L0, draws and remembers: draws
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
