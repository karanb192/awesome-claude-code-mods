auto-handoff

A Claude Code mod in dhrubo55/claude-mods

Writes a handoff by itself shortly before the prompt cache of an idle session expires, while the cache is still warm. Runs its own /auto-handoff:handoff skill and saves its answer under ~/.claude/handoffs, or another installed handoff command you pick once. Nothing in the handoff waits for approval: calls that would prompt are declined, never approved. A row above the prompt counts down; /auto-handoff opens a pane with the timeline, which command runs and why, and buttons to hand off now, pause, re-pick or copy the path.

auto-handoff reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
