session-lens

A Claude Code mod in marwansaab/Claude-Mods

A session lens pane (/lens): Claude's to-do list, its crew of subagents as animated crabs with a progress band above the prompt, and the skills and tools this session used, each section folding on its own. Replaces crab-crew: disable or don't install crab-crew alongside it.

session-lens reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 11
  • API methods referenced: 16
  • Access from classified calls: L1, reads: reads the transcript, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install session-lens --marketplace marwansaab/Claude-Mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
