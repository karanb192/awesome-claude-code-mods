workflow-watch

A Claude Code mod in alonbaron/claude-skills

Live session and Workflow tracker: main-thread turns, skills fired, spawned subagents, git commits and workflow stages with models, effort, tokens and timeline waterfall in a pane, a band above the prompt and the status line.

workflow-watch reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.
