crosswalk

A Claude Code mod in Tejas274/claude-mods

Warns you (never blocks) when Claude is about to edit a file that's also changed in an open GitHub pull request: a line above the prompt and a one-time toast. /crosswalk lists the files your branch shares with open PRs.
