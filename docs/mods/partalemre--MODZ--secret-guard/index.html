secret-guard

A Claude Code mod in partalemre/MODZ

Stops secrets before they land: scans Write/Edit and git add/commit for keys and tokens, blocks git add of .env, keeps pasted keys out of the chat as placeholders, /rec masks the screen; a card with masked values, then Move keys to .env, Allow once or Cancel (Turkish with MODZ_LANG=tr)

secret-guard reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.316.

  • Events hooked: 8
  • API methods referenced: 17
  • Access from classified calls: L2, writes or runs: runs processes, writes files, reads files, reads env vars, reads settings, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
