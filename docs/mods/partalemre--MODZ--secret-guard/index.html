secret-guard

A Claude Code mod in partalemre/MODZ

Catches secret keys (passwords, API keys, tokens) before they are written into a file or saved in a version, and stops the secrets file (.env) from being saved with your work. A card shows each key half-hidden and asks you to move it to the secrets file, allow it once, or cancel. Keys you paste into the chat reach Claude only as stand-ins, and /rec hides keys on screen while you record (Turkish with MODZ_LANG=tr).

secret-guard reaches L2 (writes or runs) and passed claude plugin validate with warnings.
