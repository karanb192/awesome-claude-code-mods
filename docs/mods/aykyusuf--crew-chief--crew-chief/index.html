crew-chief

A Claude Code mod in aykyusuf/crew-chief

Difficulty-based routing for Claude Code. You pick the main model and effort; Claude decides what to do itself and what to hand to tiered Haiku, Sonnet, and Opus subagents (including browser and emulator UI testers), escalates when a tier gets stuck, and follows your overrides like "do it yourself" or "give this to Sonnet at medium".

The scan could not record a complete footprint for crew-chief, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.304.
