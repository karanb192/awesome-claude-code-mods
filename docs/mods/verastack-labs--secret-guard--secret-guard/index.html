secret-guard

A Claude Code mod in verastack-labs/secret-guard

Blocks API keys, tokens and private keys from being written to disk, put on a command line, or committed to git by Claude.

secret-guard reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.316.
