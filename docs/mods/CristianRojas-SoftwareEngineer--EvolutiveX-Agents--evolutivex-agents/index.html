evolutivex-agents

A Claude Code mod in CristianRojas-SoftwareEngineer/EvolutiveX-Agents

Narra por voz la actividad de la sesión de Claude Code usando AI Voice-InterConnector, emite notificaciones de escritorio nativas y, de forma opt-in, enriquece el transcript con la hora de inicio, la duración y contadores en vivo de cada bloque. Genera un mensaje conversacional corto por turno (Gemini free tier con degradación local) y lo sintetiza vía el CLI ai-voice-interconnector. Multiplataforma, costo cero y no intrusivo por defecto. Beta en español; Windows 11 verificado, Linux y macOS experimentales.
