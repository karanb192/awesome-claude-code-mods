clean-view

A Claude Code mod in wickedhardflip/claude-code-mods

Hides tool-call rows while Claude works; shows a plan checklist band (done / current / left).

clean-view reaches L1 (reads) and passed claude plugin validate with warnings on Claude Code 2.1.310.
