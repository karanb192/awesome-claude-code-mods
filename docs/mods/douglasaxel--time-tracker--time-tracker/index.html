time-tracker

A Claude Code mod in douglasaxel/time-tracker

Measures the time worked on each project with Claude Code, shows today's time in the status line, and opens the /horas panel with the time per folder and day, corrections and a Markdown copy for hours reports.

time-tracker reaches L1 (reads) and passed claude plugin validate with warnings.

  • API methods referenced: 25
  • Access from classified calls: L1, reads: writes the clipboard, reads files, reads env vars, reads settings, reads mod state, persists state, draws
