menu

A Claude Code mod in danielmalka/malka-claude-mods

An optional /mods menu that lists the installed mods (status line, clean screen, mode, permissions, tree-explained) and opens each one's page in a pane.

menu reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.316.

  • Events hooked: 5
  • API methods referenced: 7
  • Access from classified calls: L1, reads: reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
