oh-my-claudeagent

A Claude Code mod in UtsavBalar1231/oh-my-claudeagent

Claude Code, with receipts. Plans with you, hands each task to a specialist agent, and keeps a session from calling work done until a verification is logged. Its hooks run in every session, a guard holds destructive shell commands for review, and setup can point your status line at OMCA.
