sendbird-client

A Claude Code mod in sendbird/sendbird-client-plugin

Add Sendbird Chat (including authentication and sessions), UIKit, and Calls to iOS, Android, React, and React Native apps from Claude Code or Codex, writing code from verified documentation and the Sendbird SDK you have installed. It runs local shell scripts as hooks. See "What runs on your machine" in the README.
