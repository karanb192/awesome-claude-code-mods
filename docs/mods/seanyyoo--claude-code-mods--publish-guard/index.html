publish-guard

A Claude Code mod in seanyyoo/claude-code-mods

Stops Claude from typing private terms into the browser or writing them into your publishing files, and keeps a log of what it blocked

publish-guard reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
