code-reference

A Claude Code mod in hyperbola-bear/claude-mods

Replies that point at code: ask with /code-reference (a question, or a PR to review) and each place the reply names opens in a code pane beside it, the prose linked to it and boxed under each section. Only the command triggers it. Drawn the same in the terminal and the desktop app. PRs are read with gh, a GitHub MCP server or git, and checked out into a review worktree.

code-reference reaches L2 (writes or runs) by its classified calls and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 9
  • API methods referenced: 27
  • Access from classified calls: L2, writes or runs: runs processes, writes files, drives Claude, writes the clipboard, reads files, reads env vars, reads the transcript, reads mod state, persists state, draws
  • Calls in a namespace that is not in the Claude Code 2.1.302 core table: 1 ($.browser.open), full access unknown
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
