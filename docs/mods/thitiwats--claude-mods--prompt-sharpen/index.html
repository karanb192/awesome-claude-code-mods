prompt-sharpen

A Claude Code mod in thitiwats/claude-mods

/prompt-sharpen:upgrade <prompt> opens a pane that asks a few clarifying questions with recommended answers, then rewrites the prompt clearer and more complete with the same intent, to run, edit or copy
