agent-board

A Claude Code mod in JeremyHo1123/claude-code-agent-board

Writes each session's subagents, activity, context fill and subscription usage to ~/.claude/agent-board for the Agent Board VS Code extension, and draws a subagent pane in the terminal (/agent-board)

agent-board reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 12
  • API methods referenced: 19
  • Access from classified calls: L3, network: network, writes files, reads files, reads env vars, reads mod state, requests an Anthropic credential handle, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
