prompt-refiner

A Claude Code mod in jz-wilson/claude-mods

A Refine button under the prompt, any time in the chat: pick a rewrite style (Clearer, Shorter, Elaborate, Structured, Ask me first, My guidance), then use it, refine again, or discard it.

prompt-refiner reaches L2 (writes or runs) and passed claude plugin validate.
