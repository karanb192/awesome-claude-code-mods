limits-meter

A Claude Code mod in ice-lfernandes/claude-code-mods

Plan limits and context above the prompt: model and effort, 5-hour and weekly windows with reset times, context fill, cache hit rate, tokens per turn, and a toast on a costly model switch near the limit

limits-meter reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 16
  • Access from classified calls: L1, reads: writes the prompt box, reads env vars, reads settings, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
