cache-meter

A Claude Code mod in drdickgraysonjr/chalkery

Prompt cache status above the prompt: how long the cache stays warm, what a re-cache would cost, plan limits near the cap. Keeps a big cache warm on request and asks before a cold send. The cache part of Nate Herk's cache-keeper.

cache-meter reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • API methods referenced: 19
