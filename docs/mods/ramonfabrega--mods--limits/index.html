limits

A Claude Code mod in ramonfabrega/mods

Logs the subscription's rate-limit windows (five_hour, seven_day, and each per-model week such as Fable's: percent used and when each resets) to ~/.lore/limits.jsonl, one line per whole-point move, from every session that has it, and keeps the latest per-model reading in ~/.lore/limits-now.json for a status line to draw: the figures the account enforces, kept, so a week of them gives the exchange rate between tokens and the sub.

limits reaches L3 (network) and passed claude plugin validate.
