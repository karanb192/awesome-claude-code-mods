prompt-upgrade

A Claude Code mod in afterever/claude-mods

Turns a rough prompt into a great one before it is sent: /better opens a pane that asks up to three quick questions, rewrites the prompt and shows both side by side. Nothing runs until you press Run.

prompt-upgrade reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 5
  • API methods referenced: 16
  • Access from classified calls: L2, writes or runs: drives Claude, writes the prompt box, writes the clipboard, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
