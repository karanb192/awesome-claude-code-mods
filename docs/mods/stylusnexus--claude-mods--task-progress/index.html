task-progress

A Claude Code mod in stylusnexus/claude-mods

A progress row above the prompt for each plan the model reports, plus a row per running subagent. The bar shows what the model reports; it costs no tokens to draw.

task-progress reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 7
  • API methods referenced: 6
  • Access from classified calls: L2, writes or runs: drives Claude, draws
