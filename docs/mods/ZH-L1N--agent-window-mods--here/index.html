here

A Claude Code mod in ZH-L1N/agent-window-mods

A HERE band above the prompt that says where the session is, with no model call by default (option rewrite=haiku makes one per answer): the goal (goal-meter's goal name, else the first line of the prompt that started the open task list), what Claude is doing now (the last tool call's verb and path, or the spinner word while it thinks) and the questions the last reply asked you; /here prints the three, /here on | off.

here reaches L2 (writes or runs) and passed claude plugin validate.

  • Events hooked: 8
  • API methods referenced: 10
  • Access from classified calls: L2, writes or runs: drives Claude, reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
