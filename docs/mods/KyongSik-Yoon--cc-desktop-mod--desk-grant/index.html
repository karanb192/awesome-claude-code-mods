desk-grant

A Claude Code mod in KyongSik-Yoon/cc-desktop-mod

Helper for desk-asana and desk-slack: lets the Asana and Slack calls their side panes make run without allow rules in your settings. Only those two plugins' own calls to their known tools are allowed; Claude's calls to the same tools still get Claude Code's usual permission check. Installed with desk-asana or desk-slack

In its last recorded footprint, the validator reported no API methods for desk-grant; it passed claude plugin validate on Claude Code 2.1.319.
