shelltime-statusline

A Claude Code mod in shelltime/claude-code-mods

ShellTime statusline for Claude Code: git, model, session and daily cost, quota, agent time and context, in the terminal and the desktop app. Also links PRs opened with gh pr create to the session, and reports when the session ends so ShellTime summarizes it right away.

shelltime-statusline reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 6
  • API methods referenced: 14
  • Access from classified calls: L3, network: network, runs processes, reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
