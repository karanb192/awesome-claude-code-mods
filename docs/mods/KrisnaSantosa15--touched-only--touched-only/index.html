touched-only

A Claude Code mod in KrisnaSantosa15/touched-only

Stops `git add -A` and `commit -a` from sweeping in files Claude never touched, and hands Claude the exact paths to stage instead.

touched-only reaches L1 (reads) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 3
  • API methods referenced: 4
  • Access from classified calls: L1, reads: reads mod state
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

/plugin install touched-only --marketplace KrisnaSantosa15/touched-only
