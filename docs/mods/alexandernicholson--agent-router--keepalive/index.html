keepalive

A Claude Code mod in alexandernicholson/agent-router

A prompt cache bar for every conversation, subagent and teammate, a dashboard with /keepalive, per-conversation cache TTLs, and upkeep that keeps an idle cache warm or compacts it before it expires. Requires Claude Code Mod function hooks enabled.

keepalive reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.
