budget-governor

A Claude Code mod in ccdwyer/budget-governor

Enforces session and daily spend caps: a live gauge above the prompt, a wrap-up nudge at 80%, and new prompts refused at the cap

budget-governor reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
