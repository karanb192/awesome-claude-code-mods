proactive-compact-mod

A Claude Code mod in Apemb/proactive-compact-mod

Lets the agent prepare and choose its own compaction instead of suffering auto-compact: asks it to save its memories at a context threshold, and gives it tools to read its context and compact itself.

proactive-compact-mod reaches L2 (writes or runs) and passed claude plugin validate.
