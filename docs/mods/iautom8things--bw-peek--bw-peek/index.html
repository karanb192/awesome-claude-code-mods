bw-peek

A Claude Code mod in iautom8things/bw-peek

A Beadwork ticket pane inside Claude Code: /bw <id> or a search box runs bw show and draws the digest, title, description and comments; every ticket id a reply mentions gets a button that opens it. Needs function hooks (CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1).

bw-peek reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
