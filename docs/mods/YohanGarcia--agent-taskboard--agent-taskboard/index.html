agent-taskboard

A Claude Code mod in YohanGarcia/agent-taskboard

A live task board for Claude Code: plans before building and shows every task, its status, time, subagents and checks in a side panel. Progress survives sessions.

agent-taskboard reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
