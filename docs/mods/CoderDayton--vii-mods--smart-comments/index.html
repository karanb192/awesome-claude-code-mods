smart-comments

A Claude Code mod in CoderDayton/vii-mods

Reads each comment Claude adds, lets through the ones that tell a reader what the code cannot, skips docstrings, and names the lines to cut.

smart-comments reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.316.
