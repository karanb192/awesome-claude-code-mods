agentic-fmi-pane

A Claude Code mod in MechC-ODE/agentic-fmi

Early-access live pane for Agentic FMI (/fmi): run progress, values with units, live charts, Pause/Resume/Step/Set/Stop for live runs, built FMUs and system connection diagrams. Reads only the run store; needs the agentic-fmi plugin.

agentic-fmi-pane reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.316.

  • Events hooked: 4
  • API methods referenced: 15
  • Access from classified calls: L2, writes or runs: writes files, reads files, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

/plugin install agentic-fmi-pane --marketplace MechC-ODE/agentic-fmi
