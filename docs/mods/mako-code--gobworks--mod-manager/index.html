mod-manager

A Claude Code mod in mako-code/gobworks

The Gobworks manager: browse every mod by category, see what each does and costs, turn mods and presets on or off, and check them. Best standalone in any terminal (gobworks); inside a running Claude Code session too (/mods).

Access

L2 Writes or runsother: $.state.get, other: $.state.set, runs processes, writes files, changes config, drives Claude, reads files, reads env vars, reads settings, persists state, draws
