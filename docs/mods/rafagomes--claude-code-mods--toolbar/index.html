toolbar

A Claude Code mod in rafagomes/claude-code-mods

A Toolbar button under the prompt: pick the model and effort, open the project in VS Code, and switch clean view, which hides the work and shows a step tracker of the task list

toolbar reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
