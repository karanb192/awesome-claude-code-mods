A Claude Code mod in nvr0x5/claude-deck

A cockpit for Claude Code: plan bars and subagent strips, context, usage limits with reset countdowns and burn rates, spend, the model route and a pet. Six bar styles, three collapsed looks. CLI and Desktop.

deck reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.
