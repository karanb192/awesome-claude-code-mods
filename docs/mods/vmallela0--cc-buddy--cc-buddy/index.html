cc-buddy

A Claude Code mod in vmallela0/cc-buddy

Brings back /buddy: the small creature that watched you code, above the prompt again. Restores the companion in ~/.claude.json exactly (same species, rarity, hat and stats), hatches an egg for new accounts, levels up from commits and passing tests, unlocks a 49-buddy roster as you ship, reacts to Claude's work for free, answers in a Haiku-written line when you say its name, and shows in a pane on desktop and mobile. Needs CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1.

cc-buddy reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 11
  • API methods referenced: 16
  • Access from classified calls: L2, writes or runs: drives Claude, reads files, reads env vars, persists state, draws
