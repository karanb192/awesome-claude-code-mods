usage-weather

A Claude Code mod in ptpmediabr/usage-weather

One quiet line above the prompt: context, 5-hour and weekly usage, whether the prompt cache is warm, and a Clear & continue button.

usage-weather reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
