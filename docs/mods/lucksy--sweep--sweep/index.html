sweep

A Claude Code mod in lucksy/sweep

See and clean the storage Claude Code leaves behind: agent and workflow worktrees with their node_modules, temp scratchpads, superseded plugin versions, old transcripts, checkpoints, old CLI binaries and stray config copies. Every view is a fresh scan; sweep stores nothing. Dry run by default; never touches unsaved work.

sweep reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.316.

  • Events hooked: 4
  • API methods referenced: 14
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, writes the clipboard, reads env vars, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install sweep --marketplace lucksy/sweep

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
