msgate-agents

A Claude Code mod in JustAzul/agent-cli-sdk

msgate-agents: ready-made agent types (second opinion, code review, cross-check, expert persona, delegation, ad hoc) that the msgate engine plugin answers with Codex, plus the dispatch skill.

msgate-agents reaches L2 (writes or runs) by its classified calls and passed claude plugin validate with warnings on Claude Code 2.1.310.
