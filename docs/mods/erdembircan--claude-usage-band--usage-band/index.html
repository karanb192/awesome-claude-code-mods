usage-band

A Claude Code mod in erdembircan/claude-usage-band

Shows the current session and weekly usage limits in a band above the prompt of the Claude desktop app, and locks a working session against Escape and stray prompts

usage-band reaches L1 (reads) and passed claude plugin validate with warnings.

  • Events hooked: 8
  • API methods referenced: 16
  • Access from classified calls: L1, reads: writes the prompt box, reads the prompt box, reads mod state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
