cc-code-format-mod

A Claude Code mod in kukaka/cc-mods

Rewrites every fenced code block in an LLM response so it conforms to the language's standard style (Prettier for the web stack, black for Python, gofmt / rustfmt / shfmt where installed).

Access

L2 Writes or runsother: $.state.get, other: $.state.set, runs processes, writes files, reads files, draws
