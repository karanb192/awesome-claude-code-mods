live-notebook

A Claude Code mod in AmberWJL/live-claude-notebook

Save replies from your Claude Code conversations as Markdown notes on your own computer, then browse, search and edit them in a pane or the web notebook. Local-first: no account, no cloud.

live-notebook reaches L2 (writes or runs) and passed claude plugin validate.
