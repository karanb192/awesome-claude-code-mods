speak-aloud

A Claude Code mod in alxwrd/alxwrd-mods

Reads the first paragraph of each turn aloud with Piper TTS; toggle with /speak on|off.

speak-aloud reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.312.

  • Events hooked: 6
  • API methods referenced: 13
  • Access from classified calls: L3, network: network, runs processes, reads files, reads mod state, plays audio, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
