token-usage

A Claude Code mod in Synthesizzz/claude-code-token-usage

A band above the prompt with context fill, the 5-hour and weekly windows, reset countdowns, a burn-rate forecast and cost. /tokens opens a detail pane; /tokens style, or words such as /tokens bars, change the layout, colours and labels.
