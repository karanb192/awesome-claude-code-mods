reflect-bridge

A Claude Code mod in smhasan-yad/claude-mod-reflect-bridge

Reflect, adapted: spots reusable corrections in your short prompts (one small Haiku call, only on prompts that read like a correction) and saves them on one press to auto-memory, the shared Claude CLAUDE.md, or the AGENTS.md all your agents read. Based on claude-reflect's mod by Bayram Annakov (MIT).

reflect-bridge reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.304.

  • Events hooked: 6
  • API methods referenced: 19
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, writes the prompt box, reads files, reads env vars, reads the transcript, reads the prompt box, reads mod state, persists state, draws
