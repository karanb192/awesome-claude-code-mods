context-band

A Claude Code mod in Tekkiiiii/the-agency

Band above the prompt: context %, tokens, model, cost, prompt-cache size/share/TTL countdown, 5h and weekly usage-window reset timers and next-request estimate; /ctx opens a detail pane; toast when a background subagent finishes; Jev router line (today's calls, tokens, USD, Haiku fallback) and outage warning, hidden unless the router usage log exists
