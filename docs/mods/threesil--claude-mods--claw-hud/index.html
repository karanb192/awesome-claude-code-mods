claw-hud

A Claude Code mod in threesil/claude-mods

Claw mod: a task band above the prompt and a /hud pane to add and tick off tasks, reading the same TASKS.md as the Claw skill.

claw-hud reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
