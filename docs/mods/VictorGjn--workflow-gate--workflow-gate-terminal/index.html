workflow-gate-terminal

A Claude Code mod in VictorGjn/workflow-gate

workflow-gate in the Claude Code terminal: the plan as a flowchart with editable tiers and missions, an Opus review before you approve, the run live card by card (progress, cost, each agent's story), reasoning checks with an Opus orchestrator, retros, and learning across runs. Requires workflow-gate.
