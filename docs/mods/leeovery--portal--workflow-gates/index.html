workflow-gates

A Claude Code mod in leeovery/portal

Draws the agentic-workflows engine's gates in the band above the prompt: rows a click puts in the prompt and a second click sends: instead of a menu the model has to reproduce; carries a handoff into a fresh conversation; appends the engine's note to a workflow conversation's compaction, so Claude re-reads what it works from; says the phase in the spinner; and refuses a direct edit of a workflow manifest.

The scan could not record a complete footprint for workflow-gates, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.304.

  • Access: unknown, the footprint is incomplete
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
