status-board

A Claude Code mod in HolyGrail/claude-mods

Shows a status board the model writes for this session, optionally proofread against rules you name, a one-line status above the prompt, and the per-prompt history of plans, steps, recaps, questions and linked pull requests

status-board reaches L2 (writes or runs) by its classified calls and passed claude plugin validate.

  • Events hooked: 8
  • API methods referenced: 25
  • Access from classified calls: L2, writes or runs: drives Claude, writes the clipboard, reads files, reads env vars, reads settings, persists state, draws
  • Unclassified calls: 1 ($.session.info), full access unknown
  • Static scan, not a runtime test

Install hint

/plugin install status-board --marketplace HolyGrail/claude-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
