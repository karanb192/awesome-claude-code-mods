next-steps

A Claude Code mod in Liberty-Technical-Solutions/claude-workflow-mods

Whenever nothing is running (session start, after a reply, after a stopped reply), shows a checkbox panel of next-step options above the prompt. Tick one or more and Send selected or Edit selected, or send one with a click.

next-steps reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.310.
