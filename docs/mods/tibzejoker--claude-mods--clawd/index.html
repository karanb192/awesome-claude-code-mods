clawd

A Claude Code mod in tibzejoker/claude-mods

Clawd's HQ: Clawd lives in a pixel art office, mimes what Claude does, and a game HUD shows the model, context and rate limits

clawd reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 13
  • API methods referenced: 23
