A Claude Code mod in muxia23/ricky-pixel-mod

Ricky, a pixel-art cat companion for Claude Code: an animated night-sky pane with a task / subagent / activity / files board, a cat in the band above the prompt, and a purple-gold spinner

ricky-pixel-mod reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.
