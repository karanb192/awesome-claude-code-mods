claudepad

A Claude Code mod in nwilsson/claudepad

A notepad pane for Claude Code: notes per repo, per branch or global, that Claude can read, add to and tick off. Tags, due dates, search, pinned context, and NOTES.md or git-folder sync.

Access

L2 Writes or runsother: $.state.get, other: $.state.set, runs processes, writes files, drives Claude, writes the prompt box, reads files, reads env vars, reads the transcript, persists state, draws

Validation

Passed on Claude Code 2.1.301

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
