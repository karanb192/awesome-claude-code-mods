spick-dashboard

A Claude Code mod in Brulek/spick

Shows who is working now (lane, model, the main loop's prompt size) above the prompt, and a /spick pane with switches (routing, review, gate, guard, lanes, band), lane totals, local quota with each sample's age and recent turns. The switches shape the per-prompt triage checklist, which carries a keyword Hint line per prompt. Enforcement is on facts: the guard lets the main session edit one source file per turn (the second goes to a coder) and sends a turn back once when source was edited and no check passed after the last edit; the gate sends a turn back once when a hinted verdict's role (deep for judgement, the review lane or deep for review) did not complete and no Kept: line says why; both reasons go back in one block. A check that fails twice in a turn adds an escalation line; a coder, planner or deep call with no effort gets the default; a Haiku session past 80k tokens is warned. Each main turn is one JSON line in <config>/spick/turns/<session>.jsonl; /spick spend and /spick audit report on them.
