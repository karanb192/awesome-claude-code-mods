cockpit

A Claude Code mod in servaes/cockpit

Cockpit Board: one side panel with the account's usage windows, this chat's context and cache (warm or cold, the cold price, Keep warm, the Handoff note and Resume), live progress with a time estimate, goals with a Create goal box, agents, a Needs you section for everything that waits on you (held risky commands, hand-offs, the wrong-folder nudge), a CHANGES zone with the changed files, See code changes, See visual changes (the screen before and after) and Ship (six steps to live), and the file tree; the crew skill (/cockpit:crew, which runs a big task with a crew of worker agents), the goal meter, the agents and cache-tax ship inside it, all in one pane; above the prompt, two columns: the next steps ideas and Run It (Do it here, Hand to a cheaper agent, Open in a new chat, Split across agents, Plan first, then build, and the Codex 2nd opinion; the route the draft calls for is marked Suggested, with the lane and why), then what the message being typed will cost.

The scan could not record a complete footprint for cockpit, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.310.
