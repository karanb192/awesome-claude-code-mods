workflow-gates-rows

A Claude Code mod in leeovery/portal

Draws the transcript rows of what the workflow-gates mod sends: an answer as the question it answered and the answer, a handoff's continuation as where the work went: and a compaction's note as one dim line, instead of Claude Code's framing.
