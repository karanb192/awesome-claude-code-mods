context-git-band

A Claude Code mod in mlabo-org/context-git-band

Claude Code mod: one line above the prompt with the context window fill (weather, with a compact button beside it), the subscription quota left (5-hour and weekly gauges) and the git state

context-git-band reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.304.

  • Events hooked: 7
  • API methods referenced: 21
  • Access from classified calls: L3, network: network, runs processes, drives Claude, reads files, reads env vars, reads settings, reads mod state, requests an Anthropic credential handle, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
