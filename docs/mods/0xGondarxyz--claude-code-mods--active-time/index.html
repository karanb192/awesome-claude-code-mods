active-time

A Claude Code mod in 0xGondarxyz/claude-code-mods

Counts the time you really spend with Claude Code (typing and Claude working, not an idle terminal) and shows it in the status line and /claude-time.

active-time reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 8
  • API methods referenced: 14
  • Access from classified calls: L2, writes or runs: runs processes, writes files, reads files, reads env vars, persists state, draws
  • Static scan, not a runtime test

Install hint

/plugin install active-time --marketplace 0xGondarxyz/claude-code-mods

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
