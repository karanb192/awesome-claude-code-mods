turn-receipt

A Claude Code mod in l-a-motta/motta-claude-mods

A receipt under each turn's reply, yours and the ones agents' reports start: how long it took, the agents spawned, the edits made, the failed tool calls and the cost added. The figures in tool-borders' colors; agents opens savvy-progress's agents pane, edits changes-drill's Changes pane. Read from the engine's events; no model calls.

turn-receipt reaches L1 (reads) by its classified calls and passed claude plugin validate.

  • Events hooked: 5
  • API methods referenced: 7
  • Access from classified calls: L1, reads: reads mod state, draws
  • Calls in a namespace that is not in the Claude Code 2.1.302 core table: 2 ($.changesDrill.open, $.savvyProgress.open), full access unknown
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test
