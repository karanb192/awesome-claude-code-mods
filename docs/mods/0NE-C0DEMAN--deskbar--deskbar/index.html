deskbar

A Claude Code mod in 0NE-C0DEMAN/deskbar

A desk for the Claude Code prompt: context weather, Gmail, calendar, tasks across sessions, notes, a music deck and a billable-hours timer

The scan could not record a complete footprint for deskbar, so its access is unknown; it passed claude plugin validate on Claude Code 2.1.310.

To install it, open the repository and follow the author’s setup instructions. Mods need Claude Code 2.1.287 or later.
