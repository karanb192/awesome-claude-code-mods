agent-monitor

A Claude Code mod in gvart/claude-config

A sidebar pane for Claude Code: live progress, pause/resume, stop and messaging for subagents and workflow agents, plus session spend and plan limits

agent-monitor reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 9
  • API methods referenced: 18
  • Access from classified calls: L2, writes or runs: runs processes, drives Claude, writes the prompt box, reads mod state, persists state, draws
