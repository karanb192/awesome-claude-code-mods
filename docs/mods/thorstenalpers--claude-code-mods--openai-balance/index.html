openai-balance

A Claude Code mod in thorstenalpers/claude-code-mods

Your OpenAI API credit above the prompt: an estimated balance with a gauge, today's spend, where the money mostly went, and the last call. /openai-balance shows the breakdown.

openai-balance reaches L3 (network) and passed claude plugin validate on Claude Code 2.1.310.

  • Events hooked: 4
  • API methods referenced: 10
  • Access from classified calls: L3, network: network, runs processes, reads mod state, persists state, draws
