usagi-code

A Claude Code mod in SungsooKwon/claude-mods-custom-box

Usagi or Chiikawa acts out what Claude is doing in a pane above the prompt, with the order, subagents and progress beside it. Ported from clockendbader/mascot-studio (MIT).

usagi-code reaches L1 (reads) and passed claude plugin validate.

  • Events hooked: 13
  • API methods referenced: 16
  • Access from classified calls: L1, reads: reads mod state, persists state, draws
  • Reads mod state: the scan does not record whose state, so this does not show that it reads another mod’s values
  • Static scan, not a runtime test

Install hint

/plugin install usagi-code --marketplace SungsooKwon/claude-mods-custom-box

From the repository's own marketplace. Confirm the plugin name in the repository's README before installing. Mods need Claude Code 2.1.287 or later.
