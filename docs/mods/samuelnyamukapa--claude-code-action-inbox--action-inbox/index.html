action-inbox

A Claude Code mod in samuelnyamukapa/claude-code-action-inbox

A cross-session inbox of the decisions and manual actions you owe, grouped by project and session, with replies routed back to the owning session.

action-inbox reaches L2 (writes or runs) and passed claude plugin validate on Claude Code 2.1.304.
