review-ledger

A Claude Code mod in ipartington/claude-mods

Keeps review findings (H1, M3, L2...) per repo across sessions and ticks them off when their PR merges

review-ledger reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.304.
