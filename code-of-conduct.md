# Code of Conduct

This list describes other people's work. Keep it factual and kind.

- A footprint is what a mod can touch, read off Claude's validator. It is not an accusation, and entries never speculate about intent.
- Disagreements about a row go in an issue with the validator's output attached, not in the description text.
- Be respectful in issues and pull requests. Harassment, personal attacks, and discriminatory language are not tolerated, and maintainers will remove them and may block repeat offenders.
- Maintainers make the final call on what counts as a curated entry and explain the reason when they say no.

Report problems by opening an issue or emailing karan@karanbansal.in.
